# 霓虹工厂：界面与性能约定

地下端口使用 30px 整数 SVG，沿用传送带深色带面与金属轨道，增加钢制护罩、警示条、粉色入口 / 青色出口标记。图鉴与地图共用几何，入口预览半透明；选中配对才显示静态虚线，不绘制地下载荷轨迹。物品图标独立使用 32 格结构、128px 透明像素贴图。无新 RAF、微缩文字或持续装饰动画；资源与交互见 [地下传送带](underground-belts.md)。

厂区页与其升级 / 改名弹窗统一采用直角卡片、Tag、输入框和按钮，不使用圆角。面板复用其他操作台的深底色与细边，扩建栏使用青色左强调线，当前厂使用青色边框及静态浅底；弹窗沿用配方弹窗的青色细边和轻微静态光晕，不使用下沉式柔和阴影。两列密度、字号与交互保持。

厂区管理使用顶部青色细边扩建栏和固定两列紧凑卡片。卡片以文字按钮作为厂名 / 切换入口、右侧建筑数，当前厂静态青边，状态与两类终端数量收进至少 12px 的 Tag；底部并列青色取货升级、紫色存入升级及次级改名。费用和安装说明移入小型原生 modal dialog，列表不重复铺长段文字 / 每厂 tick；扩建保留当前数 / 上限，不显示六阶段长列表。对话框使用深色底、细边、终端静态贴图和正常字号，背景仅暗化，不加滤镜 / 动画，不参与工作台尺寸。任务机制奖励增加独立换行的次级使用指引。

开发者“功能测试”的模拟倍速复用 developer-tools 静态深底卡片，数值输入与应用 / 恢复按钮采用可换行 flex，字号继承至少 12px。当前 TPS、范围、临时生效说明和错误在卡片内显示；顶部沿用原 Tick / TPS 状态行，不扩大 HUD 或改变工作台 / 地图尺寸。速率不改变普通 / 节能 RAF 约 60 / 15 FPS 上限，不增加独立动画时钟。

全站字体统一为本地分发的 Fusion Pixel Font 12px proportional zh_hans Regular，包括登录 / 注册、原 mono 令牌与表单。当前使用 400 / normal，重置语义标题 / strong / em 和伪元素，禁用合成粗体 / 斜体；低于 18px 不粗体、任何字号不斜体，最小字号仍为 12px。HTML 优先请求同源字体，进入工厂前以真实文件进度条等待字体和所有图标就绪；不增加持续动画，加载 / 错误页继续共用工作台尺寸。许可证、加载与验收见 [fonts-and-loading.md](fonts-and-loading.md)。

建筑 / 物流已采用正式混合外观：78 张方形正视、适量金属机械结构的 128px 透明图片，12 个可拼接物流定义由整数几何代码绘制，覆盖全部 90 个目录 ID。GUI 使用建筑自身阶段的脚下光影，地图使用阶段轮廓；正视机壳不旋转，方向箭头、状态点和真实液位由代码叠加。全量资源、来源与复现见 [building-art.md](building-art.md)。

物品采用经用户确认的 V2 像素方向，正式资源为 128×128 透明 PNG，保留约 32 格的 MD / SFC 像素结构、大色块、简洁明暗和粉 / 青强调。处理阶段补 1 个逻辑像素的黑色轮廓；阶段色改为图片下方的静态椭圆光影，不烘焙彩边 / 光影。352 种现行物品与 3 种旧档物品已接入共用 ItemSprite，详见 [item-art.md](item-art.md)。

任务卡采用静态深色渐变底、左侧强调线和纯白色 12px 标题，与 item-name-link 字号一致，避免内嵌物品名称出现大小 / 颜色跳变；描述以 12px 次级文字区分。物品链接仍保留悬停青蓝色与点击查来源。阶段 / 状态 / 终局各为独立标签，进行中暖黄、待领奖青色、已领奖灰色，均保留明确文字。奖励采用与 workshop-material-card 共用的两列物料卡，32px 物品图标、可点查名称和独立数量行，机制奖励单列；长名称换行，领奖按钮靠右。隐藏终局只显示“终局任务会在工厂发展到一定程度后出现”；保持原开放规则、固定工作台、最小 12px 和独立滚动，无新增动画。

P2 多物品入库任务在原任务卡中按物品显示图标、可点查名称与独立计数，使用可换行网格、静态青色数字和至少 12px 文字；保留现有奖励卡 / 终局粉框，不新增动画或改变固定工作台尺寸。

通用阶段目标只显示一段简短搞怪叙事，不重复附加阶段成果 / 解锁规则长说明；任务页移除通用说明，实际门槛仍由任务卡展示。能源类型页签常显，未开放项使用灰字、暗边框和 disabled，不可点击；P1 手工动力复用静态卡片与两列读数，标明趣味自评，无新计时器、动画或能源状态。

机器人、能源和开发者子页使用统一静态操作台样式：深色卡片、青色操作边框、紫色 / 粉色导览条、12px 等宽短标签与 18px 导览标题。机器人以三步准备、三列机队数据、两列部署 / 路线表单和机队卡片分区，运行参数使用原生 details / summary 折叠；本厂限定机型省去无效厂区表单，P2 不渲染训练 / 摄像头 / 智能施工控件。能源使用类型切换、连接顺序与三步指引、两列供需数据和独立网络卡片；炉体热量单列，电池说明按电力类型出现。开发者工具内以“功能测试 / 闭环诊断”按钮切换，不新增顶级诊断页签。所有卡片 / 表单可收缩、长内容换行，checkbox 保持 18px；文字至少 12px，独立滚动和固定 16:9 / 18:58:24 三栏保持，无新 RAF、滤镜或装饰动画。

图鉴搜索框使用内缩 12px 的容器、100% 宽与 min-width:0，不让原生输入框越过侧栏；下方阶段筛选采用六等分 minmax(0,1fr) 按钮，12px 字号、青色选中 / 禁用灰显，窄栏不撑宽。地图标题保持 42px，X / Y 提示右侧放 142×28px 厂区下拉框，长名称受选择框宽度约束。仓库每张卡统一采用 36px 顶部内边距，按钮仍绝对定位右上，图标 / 名称不因能否下单错位；不添加不可见可聚焦按钮。检视“机械手下单”沿用来源按钮样式并紧随其下。保持固定 16:9、18:58:24 三栏、仓库五列和最小 12px，不新增 RAF。

传送带使用 30×30 整数像素 SVG，包含暗色带面、金属轨道 / 横纹、阶段轮廓与独立白色方向箭头。沿用原邻格带的方向判定：上游箭头指向本格时补接入口，本格出口贴合前方传送带，支持不同级别带和多入口。方形拐角 / 交汇共享截面，相连开口没有横挡，空闲端封闭且不越格。几何按类型 / 端口 / 开放边缓存，仅视觉读布局，不依据启停 / 缺能 / 过滤 / 带速推断成功运输；放置 / 移动预览复用，物品动画与运行层不变，不新增 RAF。

普通 / 回流管道采用同一整数几何体系，金属壁、内腔和管箍形成方形弯头 / 汇流口；沿用原邻格流体节点朝向，本格出口沿自身箭头，无入口时保留后方接口。非零真实存量仅提高内腔亮度，不改变端口或推断成功流动。储罐 / 阀 / 泵使用正视图片外壳叠代码接口和真实液位；轴网、电缆、液压动力线各有区别明确的几何与配色，只连接同类型邻格导线。地图 / 预览共用 30px 整格，保留选中 / 有效 / 无效提示，不新增 RAF 或持续动画。

阶段终局任务在纵向卡片中使用粉色描边、静态轻阴影与“阶段终局任务”小标签，领奖就绪也保持粉框；下一阶段说明及隐藏前的简短发展提示为至少 12px 粉色文字，允许换行。隐藏项不占列表高度 / 数量 / 红点，已领奖终局仍显示标签；不加呼吸动画、RAF、滤镜或改变固定工作台尺寸。

P1 漫画为五张工作室 / 仓库 / 空厂房内景，复用开场手绘动漫 / 日漫式蒸汽波配色。BAKA-01 保持奶白方头、青色屏幕双眼、粉球天线、黄色机身、青绿围巾、金属夹爪及红工作靴，机械手是腕部外骨骼附件；不改成人形手掌或另一名角色。每页五行定稿正文自然换行，使用原播放器 14px / 18px 排版、图片 contain 和下一页预取，不新建滤镜 / RAF，也不改变工作台尺寸。

开发者工具默认不渲染入口与内容，控制台开启后位于主导航末尾，独立诊断已并入子页；关闭时回到原工厂视图，不保留空白内容。主导航仍为固定 44px 高并在超宽时自身横向滚动，显隐只影响按钮占位，不撑缩工作台或地图。设置页沿用深色面板 / 细边框，18px 勾选开关与至少 12px 的名称 / 状态 / 提示，文本允许换行；不增加 RAF 或持续装饰动画，不改变固定 16:9 / 三栏 / 地图尺寸。

仓库下单按钮位于可制品卡右上角，增加卡内顶部空间而不改五列布局。机械手计划大弹窗复用建筑来源弹窗深色遮罩 / 青框，编号工序用紫边与静态物品像素图；每步展示原料 / 产物，材料列表换行、内容独立滚动，数量 / 确认按钮固定底部。标题 / 关闭常驻，文字至少 12px；不改变底层 16:9 / 三栏 / 地图，不新增 RAF 或装饰循环。机械手运行使用现有顶部三行与共享进度时钟，工序与批次信息代替普通队列剩余行；机制奖励显示文字而非虚构物品图标。

剧情采用五张批准的手绘动漫 / 日漫式蒸汽波废土插图，单页大图在上、正文在下，黑蓝底 / 青框 / 紫色页标题。模态宽度最多 960px，高度随视口限制，图片最高 42dvh、contain 完整显示，内容独立滚动；页码和翻页按钮保持可用，底层 16:9 工作台不变。正文 14px / 18px 行高、段落单次换行，正文内边距 12px / 20px，无显示全文按钮；其余文字至少 12px，完整文案占位稳定版面。3 秒有限打字定时器最多普通 30 / 节能 15 次每秒更新，无新增 RAF 或持续装饰动画。资源与观看记录边界见 stories.md。

任务入口紧邻中央“工厂”，待领奖用纯图形红点和可访问文字表示；任务页独立滚动，待完成 / 已完成子分类使用静态青色选中边框。待完成卡片先列“已达成 · 待领奖”，后列“进行中”，同状态按推荐顺序纵向排列；已完成保留推荐顺序。物品图标 / 奖励数量允许换行，文字至少 12px。底部达成气泡为工作台内绝对定位的静态深底青框，pointer-events:none，每条用定时器显示 3 秒，无新增 RAF 或常驻装饰动画，不撑缩工作台 / 地图。

建筑来源弹窗使用深色遮罩、青色细框和静态紫色安装道具卡，宽度最多 1080px、受视口限制，高度受视口限制并在内容区滚动；标题 / 关闭按钮常驻顶部，配方卡随可用宽度排列一至多列。获取来源与设施配方分区，名称对应关系用文字和洋红强调。文字至少 12px，不新增持续动画，不改变底层固定 16:9、三栏或地图尺寸。

## 设计方向

参考用户的 [BAKA CYBER GAME](https://iobaka.com/)：已通过浏览器查看页面截图，提取黑底、青 / 洋红双霓虹、像素标题、街机按钮、细框与低亮度网格的视觉语言。本项目重新绘制自己的工厂场景、标题、图标，不依赖该站资源或脚本；字体采用随项目分发的开源 Fusion Pixel。

画风为赛博朋克与蒸汽波结合。深夜蓝黑作为大面积背景，青色表示连通、有效建造和运转，洋红用于建造选择与品牌，紫色连接两者。落日、透视网格与工业轮廓主要用于游戏入口；游戏中保持背景克制，让真实物品、端口、方向与选中标记清楚可见。

入口使用像素 SVG 字标和静态矢量工厂插画。主界面是一张地图周围的游戏 HUD，避免大块账号表单、阶段说明和实现细节占据游戏空间。文字仍以易读中文为主，英文只作短标签。颜色之外保留物品名称、文本代号、方向箭头、状态文字和有效 / 无效边框。

## 全局排版要求

所有中英文文字最小 12px，此规则同时约束当前界面和未来开发。说明、次级标签、快捷键、坐标、库存数量、图标代号、表单占位符与小屏样式均无例外。style.css 的 --font-min=12px 提供继承下限，既有显式字号均已提升；不使用 font-size:0 隐藏文字。行高和图标容器同步扩大，空间不足使用换行或布局调整。

地图坐标在缩放小于 100% 时用反向字号补偿，使保留的坐标实际至少 12px；缩小状态只显示每 5 格的主要坐标。机壳图像不烘焙文字；120% 起仅建筑类机器在格子下半部叠三字以内中文简称，使用独立于地图 scale 的 12px Regular 屏幕图层，白色填字、2px 工厂地面色描边，先描边再填字。物流和非机器不显示，未知定义的旧 SVG 代号在地图内也隐藏；完整名称 / 编号留在图鉴、检视、鼠标提示和无障碍名称。放置 / 移动预览共用，标签不旋转、不拦截手势、不新增 RAF，底部原进度条保持。清单见 [machine-map-names.md](machine-map-names.md)。运动中的物品使用对应物品像素图；地图 120% 起在图标底部显示实际堆叠数量，固定屏幕 12px Regular，低于门槛省略数字。数字复用载荷节点的 transform，不新增 RAF 或逐帧 React 更新；进入机器 / 仓库后的吸收尾迹不保留数字，避免缩小文字。

`npm run lint` 包含 scripts/check-ui-typography.mjs：检查 CSS 的 font / font-size、变量下限与 TSX 字面量 fontSize，并禁止斜体 / oblique，粗体声明须在同规则明确至少 18px。新字号使用 px、已验证变量或带 12px 下限的 max / clamp；相对单位不能单独作为字号而绕过下限。当前字体仅用 Regular，新增标题也应优先通过字号 / 颜色表达层次。该检查是源码约束，实际浏览器排版仍由用户验收。

## 布局与交互

所有选择框采用统一静态霓虹下拉：深色直角按钮、青色边框 / 箭头，当前项勾选，悬停 / 键盘活动项浅青底，禁用项灰显。物品展开宽约 380px，顶部七等分“全部 / P1～P6”和搜索，24px 像素图标搭配名称 / 编号 / 阶段；配方展开宽约 560px，名称 / 工时与完整投入 → 产出分行，材料图标 / 数量可换行。弹层按视口上下放置、限宽限高，仅列表滚动，字体至少 12px / 行高 18px；无滤镜背景或持续动画。普通字段约 36px，快捷切厂保留 142×28px，固定工作台与三栏保持，见 [自定义下拉](custom-selects.md)。

连续删除沿用工具栏现有回收按钮，以静态红边 / 深红底标明激活态，并在工具说明与状态栏显示“连续删除 · 右键 / Esc 退出”。鼠标为十字，悬停目标的全部覆盖格及地下配对显示红色轮廓；不可回收设施使用灰色虚线及文字原因。机器人仍显示但不执行点删。无额外定时绘制、装饰动画或布局变化，全部提示继承至少 12px 字号。

地图批选使用静态青色半透明屏幕选框，选中实例全部覆盖格显示内边框；整组拖动逐实例显示透明机壳预览、有效 / 无效占格颜色及数量提示。选框、预览和状态不参与布局计算，不新增 RAF、缩小字号或装饰动画，范围见 [批量编辑](batch-editing.md)。

- **16:9 固定在整个 factory-workspace 外框**，包含资源 HUD、三栏主区和底部操作条。工作台宽度 max(90vw,1200px)，显式高度为该宽度的 9/16；浏览器宽 1920px 时约 1728×972px，最小 1200×675px。游戏页面与工作台对齐、居中，不再受旧内容最大宽度或额外横向内边距限制。
- 登录状态区分未确认 / 游客 / 玩家：未确认先保留 game-shell，只有确认游客后才显示首页。登录确认和工厂加载 / 失败使用与正式工作台共享的宽高规则；玩家条及登录确认占位统一为 53px，加载框无额外外边距。刷新恢复登录时不先闪现首页，也不从 300px 高的加载框跳到完整工作台。
- 建造阵列 / 产线现场 / 模组检视按 **18:58:24** 分配扣除两个 16px 间距后的宽度，检视固定在右侧。主区行高使用 minmax(0,1fr)，两侧栏 size containment、独立滚动并预留滚动条；中央地图填充剩余空间，工具及状态条保留固定高度。Tab、不同配方详情、建造提示和错误浮层不参与外框尺寸计算。
- 窄窗口仍保持最小 1200px 和三栏比例，用页面横向 / 纵向滚动查看，不切回旧的上下布局或缩小字号。16:9 指工作台外框，中央可操作地图区域随中央面板填充，不另设比例造成争抢高度。
- 玩家档案收进弹出层；可改昵称并保存，登出保留在玩家条。档案与操作指南支持点击外部、Esc 关闭；Esc 关闭后返回触发按钮，再由后续 Esc 取消建造。成功提示 4.5 秒后自动清除。
- 数字 `1–6` 按当前阶段图鉴的前六项切换建造，不受搜索结果重排；同键再按退出。输入框、可编辑内容、Ctrl / Meta / Alt 组合、按键连发不触发。原有 `R`、`Delete`、`Esc` 与鼠标交互保持。
- `F` 或“沉浸视图”收起左右侧栏；DOM 保留，所选工具、旋转方向与库存不丢失，数字键仍可更换模组。工作台外框宽高保持，中央地图横向扩展；退出后恢复三栏。ResizeObserver 在视口尺寸改变时保持同一世界位置位于视口中心，取消未完成的指针操作，避免相机跳动。
- 建筑选中使用青色角标；放置有效为青色、无效为红色。空格和地图容器保持无焦点高亮边框。已有建筑 50ms 长按移动、右键菜单、连续建造、滚轮缩放和拖动空格平移保持。

## 性能边界

- 沿用 DOM / CSS / SVG，不新增引擎或图形依赖；字体为单个同源 WOFF2，进入工厂前与全部图标预热，运行中不持续请求。无背景视频、粒子海、全屏模糊、SVG 滤镜或不断运行的故障闪烁。光晕仅少量静态背景 / 悬停效果，空闲界面没有装饰动画循环。
- 物品与生产进度仍共享一个 RAF，平衡模式将持续 DOM 绘制限制在约 60 FPS，避免高刷屏重复绘制；节能模式约 15 FPS，减弱地图装饰和物品阴影。按实际经过时间采样，因此动画时长、客户端 2 TPS 和生产速度不变。快照 / 交互确认会即时校正一次画面。
- 所有视觉完成后停止请求 RAF；后台暂停；恢复不补播积压物流。节能模式仅减少绘制次数，不改变本地生产规则。
- 节能开关保存到本浏览器 localStorage 的 `bakafactory:power-saving`，不写入账号或工厂。没有显式偏好时，系统 `prefers-reduced-motion: reduce` 默认启用节能；CSS 同时关闭交互过渡。存储被禁用时，当前页面仍可切换。
- 静态图标、带面、机器地图进度条与物品图层 memo 化；坐标 / 类型查找 Map 根据布局和图鉴 memo 化，避免鼠标移动反复重建 SVG 和物流图层。地图视口使用布局 / 绘制 containment，物品轨迹仍直接更新 transform / opacity，不逐帧 React setState。
- 维持 30px 单元、25px 坐标轴、1px 网格边框及原有坐标换算；不让视觉重构破坏落点。本地模拟与网络备份分离，尺寸不随在线 / 备份状态改变。

这里是实现策略，不是设备性能基准。实际帧率、浏览器缩放 / 高 DPI、移动端排版和长时间挂机功耗由用户验收；不要把编译通过写成实机性能测试通过。
