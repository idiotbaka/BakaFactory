# 霓虹工厂：界面与性能约定

任务、工作室物料和仓库的可查道具名使用 12px 白色文字及同色下划线，悬停立即显示主题青蓝色，移开立即恢复白色，不启用颜色过渡；展开状态不单独改色，保留键盘焦点轮廓。来源小浮卡为固定定位的深底青框，宽度最多 420px、高度最多 600px 且受视口限制；标题 / × 常驻，详情独立滚动，长名称与材料列表换行。浮卡在名称旁按实际尺寸避开视口边缘，不加遮罩、全屏滤镜、持续动画或额外 RAF，不改变底层固定 16:9 / 三栏 / 仓库五列布局。

剧情采用五张批准的手绘动漫 / 日漫式蒸汽波废土插图，单页大图在上、正文在下，黑蓝底 / 青框 / 紫色页标题。模态宽度最多 960px，高度随视口限制，图片最高 42dvh、contain 完整显示，内容独立滚动；页码和翻页按钮保持可用，底层 16:9 工作台不变。正文 14px / 18px 行高、段落单次换行，正文内边距 12px / 20px，无显示全文按钮；其余文字至少 12px，完整文案占位稳定版面。3 秒有限打字定时器最多普通 30 / 节能 15 次每秒更新，无新增 RAF 或持续装饰动画。资源与观看记录边界见 stories.md。

任务入口紧邻中央“工厂”，待领奖用纯图形红点和可访问文字表示；任务页独立滚动，待完成 / 已完成子分类使用静态青色选中边框。卡片沿推荐顺序纵向排列，物品图标 / 奖励数量允许换行，文字至少 12px。底部达成气泡为工作台内绝对定位的静态深底青框，pointer-events:none，每条用定时器显示 3 秒，无新增 RAF 或常驻装饰动画，不撑缩工作台 / 地图。

建筑来源弹窗使用深色遮罩、青色细框和静态紫色安装道具卡，宽度最多 1080px、受视口限制，高度受视口限制并在内容区滚动；标题 / 关闭按钮常驻顶部，配方卡随可用宽度排列一至多列。获取来源与设施配方分区，名称对应关系用文字和洋红强调。文字至少 12px，不新增持续动画，不改变底层固定 16:9、三栏或地图尺寸。

左侧图鉴三分类依次为建筑、物流、物品。未获得物品使用灰色文字 / 边框和灰阶图标，仍可选择查看，名称 / 编号和原序保持；获得后恢复现有实体色，不添加解锁动画。中央仓库固定五列卡片，图标、名称、数量纵向排布并允许长文本换行，最小 12px。顶部仓库摘要移除后 HUD 保留原 100px 行高，状态与 tick 排两列，工作台 / 地图尺寸不变。

顶部横栏保持 100px，左侧工厂名 / 状态，右侧手工加工采用三行紧凑布局：状态 / 当前批次、配方 / 工时进度、剩余批数（含当前批）/ 取消按钮。行距 3px，12px 文字采用 18px 行高，按钮内边距 2px / 6px，进度条上间距 4px；长配方名省略显示，不撑高外框。复用现有 DetailedProgress 和共享帧时钟；空队列隐藏取消及剩余批数，工作室不再显示独立队列卡。工作室数量 / 批量按钮在配方卡片内可换行，显示本次可加工上限和非法数量提示，不增加独立 RAF 或装饰动画。

机器检视的批量补料保持同一行左侧数字输入、右侧补料按钮；输入宽 56～72px，按钮占剩余宽度，下方为跨两列的当前可补完整批数 / 自动上限说明。文字至少 12px / 18px 行高，长提示换行并随检视滚动，不撑缩三栏和地图；输入超上限不标为错误，执行后回显采用的批数。

工作室设备子分类放在垃圾堆下方，仅子分类包在 sticky 容器中，垃圾堆保持普通文档流；子分类容器以 top:0 吸附中央 industry-content 滚动区顶部，z-index:20、不透明面板背景 / 底边框，负外边距补齐滚动区左右内边距；不额外监听滚动或增加 RAF。子分类超宽时仅自身横向滚动；锁定项灰色但名称完整，外层悬停提示解锁要求。配方卡仅标注实际手工工时，批数超限立即显示当前上限，不以错误色拒绝合法正整数。物料卡使用静态 SVG 图标、右侧名称和库存 / 需求或产量两行文字；每批原料 / 产物各两列，名称和大数量允许换行，字体至少 12px，不缩放文字。原料不足以文字 / 边框表示；切设备和解锁不改变 16:9 外框、三栏及顶部进度尺寸。

F 诊断使用中央独立滚动页和现有霓虹表单 / 列表，固定三栏与工作台尺寸；实际观察窗口、问题坐标、配方来源和终局文字均至少 12px。问题最多显示 80 条、实产 / 机器人列表最多 40 条，说明保留全部问题数与显示范围。没有终局全屏特效、常驻图表动画或额外 RAF；定位问题回到既有地图选择。

机器人用小型静态 SVG 轮廓显示确认格位，无字母微缩或装饰循环，过境隐藏旧位置。机器人管理沿用中央独立滚动页，部署 / 召回 / 优先级 / 授权及 E2b 任务表单文字至少 12px；多厂区授权与取送设置只展开当前选中机器人，避免为每台同时展开百区清单。列表展示携货、过境与阻塞状态，标签行可横向滚动，仍保持固定工作台高度。

E2c 真实作业面板沿用同一中央滚动容器，显示确认的异常、账本存量和附件 / 指派按钮，不增加地图浮层 / 全屏动画。检查 / 维护进度用原有任务文字，配方条件说明仍至少 12px；状态刷新不改变工作台、地图或左右列宽。

E2d1 自主派单复用选中机器人详情，四个权限选项及最多 20 条最近记录独立随中央页滚动，不展开全世界实体树，不增加常驻动画；配置与日志仍遵守最小 12px 和固定列宽。

E2d2 蓝图表单复用机器人详情独立滚动，按当前厂区设置设备 / 坐标 / 方向 / 配方。地图以静态紫色虚线工具图形表示预留格，无微小字母、进度动画或独立 RAF；取消释放标记，真实完成后才显示建筑。进度和携货仅用确认文本，字体至少 12px，切换施工 / 错误状态不改变工作台尺寸。

E2e 机器人标记为可选 SVG 图形，选中边框与当前单路段静态虚线使用青色，不增加持续动画。右侧 RobotInspector 沿用既有 24% 检视列与独立滚动，中央列表筛选 / 定位不更改 16:9 外框及三栏比例；原编辑手势保持，建造模式优先处理放置，不让机器人标记抢占建造。状态、锁定原因和坐标文字至少 12px，机器人图形内不放微缩字母。

## 设计方向

参考用户的 [BAKA CYBER GAME](https://iobaka.com/)：已通过浏览器查看页面截图，提取黑底、青 / 洋红双霓虹、像素标题、街机按钮、细框与低亮度网格的视觉语言。本项目重新绘制自己的工厂场景、标题、图标；不依赖该站资源、脚本或第三方字体。

画风为赛博朋克与蒸汽波结合。深夜蓝黑作为大面积背景，青色表示连通、有效建造和运转，洋红用于建造选择与品牌，紫色连接两者。落日、透视网格与工业轮廓主要用于游戏入口；游戏中保持背景克制，让真实物品、端口、方向与选中标记清楚可见。

入口使用像素 SVG 字标和静态矢量工厂插画。主界面是一张地图周围的游戏 HUD，避免大块账号表单、阶段说明和实现细节占据游戏空间。文字仍以易读中文为主，英文只作短标签。颜色之外保留物品名称、文本代号、方向箭头、状态文字和有效 / 无效边框。

## 全局排版要求

所有中英文文字最小 12px，此规则同时约束当前界面和未来开发。说明、次级标签、快捷键、坐标、库存数量、图标代号、表单占位符与小屏样式均无例外。style.css 的 --font-min=12px 提供继承下限，既有显式字号均已提升；不使用 font-size:0 隐藏文字。行高和图标容器同步扩大，空间不足使用换行或布局调整。

地图标注在缩放小于 100% 时用反向字号补偿，使保留的坐标实际至少 12px；缩小状态只显示每 5 格的主要坐标，隐藏建筑代号，避免重叠。100% 起其他建筑正常显示代号；地图传送带在所有倍率均不显示 BELT（含放置 / 移动预览），保留带面、轨道和箭头，图鉴、检视与鼠标提示仍可识别名称。运动中的物品使用矿石 / 板材 / 齿轮矢量图形，不把字母压缩到微小图块或淡出缩放中。

`npm run lint` 包含 scripts/check-ui-typography.mjs：检查 CSS 的 font / font-size、变量下限与 TSX 字面量 fontSize。新字号使用 px、已验证变量或带 12px 下限的 max / clamp；相对单位不能单独作为字号而绕过下限。该检查是源码约束，实际浏览器排版仍由用户验收。

## 布局与交互

- **16:9 固定在整个 factory-workspace 外框**，包含资源 HUD、三栏主区和底部操作条。工作台宽度 max(90vw,1200px)，显式高度为该宽度的 9/16；浏览器宽 1920px 时约 1728×972px，最小 1200×675px。游戏页面与工作台对齐、居中，不再受旧内容最大宽度或额外横向内边距限制。
- 登录状态区分未确认 / 游客 / 玩家：未确认先保留 game-shell，只有确认游客后才显示首页。登录确认和工厂加载 / 失败使用与正式工作台共享的宽高规则；玩家条及登录确认占位统一为 53px，加载框无额外外边距。刷新恢复登录时不先闪现首页，也不从 300px 高的加载框跳到完整工作台。
- 建造阵列 / 产线现场 / 模组检视按 **18:58:24** 分配扣除两个 16px 间距后的宽度，检视固定在右侧。主区行高使用 minmax(0,1fr)，两侧栏 size containment、独立滚动并预留滚动条；中央地图填充剩余空间，工具及状态条保留固定高度。Tab、不同配方详情、建造提示和错误浮层不参与外框尺寸计算。
- 窄窗口仍保持最小 1200px 和三栏比例，用页面横向 / 纵向滚动查看，不切回旧的上下布局或缩小字号。16:9 指工作台外框，中央可操作地图区域随中央面板填充，不另设比例造成争抢高度。
- 玩家档案收进弹出层；可改昵称并保存，登出保留在玩家条。档案与操作指南支持点击外部、Esc 关闭；Esc 关闭后返回触发按钮，再由后续 Esc 取消建造。成功提示 4.5 秒后自动清除。
- 数字 `1–6` 按当前阶段图鉴的前六项切换建造，不受搜索结果重排；同键再按退出。输入框、可编辑内容、Ctrl / Meta / Alt 组合、按键连发不触发。原有 `R`、`Delete`、`Esc` 与鼠标交互保持。
- `F` 或“沉浸视图”收起左右侧栏；DOM 保留，所选工具、旋转方向与库存不丢失，数字键仍可更换模组。工作台外框宽高保持，中央地图横向扩展；退出后恢复三栏。ResizeObserver 在视口尺寸改变时保持同一世界位置位于视口中心，取消未完成的指针操作，避免相机跳动。
- 建筑选中使用青色角标；放置有效为青色、无效为红色。空格和地图容器保持无焦点高亮边框。已有建筑 50ms 长按移动、右键菜单、连续建造、滚轮缩放和拖动空格平移保持。

## 性能边界

- 沿用 DOM / CSS / SVG，不新增引擎、图形依赖或字体请求；无背景视频、粒子海、全屏模糊、SVG 滤镜或不断运行的故障闪烁。光晕仅少量静态背景 / 悬停效果，空闲界面没有装饰动画循环。
- 物品与生产进度仍共享一个 RAF，平衡模式将持续 DOM 绘制限制在约 60 FPS，避免高刷屏重复绘制；节能模式约 15 FPS，减弱地图装饰和物品阴影。按实际经过时间采样，因此动画时长、客户端 1 TPS 和生产速度不变。快照 / 交互确认会即时校正一次画面。
- 所有视觉完成后停止请求 RAF；后台暂停；恢复不补播积压物流。节能模式仅减少绘制次数，不改变本地生产规则。
- 节能开关保存到本浏览器 localStorage 的 `bakafactory:power-saving`，不写入账号或工厂。没有显式偏好时，系统 `prefers-reduced-motion: reduce` 默认启用节能；CSS 同时关闭交互过渡。存储被禁用时，当前页面仍可切换。
- 静态图标、带面、机器地图进度条与物品图层 memo 化；坐标 / 类型查找 Map 根据布局和图鉴 memo 化，避免鼠标移动反复重建 SVG 和物流图层。地图视口使用布局 / 绘制 containment，物品轨迹仍直接更新 transform / opacity，不逐帧 React setState。
- 维持 30px 单元、25px 坐标轴、1px 网格边框及原有坐标换算；不让视觉重构破坏落点。本地模拟与网络备份分离，尺寸不随在线 / 备份状态改变。

这里是实现策略，不是设备性能基准。实际帧率、浏览器缩放 / 高 DPI、移动端排版和长时间挂机功耗由用户验收；不要把编译通过写成实机性能测试通过。
