# 用户启动与验收

## 开场漫画与重放

以下由用户启动服务和验收；保留现有账号 / 工厂 / 数据库。首次流程可使用新注册的测试账号，不清除已有存档。

1. 新账号注册 / 登录，确认本机和云均无工厂后，在命名界面自动弹出“开场：下班计划开启”。加载中、读取失败或云冲突时不提前显示。首屏为宇宙垃圾合同，不能在弹窗后方创建工厂；首次无关闭按钮，Esc 不标记完成。
2. 逐页核对五张已确认原图与定稿文字：垃圾合同、BAKA-01 任命、招聘 0 人、制造同事、下班计划。弹窗最大宽 960px，正文 14px / 18px 行高、段落间不再插空白行，图片完整、不裁切；每页文字在 3 秒内显示完，普通 / 节能均为 3 秒，播放前后均不出现显示全文按钮。打字不改变内容区高度；切页重新计时，回看也是如此，生产快照不会重启动画。末页下一页变为完成，键盘翻到末页不自动结束。
3. 点击完成，保存成功后返回工厂命名表单，输入框恢复焦点且尚未自动建厂。可修改名称再明确点击创建；完成后即使还没建厂就刷新，也不再自动显示。中途刷新未完成则从首屏重新显示；失败时保留末页重试，不靠清缓存修复。
4. 已有工厂账号登录 / 刷新不强制播放。右下角操作指南左侧有重放剧情；向上弹层只列开场条目，点击后关闭列表、从第一页播放。重放可关闭、Esc 或点击遮罩退出，焦点回重放入口；再次重放从首屏开始，完成也不会新增工厂、资源或改变厂名 / 云版本。
5. 鼠标 / 上一页 / 下一页、方向键 / PageUp / PageDown 可翻页，Tab / Shift+Tab 焦点留在弹窗。弹出时按 1～6 / F / R / Delete 不改变底层地图与工具；关闭后恢复。长文 / 图片加载失败仍可滚动、查看文字和翻页，标题 / 完成按钮可用；文字不小于 12px，工作台 / 地图尺寸不变。重放时工厂仍按正常在线 / 可见性规则生产。
6. 同浏览器登出再登录同账号保留已观看；另一个无工厂账号仍自动显示。云恢复不清除本机已看记录；记录仅存本机，换浏览器无记录但恢复到已有工厂仍不强制显示。图片是独立静态资源，只展示当前页并预取下一页，不应在未打开剧情时一次加载五张。

已补三秒 / 节能 / 正文及翻页 / 失败与并发完成 / 模态焦点清理、首次流程 / 重放 / 既有工厂、建厂前保存 / 账号隔离 / 云恢复及保存失败重试的测试代码，留给用户执行 `npm test`；当前未运行自动或浏览器测试。

## P1 开放任务

本轮修改了 Go 云存档结构，请先由用户重启 `npm run dev`；保留账号、本机与云存档，不清档。任务配置和奖励表见 quests.md。

2. 工作室执行 R1001，一批实际完成时任务 1 达成：底部气泡显示 3 秒，随后消失；任务入口右上角有红点。开工后取消 / 未完成、地图分拣台执行 R1001、暂停等待不能完成该任务。批量多批仅产生一次该任务达成通知。
3. 按顺序或跳序制造 / 获得 M03、M04、M06、M08、手摇带、初阶自动投料机；各项达成并显示奖励。自动投料机任务明确实际道具名，奖励 5 初阶自动投料机。已安装或消耗道具不撤销达成，多任务同一刻达成时通知逐条各 3 秒，不因下一 tick 刷新延长。
4. 对达成项点击领取，按表核对起始仓增加 10 支架 / 20 粗铁片 / 120 垃圾包 / 20 废铜线与 40 铁质碎片 / 40 粗铁锭与 40 简易齿轮 / 15 手摇带 / 5 投料机。领取后进入已完成，不再提供领奖；还有其他未领奖项时红点保留，全部领取后红点消失。重复请求、溢出原子拒绝由测试代码覆盖，不在正式存档造假。
5. 切分厂查看 / 领奖，奖励仍只到起始仓；暂停 / 断网时不能领奖，恢复后继续。领奖不改变原建造工具或设备配方，不增加制造量 / 首次制造解锁。正常生产 tick 仍可继续。
6. 本机保存后刷新、上传云备份并恢复或换端，完成 / 已领奖保留，不能重复领；不重播旧任务气泡。旧档已有设备获得记录会补认，但无法证明旧工作室 R1001 历史时需再实际完成一批。旧档补认后的待领奖项应有红点，无需重新制造设备。

测试代码覆盖实际批次、取消 / 机器分拣不计、跳序 / 分厂领奖 / 重复与溢出回滚、旧档及坏账本、云恢复 / 通知去重、三秒时序、界面顺序与红点；由用户运行 `npm test` 和浏览器验收，当前未执行。

## 工作室设备子分类与物料卡

1. 打开起始工作室，在无尽垃圾堆下方看到手动分拣台、铁砧锻台、手工工作台、简易拆解台、手摇破碎机、手工装配台。前三项可选、默认分拣，仅显示当前设备配方；切分类和输入搜索不影响正在运行的共用队列，顶部进度保持。
2. 未制造拆解台 / 破碎机 / 手工装配台时，对应三项灰显不可切入，鼠标悬停显示“至少需要生产 1 次该设备后才能解锁”。通过手工工作台真实完成相应设备后立即可选，不要求安装或额外支付。将道具用于安装 / 消耗后仍解锁，刷新及云恢复保留；旧已有制造记录也应开放。只持有、查看或拆回设备不代替真实制造记录，Worker / 云存档非法队列由测试验证，不在正式存档中造假。
3. 在新增分类选配方直接批量加工，原料从起始仓预留、产物逐批直接入仓；工时、100 批上限、暂停 / 恢复和取消剩余退款不变，不需要地图设备参与。炭化炉及其他设备不因解锁这两项而获得工作室权限。
4. 每批原料 / 产物分别呈现小卡，包含物品图标、名称以及“存 60 / 需 3”或“存 0 / 产 2”；这里数量是每批值。库存不足显示“不足”且不能开工，库存变化实时更新。核对九种分拣产物、大数量 / 长名称、空搜索结果、切子分类及灰显解锁均不撑开工作台 / 地图，所有文字至少 12px。

手工装配台追加验收：完成 R1032 后不安装设备，切入手工装配台，直接批量生产 R1033 手摇传送带；中途取消只返未完成原料，成品直接入起始仓。M08 后续阶段配方仍受原阶段 / 里程碑限制；六个子分类超宽时在中央区域横向滚动，不挤压工作台。

## 顶部手工进度与批量加工

1. 在起始工作室备 36 包垃圾，为基础分拣输入 3 批并提交：立即预留 36，顶部显示配方 / 第 1 / 3 批及当前批工时；中央不再重复进度条。切工厂、仓库、机器人及分厂，顶部仍显示同一队列，100px HUD / 固定三栏不变。分厂不能另开第二队列，输入框不触发建造快捷键。
2. 库存只够 2 批时，输入 3、0、小数或留空不可提交，显示按最短缺原料计算的可加工上限；库存足够时也不能超过 100。操作期间库存变化后 Worker 复核，不得半扣原料。相同配方每次只能排一组；忙碌、暂停或无原料时按钮不可用。
3. 按原配方工时完成第一批，只增加这一批产物和制造记录，剩余数为 2；第二批未完成时取消，已完成产物保留、只退 24 包，重复取消不再退款。100 批按相同单批速度依次完成，不能一次给全部产物或随厂数加速。
4. 在中途工时 / 多批剩余时本机保存、刷新、手动上传及换端恢复，批次与进度保留、不重扣原料；旧单批队列按 1 批继续。后台 / 断网暂停，恢复不追赶。产物数值上限的程序边界由测试代码验证，不要求在正式存档中手改库存；该等待时顶部不预演生产，取消仍按剩余数量退款。

新增批量守恒 / 取消 / 100 批 / 非法数量 / 旧档 / 多厂只推进一次、跨厂背压与完整云快照、UI 数量校验及顶部进度 / 暂停测试代码，自动测试与浏览器验收由用户运行。

## E2d3 / E2e 机器人交互与恢复人工验收

本节与全量游玩一起执行，不需修改存档。测试代码仍由用户统一运行。

1. 地图点选或键盘激活一个机器人标记：右侧切到“机器人检视”，显示相同实体 ID、确认坐标、能量、任务与携货；不会建造 / 移动建筑。打开管理后列表选中同一实体；列表搜索或切换当前厂区 / 等待筛选只改变显示，不取消任务。点图鉴或建筑恢复原检视，原连续建造、50ms 长按移动、右键、平移 / 缩放、1～6、F 与节能保持。
2. 为运输、现场作业或施工中的机器人查看地图：只绘制当前单路段静态虚线，避开实际建筑 / 蓝图并按 WH 端口和当前占格计算。实际下一行动应与当前预览一致（其后别的实体可能改道）；没有提前扣料、授能或凭据。取消、目标配置变化 / 删除、新快照后预览更新，不重放已完成路段。

## 4. 本机保存与暂停

1. 建造、移动、旋转和删除后刷新，编辑结果保持；正常生产至少 5 秒后刷新，恢复最近本地保存。
2. 关闭游戏，等待一分钟后重新打开；tick 与数量从保存位置继续，不增加一分钟收益。
3. 切到其他标签页或最小化后等待，再返回；工厂没有后台收益，也不连续追刻。休眠 / 唤醒同样不补算。
4. 游戏已载入后断开网络；页面应暂停并保留工厂。恢复网络后经心跳校验继续，不补算断网时长。
5. 在浏览器 Network 中只让云上传失败，保留心跳成功；本机生产不受失败影响，显示备份失败并后续重试。
6. 限制网站存储导致写入失败时，显示本地保存失败并暂停；恢复存储能力后通过“存档 → 重试本地保存”恢复。损坏存档不能静默清档。

强制终止浏览器可能丢失最近未完成保存的少量进度；不承诺关闭事件必定执行。

## 5. 单槽云备份与换设备

1. 打开“存档”，确认本机 / 云端时间和“有新进度”。点击“立即上传云存档”，显示成功时间。
2. 修改工厂后再次上传；服务端仍仅有一个云存档，后一次覆盖前一次。
3. 持续前台联网游玩 30 分钟，确认自动备份；生产中的快照请求不再每秒发到服务器。心跳约每 10 秒一次且不含工厂状态。
4. 换另一个浏览器 / 设备登录，默认恢复最近成功上传的工厂；未上传进度不能在新设备恢复。
5. 新设备登录后旧设备在下次心跳失败时返回登录。旧设备本地数据保留，不能再上传。检测有轮询延迟，Worker 在线许可最多 30 秒。
6. 另一设备上传更新后回到原设备重新登录：本机与云版本不一致时暂停，出现选择入口，不应静默覆盖。
7. 选择“保留本机并覆盖云端”则明确以本机替换唯一备份；选择“恢复云存档”需确认后以云状态替换本机。
8. 手动恢复时取消确认，本机保持。上传进行期间继续生产，上传响应到达时 tick / 库存不能倒退。
9. 上传成功后清除该站点数据，再登录可恢复云备份。仅有本机进度且从未成功上传时，清除网站数据将无法恢复；请先上传后做此验收。
10. 同一浏览器另一页面重新登录后，旧页面不能借用新 Cookie 延续旧游戏会话。
