# 用户启动与验收

本轮服务启动、自动测试和浏览器验收由用户执行。账号保留；旧服务端工厂进度不导入新架构。不要删除旧数据库。

## 1. 启动与检查

首次安装依赖用 `npm run setup`，之后在仓库根目录运行 `npm run dev`。升级后重启原 Go / Vite 服务，刷新页面，保证前后端均为新版本。

可分别运行 `npm run lint`、`npm test`、`npm run build`、`npm run test:smoke`，或 `npm run check`。HTTP 冒烟使用临时数据库与临时服务，验证登录、单槽云备份、旧版本拒绝、重启保存及服务端不生产；浏览器生产和物流由 Web 测试与下列手动步骤覆盖。

## 2. 新架构首次进入

1. 登录已有账号：没有新本机 / 云存档时出现命名表单，不读取旧布局。创建工厂后只有中心固定 WH，库存为零。
2. 刷新后工厂来自本机 IndexedDB，名称、布局、库存和进度保持；其他账号应是独立工厂。
3. 登录确认、加载失败与正式工作台保持相同 16:9 外框和玩家条高度，不闪回游客首页。
4. 第二个标签页打开同账号，提示原页面已运行，不应多开生产；关闭原页面后重试可接管。

## 3. 基本生产、物流与守恒

最简链：MIN(-2,0) → OUT(-1,0) → WH(0,0)，朝向全部向右。每秒入库一件铁矿，选中机器可看库存。生产 1 TPS，普通 / 节能模式数量增速一致。

完整链在 y=0，x 从 -10 到 0：

| x   | 建筑    |
| --- | ------- |
| -10 | MIN     |
| -9  | OUT     |
| -8  | BELT    |
| -7  | IN      |
| -6  | FUR     |
| -5  | OUT     |
| -4  | BELT    |
| -3  | IN      |
| -2  | ASM     |
| -1  | OUT     |
| 0   | 固定 WH |

等待约 20 秒应出现齿轮；熔炉 4 秒、装配机 8 秒。测试满产物暂停、堵塞带保留物品、同一物品不瞬间多走几格、满载环路同时转移。将铁矿送给 ASM 应拒绝，来源数量不变且不出现成功入料动画。

拆除装有原料、产物或带上物品的建筑，全部已有物品一次回收到总仓库；未完成配方不提前发放产物。移动 / 旋转后实例 ID、库存和进度保持。WH 不可删除或搬动。

## 4. 本机保存与暂停

1. 建造、移动、旋转和删除后刷新，编辑结果保持；正常生产至少 5 秒后刷新，恢复最近本地保存。
2. 关闭游戏，等待一分钟后重新打开；tick 与数量从保存位置继续，不增加一分钟收益。
3. 切到其他标签页或最小化后等待，再返回；工厂没有后台收益，也不连续追刻。休眠 / 唤醒同样不补算。
4. 游戏已载入后断开网络；页面应暂停并保留工厂。恢复网络后经心跳校验继续，不补算断网时长。
5. 在浏览器 Network 中只让云上传失败，保留心跳成功；本机生产不受失败影响，显示备份失败并后续重试。
6. 限制网站存储导致写入失败时，显示本地保存失败并暂停；恢复存储能力后通过“存档 → 重试本地保存”恢复。损坏存档不能静默清档。

强制终止浏览器可能丢失最近未完成保存的少量进度；不承诺关闭事件必定执行。

## 5. 单槽云备份与换设备

1. 打开“存档”，确认本机 / 云端时间和“有新进度”。点击“立即上传云存档”，显示成功时间。
2. 修改工厂后再次上传；服务端仍仅有一个云存档，后一次覆盖前一次。
3. 持续前台联网游玩 30 分钟，确认自动备份；生产中的快照请求不再每秒发到服务器。心跳约每 10 秒一次且不含工厂状态。
4. 换另一个浏览器 / 设备登录，默认恢复最近成功上传的工厂；未上传进度不能在新设备恢复。
5. 新设备登录后旧设备在下次心跳失败时返回登录。旧设备本地数据保留，不能再上传。检测有轮询延迟，Worker 在线许可最多 30 秒。
6. 另一设备上传更新后回到原设备重新登录：本机与云版本不一致时暂停，出现选择入口，不应静默覆盖。
7. 选择“保留本机并覆盖云端”则明确以本机替换唯一备份；选择“恢复云存档”需确认后以云状态替换本机。
8. 手动恢复时取消确认，本机保持。上传进行期间继续生产，上传响应到达时 tick / 库存不能倒退。
9. 上传成功后清除该站点数据，再登录可恢复云备份。仅有本机进度且从未成功上传时，清除网站数据将无法恢复；请先上传后做此验收。
10. 同一浏览器另一页面重新登录后，旧页面不能借用新 Cookie 延续旧游戏会话。

## 6. 编辑器与布局回归

保持连续放置、已有建筑 50ms 长按移动、右键旋转 / 删除、输入框快捷键隔离、1～6 建造、F 沉浸、拖动平移和滚轮锚点缩放。同向传送带连接保持，地图不显示 BELT 文本。

工作台固定 16:9，三栏 18:58:24，检视始终在右，侧栏独立滚动；窄屏横向滚动。切 Tab、不同详情、错误 / 存档冲突不能改变外框与地图宽高，F 只收起两侧栏。所有中英文文字至少 12px。
