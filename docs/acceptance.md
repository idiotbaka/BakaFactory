### C：固体物流验收

1. 通过 M08 制作 R1033 初阶带、R1034 料箱、R1039 自动投料机，保留对应道具。安装消耗道具，拆迁按当前批次数量完整回收；不要清除原有存档测试。

### D1：能源、蒸汽启动与储电

1. 重启更新后的 `npm run dev`。通过正常配方积累道具，在空闲区域搭独立支路，例如 (2,0) M09 固燃传动机、(3,0) 传动轴、(4,0) M10 筛分器，不接其他负载。选择筛分配方并补一批原料，未加燃料前不工作；给 M09 加 1 固体燃料块后，9 kW 工艺工作一刻，轴损 1 kJ，燃料可用量合计从 1,980 降到 1,970 kJ。
2. 暂停传动轴，进度 / 原料保持；恢复后继续。产物满载或原料不足时生产机不申请功率。机械带 / 分流 / 投料属于持续驱动负载，启用即耗能，空闲线路可暂停。
3. 进入能源视图检查独立网络供需和实际供给。让大功率设备接到不足额电源，工作能量逐刻积累、有效工时降低；不能低功率却满速。多个同级负载轮换，改优先级 1 后优先获得能量。
4. 用 M14 先净水、后 R2026 造蒸汽；M20 选择 R3007、补原油并手动添加 4 u 高压蒸汽。无液压网时也可完成 16 秒分馏，产生原配方产物，剩 80 kJ 蒸汽能量。原油、蒸汽均须实际制造，不赠送初始库存。
5. M21 用 R3012 两批冷混配，真实消耗添加剂 / 净水，收得 4 u 工作液；注入 1 u 后仓库剩 3。另加真实动力燃料，选择 R3013 补工作液 3 / 净水 1，14 秒增压消耗 280 kJ。液压动力管接到 M22 后可供能；拆除 M21 仅返还真实 medium 和未燃烧燃料，不把余能逆转成燃料，不能靠重装获得额外工作液。
6. 干净电网只放 M28、能量线缆、普通储能箱；给 M28 添加 1 u 液体燃料，第一个 tick 最多以 100 kJ 输入充电，电池增加 88 kJ、发电机余能 6,300 kJ。停发电后不再增加电量；接真实负载才放电，不能互充 / 同刻充放。
7. 改为只充、只放、保留模式；保留电量只有优先级 1 负载可用。普通 / 高密度容量为 15,000 / 30,000 kJ，上限不溢出；满电不继续空耗燃料。移动电池保留电量，拆除仅回收设备，重装不保留电量。
8. 生产机左右各接一个彼此隔离的电缆网，仅一边有发电机；自动按东/南/西/北选侧，手动指定另一供能侧后才改变来源，不能用机器桥接独立网。刷新 / 云存档往返保持工作能量、电量、舍入余数和启动工作液；断线暂停仍生效，正常后台继续生产。

## 4. 本机保存与暂停

1. 建造、移动、旋转和删除后刷新，编辑结果保持；正常生产至少 5 秒后刷新，恢复最近本地保存。
2. 关闭游戏，等待一分钟后重新打开；tick 与数量从保存位置继续，不增加一分钟收益。
3. 切到其他标签页或最小化后等待，再返回；工厂继续正常后台生产，恢复画面显示最新状态，不补播旧物流。关闭 / 休眠 / 浏览器冻结不属于本轮挂机目标，仍无离线补算。
4. 游戏已载入后断开网络；页面应暂停并保留工厂。恢复网络后经心跳校验继续，不补算断网时长。
5. 在浏览器 Network 中只让云上传失败，保留心跳成功；本机生产不受失败影响，显示备份失败并后续重试。
6. 限制网站存储导致写入失败时，显示本地保存失败并暂停；恢复存储能力后通过“存档 → 重试本地保存”恢复。损坏存档不能静默清档。

强制终止浏览器可能丢失最近未完成保存的少量进度；不承诺关闭事件必定执行。

## 5. 单槽云备份与换设备

1. 打开“存档”，确认本机 / 云端时间和“有新进度”。点击“立即上传云存档”，显示成功时间。
2. 修改工厂后再次上传；服务端仍仅有一个云存档，后一次覆盖前一次。
3. 持续前台联网游玩 30 分钟，确认自动备份；生产中的快照请求不再每秒发到服务器。心跳约每 10 秒一次且不含工厂状态。
4. 换另一个浏览器 / 设备登录，默认恢复最近成功上传的工厂；未上传进度不能在新设备恢复。
5. 新设备登录后旧设备在下次心跳失败时返回登录。旧设备本地数据保留，不能再上传。检测有轮询延迟，Worker 在线许可最多 30 秒。
6. 另一设备上传更新后回到原设备重新登录：本机与云版本不一致时暂停，出现选择入口，不应静默覆盖。
7. 选择“保留本机并覆盖云端”则明确以本机替换唯一备份；选择“恢复云存档”需确认后以云状态替换本机。
8. 手动恢复时取消确认，本机保持。上传进行期间继续生产，上传响应到达时 tick / 库存不能倒退。
9. 上传成功后清除该站点数据，再登录可恢复云备份。仅有本机进度且从未成功上传时，清除网站数据将无法恢复；请先上传后做此验收。
10. 同一浏览器另一页面重新登录后，旧页面不能借用新 Cookie 延续旧游戏会话。
