# 用户启动与验收

本轮不代启动服务或执行测试；以下命令和浏览器验收由用户完成。原有账号和工厂无需重建。

## 1. 启动

仓库根目录运行：

```bash
npm run dev
```

打开 <http://127.0.0.1:5173>，登录原账号。首次升级自动执行新增迁移，工厂布局和方向保持，上方出现总仓库及 Tick / 1 TPS。停止用 Ctrl+C。

## 2. 最简入库链

清出 (−2,0)、(−1,0) 两格，中心 (0,0) 为 Bus，放置：

```text
MIN(-2,0) → OUT(-1,0) → BUS(0,0)
```

OUT 为 0° 向右。矿机每秒产出 1 铁矿，OUT 每秒转移一件，上方铁矿数量持续增加。点击 OUT 核对“来源 / 目标”；IN 替换 OUT 也应正常工作。退出放置模式后点击机器才能查看其库存。

## 3. 完整生产线

清出 y=0、x=-10～-1（可将已有建筑移到其他位置；拆除会回收内部物品）。所有端口和传送带均为 0° 向右：

| x   | 建筑           |
| --- | -------------- |
| -10 | 采矿机 MIN     |
| -9  | 物品输出口 OUT |
| -8  | 传送带 BELT    |
| -7  | 物品输入口 IN  |
| -6  | 熔炉 FUR       |
| -5  | 物品输出口 OUT |
| -4  | 传送带 BELT    |
| -3  | 物品输入口 IN  |
| -2  | 装配机 ASM     |
| -1  | 物品输出口 OUT |
| 0   | 原有中心 Bus   |

```text
MIN → OUT → BELT → IN → FUR → OUT → BELT → IN → ASM → OUT → BUS
```

可用图鉴连续放置，再点相同类型或 Esc 退出。观察：

- 约 1 秒矿机产出，矿石图块进入第一条带；每条带走一格需 1 秒。
- 熔炉输入仅铁矿石，4 秒产生 1 铁板；装配机输入仅铁板，8 秒产生 1 齿轮。
- 选中机器，输入 / 产物各 4 格、每格显示数量，进度条推进、缺料时等待。
- 从空库存开始整条线约 15 秒送出首个齿轮，此后受装配机瓶颈约每 8 秒一个；接线时间、轮询和首次供料会影响首件观察时刻。
- 点击 Bus，齿轮累积在上方总仓库。矿机与熔炉速率更高，上游库存逐渐积累属正常。

## 4. 白名单

在空地搭 `MIN(2,2) → OUT(3,2) → ASM(4,2)`，OUT 向右。OUT 应显示“目标白名单拒绝”；ASM 输入不出现铁矿，矿石留在矿机产物格。将 ASM 换成 FUR 后，矿石可输入。

再将 OUT 旋转或移走，使前后为空：不应凭空生成 / 丢弃物品。IN 同样遵守目标白名单。

## 5. 堆积和容量

在空地搭 `MIN(2,-3) → OUT(3,-3) → BELT(4,-3) → BELT(5,-3)`，后方不接目标。

两条带逐渐各停 1 个矿石，状态显示下游阻塞，随后矿机产物积累。未疏通时铁矿石达到 100 后矿机停机，不能在第二格继续堆铁矿。此检查需要等待约 100 秒以上。

接通后续线路或移走部分库存建筑后，物流可继续。连续传送带同时推进，不应一刻瞬间穿过整排。分别测试右 / 下 / 左 / 上四种方向；直角转弯可以输送，面对面反向带不自动交接。

## 6. 编辑、回收和存档

- 带着库存移动 / 旋转机器，输入、产物和进度保留；已有机器仍支持 50ms 长按、右键菜单删除。
- 删除有产物的机器，总仓库增加对应数量；删除携带物品的传送带，回收一件。删除工作中的机器仅回收原料，不额外生成未完成产物。
- 关闭浏览器，保持服务运行，稍后重新登录：在线工厂应继续生产。
- Ctrl+C 停服务，再启动：库存、进度、带上物品和仓库恢复；停服期间不额外生产。
- 页面缩放 / 平移期间生产继续，滚轮和拖动不会更改库存；同向带面仍连续。
- 换另一个账号，仓库与工厂相互隔离。

## 7. 1 TPS 与平滑动画专项

1. 先 Ctrl+C 停止旧 Go 服务，再运行 `npm run dev`，页面显示 1 TPS；Tick 每秒增加一次，产量仍为矿机 1 秒、熔炉 4 秒、装配机 8 秒。
2. 点击工作中的熔炉 / 装配机：进度条与小数秒连续推进，库存数量只在服务器确认时改变。地图小进度条同样平滑。
3. 铺设至少 5 格同向传送带，观察同一个物品连续移动；密集同类物品不应反复倒退到每格起点。转弯、OUT / IN 转接也能继续显示物品。
4. 让末端阻塞：每格仍仅 1 件，物品停在格末端，不穿过下一格或凭空消失；机器满产物后进度停止，疏通后恢复。
5. 动画过程中缩放 / 平移、查看图鉴、点击不同机器：不会重启动画。移动带有物品的建筑，物品应随建筑到达新位置，不横穿整张地图。
6. 关闭服务：客户端最多补画下一刻后暂停，不持续循环假生产或增加仓库；恢复服务后重新同步。切后台几秒再回来，不应快速播放积压动画。
7. 浏览器网络面板中，工厂快照前台约每秒一次、后台约每 3 秒一次；有请求耗时则间隔更长，游戏刻由服务器独立推进。
8. 旧存档升级：库存 / 仓库 / 带上物品仍在，机器时长为 1 / 4 / 8 秒。旧进度不足整秒部分保守舍去；正常重启后不再反复取整。

## 8. 输入 / 输出动画专项（本轮）

先停止旧服务并重新运行 `npm run dev`，使 Go 端启用转移事件。无需删库或重建工厂，可直接使用第 3 节已有完整生产线。

1. 观察 `MIN → OUT → BELT`：矿石应从矿机一侧移动出来，经过 OUT，再接到传送带的平滑移动，不在带上突然出现。铁板从熔炉输出同样如此。
2. 观察 `BELT → IN → FUR / ASM`：同一个物品从带末端继续经过 IN，进入机器后缩小、淡出，不在带末端瞬间消失；输入数量按服务器确认更新，动画结束不再额外加一。
3. 观察 `ASM → OUT → BUS`，或另搭 `BELT → BUS`：齿轮 / 矿石应移动进入 Bus 后淡出。总仓库每次仍只增加实际转移的一件，动画结束不重复入库。机器经端口直接连另一机器也应有完整动画。
4. 在空地搭 `MIN → OUT → BELT → OUT → BELT`：跨第二个端口时同一物品应连续通过，不出现两份图标。将线路转向，分别核对右 / 下 / 左 / 上四个方向。
5. 让带末端阻塞，或使用第 4 节白名单拒绝布局：没有假输入 / 输出动画；物品留在来源。恢复正常接线后再继续转移。
6. 动画中缩放 / 平移、点选机器，不应重播或错位。移动 / 旋转 / 删除来源、端口或目标时，旧路线应立即撤销，后续按新布局显示；不出现悬浮残影，库存仍遵守保留 / 回收规则。
7. 刷新页面、切后台几秒再返回、断开网络后恢复：直接显示最新状态，不补播旧物流。新发生的转移继续有动画。

## 9. 霓虹画风与游戏 HUD 专项（本轮）

本轮只改前端，没有新的数据库迁移。根目录 `npm run dev` 启动后访问页面；已有服务支持前端热更新，也可重新启动后刷新。保留旧账号、工厂和产线。

1. **游戏入口**：登出查看像素标题、青 / 洋红配色、蒸汽波落日与矢量工厂。注册 / 登录仍能完成，连接状态可重连，“连接详情”能查看原有健康信息。登录后进入地图 HUD，而不是一大页账号表单。
2. **桌面布局**：资源位于顶部，图鉴 / 棋盘 / 检视固定三栏；工作台外框为 16:9、宽约浏览器的 90%、最小 1200px。窄窗口横向滚动查看三栏，详见第 11 节。
3. **建造热键**：按 `1–6` 选择对应建筑，同键再按取消；配合 `R` / 右键旋转、左键连续放置、`Esc` 退出。用户名、密码、昵称、工厂名称输入框中输入数字或 F 不会触发建造 / 沉浸；Ctrl 等组合键也不触发新快捷键。
4. **沉浸视图**：选中建筑并旋转预览，按 `F` 或按钮收起侧栏，资源 HUD 与当前工具保留；数字键仍可切换。再次 `F` 恢复，地图中心的世界位置保持，布局 / 物品不变。在沉浸前后缩放、平移、放置，落点应准确。
5. **原交互回归**：已有建筑长按 50ms 可移动、右键可旋转 / 删除；拖动空格平移的同时滚轮缩放仍自然。青色角标标记已选建筑，青 / 红预览标记有效 / 无效落点。空格按钮和地图容器不会出现此前移除的焦点高亮框。同向带保持连接。
6. **生产与节能**：完整产线上观察新图标、库存格、进度条和端口转移动画。普通模式保持平滑；开启节能后动画会明显降低绘制频率、背景减弱，矿机 / 熔炉 / 装配机仍为 1 / 4 / 8 秒，库存与仓库只由服务器结算。开关不重置进行中的进度；刷新或重登后节能选择保留。没有手动设置时，系统减少动态效果偏好默认启用节能。
7. **玩家与指南**：点“玩家档案”查看用户名并修改昵称；点外部关闭，或 Esc 关闭并回到触发按钮。操作指南同样支持外部 / Esc 关闭；先关闭弹出层的 Esc 不应顺便取消正在使用的建筑工具。成功提示几秒后自行消失，登出仍有效。
8. **挂机与性能观察**：浏览器网络面板中没有外部字体 / 背景视频 / 粒子资源请求，工厂读取仍约前台 1 秒、后台 3 秒。暂停可工作产线或使其完全阻塞，待转移动画结束后不应有装饰动画持续跑帧；切后台后暂停绘制，返回不补播积压。可分别观察普通 / 节能模式的浏览器性能面板，再反馈实际设备体验。

设计和性能策略见 [visual-style.md](visual-style.md)。实际排版与实机功耗未由 AI 浏览器验证，请将体验问题和窗口尺寸一起反馈。

## 10. 字号与固定棋盘专项（本轮）

启动仍为 `npm run dev`，已有前端支持热更新；直接刷新原账号和工厂，无新迁移。

1. 查看入口、注册 / 登录、连接详情、玩家档案、资源、快捷键、图鉴、检视、配方、库存、右键菜单与鼠标预览，中英文应至少 12px，不再依赖微小文字。小屏下文字可换行，不应为了放下而缩小字号。
2. 同一窗口下反复切换建筑 / 物品、依次选择矿机 / 齿轮 / Bus / 熔炉，工作台和中央地图宽高应完全一致；右侧详情独立滚动，不会挤压棋盘。也检查页面滚动条出现 / 隐藏时不横向跳动。
3. 16:9 现在指整个 factory-workspace（含顶部 HUD、三栏与底部操作条），内部可操作地图填充中央区域。尺寸与三栏专项按第 11 节验收。
4. 按 F 进入 / 退出沉浸：图鉴与检视收起，工作台宽高保持，棋盘横向扩展，相机世界中心、所选工具和方向保留。切 Tab 不应触发相机尺寸校正。
5. 以 50%、100%、125%、300% 缩放查看：保留的坐标至少 12px；低于 100% 只显示每 5 格的主要坐标，不显示建筑文字代号，鼠标提示及检视仍可识别名称。100% 起正常显示 MIN 等代号，传送带在所有倍率都不显示 BELT。建筑放置、拖动、旋转和滚轮平移坐标继续准确。
6. 运输中的物品改用矿石 / 板材 / 齿轮图形，沿用同一物品身份与轨迹；输入 / 输出 / 入库动画仍连续，不出现重复图标或重复结算。
7. 可运行 `npm run lint` 检查字号规则和类型；源码中新添低于 12px 的 font / font-size 或字面量 fontSize 会被拒绝。实际排版由用户浏览器验收。

## 11. 固定工作台与右侧检视专项（本轮）

在根目录运行 `npm run dev`，访问 <http://127.0.0.1:5173>；若服务正在运行，刷新页面即可。没有新迁移。

1. 浏览器页面缩放为 100%，检查 `.factory-workspace`：宽度为 max(90vw,1200px)，高度为宽度的 9/16。例如 1920px 窗口约 1728×972px，窄窗口最小 1200×675px；顶部网站 / 玩家条不计入此比例。
2. 确认左侧建造阵列、中央产线现场、右侧模组检视始终同一行。扣除两个 16px 栏间距后，三栏约为 18%、58%、24%。窗口窄于 1200px 时页面可横向滚动，检视不会移到下方。
3. 反复切换建筑 / 物品 Tab，选择配方长短不同的对象、点击已有熔炉查看库存并滚动检视。工作台、三栏和地图可操作区域宽高应保持；图鉴 / 检视的滚动互不影响，长内容都可到达。
4. 连续放置矿机 / 传送带、取消、选中机器、拖动机器，检查提示文字变化时地图高度不变。按 F 来回切换后外框宽高仍保持，恢复正常三栏；放置、拖动、右键删除、平移同时滚轮缩放的落点正确。
5. 四个方向连续铺设多格传送带，分别以 50%、100%、125%、300% 查看，所有带面及格内预览均不显示 BELT；连接、方向箭头和物品动画保持。图鉴 / 右侧检视仍能查看传送带名称和代号，其他机器代号保持原规则。
6. 打开玩家档案和操作指南，弹出层可操作且不改变工作台尺寸；状态同步失败、编辑报错的提示作为浮层显示，也不撑开布局。

## 12. 可选自动检查

根目录执行：

```bash
npm run check
```

包含格式 / 类型检查、前后端测试、构建、临时数据库 HTTP 冒烟。单元测试覆盖容量、时长、白名单、四向端口、阻塞、竞争、完整生产链和物品守恒；仓储 / 迁移测试覆盖重启、删除回收与旧工厂升级。本轮另补成功转移事件与过期、编辑失效、图标去重、后台恢复、四向路线，以及一个图标连续通过输入 / 输出并淡出、完成不改库存的组件测试。HTTP 冒烟包含完整生产线，等待首个齿轮最多 25 秒，因此比此前略久。

所有测试只使用内存或临时数据库；不会修改你的游戏存档。执行结果和浏览器反馈请回传给 AI，再记录到 progress.md。
