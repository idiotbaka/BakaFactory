# 仓库终端与厂区 IO 升级

本功能解决单座 WH 的接口数量限制，不改变地图尺寸、带速或燃料。WH 已支持移动，新增终端围绕其当前位置寻找空格；已有终端独立保留原位置，见 [工厂仓库移动](warehouse-move.md)。所有终端访问主厂 `simulation.warehouse` 唯一总账，分厂不保存库存副本。

## 任务

P2“舱门过于拥挤”（`p2_crowded_hatch`）推荐顺序在“格雷科技的微笑”之后，不要求先领奖前一任务。新目标 `submit_items` 要求一次提交基础铁板 50、铜条 50：持有材料不会自动完成，点击“提交材料”后 Worker 在世界克隆内实际扣收并记录完成，不足或重复提交不改原档。随后单独领取奖励，解锁各厂 IO 升级与五页剧情。本任务和“第一位会走路的帕鲁同事”在阶段标签左侧显示粉色“关键任务”。关键标记不改变终局规则。

P2 现为 19 项普通任务和 1 项终局，半数门槛变为 10/19；已领奖终局和已有阶段不回退，不自动补交材料或代领奖。

## 配额、费用和安装

厂区每张卡显示本厂两类终端的已安装数量 / 当前上限，每次付费增设一个终端，配额独立。下表为累计上限，费用按购买时当前阶段计算，含后期补买的名额。

扩建表单位于最上方，下面每行固定两张精简工厂卡，使用 Tag 展示终端数量和当前 / 起始厂，不显示 tick。点击厂名切换，卡片内“改名”预填对应厂名称。点击两类升级按钮打开说明弹窗，展示终端图标、升级前后数量、费用和当前库存，并提示自动创建在本厂空格内、可自由拖动；确认安装才提交原 WorldAction，取消不扣材料。原生 modal dialog 提供焦点约束、关闭后返回按钮，并隔离背景建造快捷键。

| P2       | 2        | 1        | 基础铁板 30  | 铜条 30       |

达到上限的卡片升级按钮禁用；缺材料时仍可查看升级说明，但弹窗的确认安装按钮禁用，Worker 再复核。安装从 WH 附近确定性搜索空格，排除完整建筑占地、机器人、过境落点、施工预留及会破坏安全返站的格子；无有效空格拒绝且不扣款。原 WH 实例与四面配置保持。

## 两种设施

- `warehouse_pickup`（WOUT / 取货终端）：单格、单朝向，每秒最多 1 件，配置 1～2 种互不重复的固体。初装默认选择垃圾包并暂停，选好物品后启用。可长按移动 / 旋转，不可删除，不能从图鉴或机器人施工免费安装。
- 取货可直接交给前方相邻带、箱或配方原料缓存，也可由正前方投料机提取。两物品从 `terminal_cursor` 开始尝试，缺货、目标过滤 / 容量拒绝则跳过；成功后游标移到成功物品下一槽，失败不推进。不接收物料，不从侧面 / 后方取货。
- `warehouse_intake`（WIN / 存入终端）：单格，无方向箭头，四面经既有固体物流接货后直接入总仓库，无独立库存，不向外出货；可移动、不可删除。实际入库更新自动入库账本，手动 / 拆迁 / 退款仍不计任务进度。
- 无现场能耗、不桥接能源网络、不新增计时器。取货最多行动一次，先预留库存 / 容量及带占用依赖，再统一扣收；只有成功提交才生成 transfers 动画收据和推进游标。
- 本轮仅固体；流体继续使用原 WH 和管网。机器人端点继续使用原 WH、机器和容器，不扩展任务 / 寻路规则。

## 存档、美术与边界

升级情况从本厂终端实例数派生，不重复保存等级和库存。客户端 / Go 校验配额、阶段、领奖、1～2 固体配置、轮询游标及终端空缓存。旧档无终端即零级，不赠设备、不重建地图，不改格式 / 规则版本或数据库迁移；协议由 OpenAPI 生成。

两张透明像素机壳按 128px / 64 逻辑格、黑边和有限颜色接入原建筑资源；机壳保持正视，取货用代码方向箭头，存入无箭头。五张漫画引用既有角色生成，正文单独渲染。提示词与资源处理说明见 `output/imagegen/p2-hatch-v1/`，剧情生命周期见 [stories.md](stories.md)。

## 用户验收

### 厂区页精简布局（待用户执行）

1. 查看“舱门过于拥挤”奖励，确认第二行显示“（完成后，可以在厂区页面中对工厂安装新的存入和取货终端）”。
2. 打开厂区，确认扩建表单在最上方、当前厂数 / 上限清晰；下方固定每行两个工厂，卡片使用终端 Tag，无 tick、重复说明或底部阶段长列表。窄窗口仍为两列，长厂名 / 数量自然换行，工作台与地图尺寸保持。
3. 点击另一厂的“改名”，确认预填的是该厂名称，修改并保存只更名该厂；空名不可提交，取消 / Esc 不更名。点击厂名仍可切换。
4. 点击取货 / 存入升级，确认对应厂名、类型、费用和库存，以及“自动创建在工厂内、可以自由拖动”的提示。取消不升级；材料不足不能确认，配额满时卡片按钮不可升级；确认后对应厂 Tag 更新。
5. 对话框内 Tab 不离开弹窗，改名可输入 F / R / 数字、删除文字而不触发地图操作；关闭后焦点返回原按钮，正常 / 节能模式无新增装饰动画。

### 功能与存档

1. P2 任务页检查新任务顺序、两项关键标签；少一件材料不能提交，补齐后只扣两种各 50，重复操作不重复扣款。未领奖不开放升级。
2. 领奖自动播放五页剧情，完成后支持重放；播放中刷新保留待播，历史读取 / 云恢复不伪造新领奖事件。
3. 两个厂分别升级，核对独立配额、当前阶段费用及真实实体。P2 达到 2/1 后不能再升级，P3 / P4 上限为 4/2、6/3。
4. 满地图或无安全空格时升级失败，库存 / 实体数不变；不覆盖多格建筑、机器人、落点或蓝图。
5. 取货选两种固体并启用，观察交替输出；耗尽一种仍输出另一种，补回恢复。目标过滤 / 满载时不扣错物品；侧面不能取货，移动 / 旋转后不重播旧路线。
6. 四面向存入终端送固体，核对唯一库存与自动入库统计。多个厂争用最后一件只能成功一次。两种终端均可拖动，工具栏、右键、Delete 均不能删除。
7. 刷新 / 云恢复核对位置、数量、朝向、配置与轮询状态；查看正式贴图、取货方向、存入无箭头，确认固定工作台与最小 12px 保持。
