# 机器地图简称

地图缩放达到 **120%** 时，仅“建筑”Tab 中的机器在格子下半部显示以下简称；物流始终不显示，传动轴、线缆、液压动力线、仓库、电池及补给设施等非机器同样不显示。机械分流器 m17 虽为 machine 定义，但按现有图鉴归物流，因此只保留命名设计，不在地图显示。当前 58 个机器定义均有独立简称，实际显示范围为 57 种，含 3 种旧档机器。

## 显示边界

- 简称最多三个汉字，不截取字符串猜测名称；原名三字以内的保持原名。完整名称、目录编号、提示与检视不改，不写入玩法定义或存档。
- 使用独立于地图 scale 的屏幕坐标图层，固定 12px Fusion Pixel Regular / 16px 行高，不将文字压到小于 12px；120% 时每格约 36px，三个汉字按原生 12px 绘制，不压缩文字。阈值与工具栏四舍五入后的百分比一致，避免显示 120% 却没有标签；标签沿相机平移 / 缩放重新定位，在该显示阈值以下整体不渲染。
- 白色文字、2px 工厂地面色描边（--factory-floor-color，默认 #0e1425），先描边再填白字；位置在格子高度的 72%，避开顶部方向 / 状态和底部生产进度条。不新增背景卡片、持续动画或 RAF。
- 已放置、放置 / 移动预览共用简称与定位。预览在有效地图格内时显示，非法目标同步降低透明度；移动隐藏源标签，目标已有标签让位，避免文字重叠。标签层 aria-hidden / pointer-events:none，不覆盖原按钮完整名称或拦截编辑手势。
- “适应地图”和“居中放大”沿用原缩放规则（后者为 125%），低于 120% 的适应视图隐藏简称；居中放大恢复 125% 后显示。

## 维护与验证

客户端显示映射为 apps/web/src/game/machineMapNames.json，machineMapNames.ts 根据 category=machine 与 isLogisticsBuilding 双重筛选；MachineNameLayer.tsx 位于地图视口内、地图缩放容器外，与 FactoryEditor 相机及预览同步。scripts/check-building-art.mjs 已纳入完整映射 / 一至三汉字 / 无重名检查，未来新增或更名机器需维护映射与本表。

已补完整分类 / 简称、120% 阈值、屏幕定位 / 平移、移动与占格预览去重、滚轮 / 适应地图 / 居中恢复测试代码。按仓库约定未执行应用自动 / 浏览器测试；由用户运行：

```bash
npm run test --workspace @bakafactory/web -- src/game/MachineNameLayer.test.tsx src/game/FactoryEditor.test.tsx
```

实际验证状态见 progress.md，手动步骤见 acceptance.md。刷新前端即可，无需修改存档或重启 API。
