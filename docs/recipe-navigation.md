# 图鉴筛选与物品来源导航

## 布局

- 建造阵列外层为固定高度 Flex 列。`catalog-controls` 包含标题、建筑 / 物流 / 物品、搜索和阶段，保持在上方；`catalog-scroll` 独立滚动列表与脚注。滚动槽只在内容区预留，不改变固定三栏和地图尺寸。
- 工作室 `workshop-controls` 将六种手工设备和搜索并排，以 Flex 自动换行。搜索在设备右侧，空间不足时另起一行；整组沿用中央滚动区吸顶，垃圾堆保持普通文档流。仓库搜索位置保持。
- 不增加依赖、滚动事件监听、持续绘制或动画；所有文字至少 12px。

## 信息浮卡

共用 `ItemInfo` 浮卡继续通过 Portal 定位于物品名称附近，宽度最多 420px、高度最多 600px 且受视口限制；标题 / 关闭按钮常驻，正文独立滚动。

物品说明和简洁属性之后，每个来源配方独立成卡：名称及阶段 / 编号、每批原料、箭头、每批产物、加工设备 / 设备用时与功率。物料使用现有像素图标、可点名称和数量，自动换行；工艺说明默认折叠，删除重复的工作室耗时折算段落。阶段、首次制造里程碑与真实作业凭据仍明确显示。

## 工作台合成

仅六种手工设备对应配方有入口，沿用 `workshopMachineAvailable`、当前阶段与配方 `gate`。未开放时禁用并显示原因；不是工作室配方时不提供入口。不把原料不足、暂停或队列忙碌当作导航限制，实际加工仍由工作室表单与 Worker 校验。

`ItemInfoProvider.onWorkshopRecipe` 将稳定配方 ID 交给 `IndustryViews`：

1. 再次核对设备 / 阶段 / 里程碑，关闭浮卡和仓库订单预览。
2. 清空现有搜索、切换工作室主视图及对应手工设备，保留已填写的各配方批数。
3. 待目标 DOM 挂载，用吸顶栏实际高度计算中央内容区滚动位置，聚焦配方卡并显示静态焦点边框，支持重复跳转同一配方。

整个过程只改变页面状态，不提交合成、不扣原料、不改任务 / 制造记录 / 存档。切厂不会继续执行旧厂的定位请求；页面滚动位置不跟随改变。卡内点材料继续替换单张浮卡，关闭 / Esc 的焦点恢复和外部点击退出沿用原行为。

## 代码与验证

- `apps/web/src/game/FactoryWorkspace.tsx`、`factory.css`：固定图鉴区、独立滚动及工作室工具栏。
- `apps/web/src/game/ItemInfo.tsx`、`ItemInfo.css`：配方展示、权限提示及导航入口。
- `apps/web/src/game/IndustryViews.tsx`：主视图、设备、搜索、配方定位与焦点。
- `ItemInfo.test.tsx`：跨视图 / 重复导航、搜索清空、吸顶高度偏移、无加工副作用与逐项权限；`IndustryViews.test.tsx`：工具栏包含搜索及垃圾堆不吸顶。测试代码已补，执行由用户负责。

用户可运行 `npm run test --workspace @bakafactory/web -- src/game/ItemInfo.test.tsx src/game/IndustryViews.test.tsx`。真实布局、吸顶 / 换行及焦点可见性需按 [手动验收](acceptance.md#图鉴固定筛选工作室搜索与配方导航待用户执行) 检查；静态类型和 DOM 用例不能替代实际浏览器验收。
