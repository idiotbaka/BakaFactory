# 流水线机械手与仓库递归下单

## 范围和阶段

本轮按用户新增需求实现，不恢复旧开发路线。四个可审查阶段：

1. 任务 / 目录：在 p1_feeder 后追加 p1_warehouse_delivery 与 p1_free_hands；I0060 / R1040 保持编号，物品改名流水线机械手，领取后一并开放 P2 与下单。
2. 本地规划与运行：工作室可用配方递归、整批进位、库存预留、订单私有物料、串行加工、完成 / 取消回收和两端存档校验。
3. 界面：仓库零库存可下单物品、图标顺序计划、大弹窗、缺料 / 消耗 / 全部最终产物、顶部机械手进度。
4. 验证与记录：补真实事件 / 物料守恒 / 读档和交互测试代码，执行导入、类型生成、格式化、lint / go vet 与编译；自动测试和浏览器游玩由用户执行。

以上实现及测试代码 / 验收文档均已接入；实际静态检查结果见 progress.md。自动测试和浏览器游玩尚待用户执行，不能将编译结果视作测试通过。

## 任务与解锁

开发测试例外：诊断右侧的开发者工具可开启“仓库下单始终可用”。默认关闭，随行业存档保存；只绕过下单的领奖条件，不替代 P2 门槛、配方 / 设备解锁或材料。未领奖且在执行订单时，完成 / 取消后才能关闭，正常已领奖玩家可随时关。其余规划 / 消耗 / 工时 / 取消规则与正式订单相同。

- 自动化入库只记录固体物流、流体物流或机器人正常卸货实际成功进入任意 WH 的数量。失败 / 堵塞 / 手动收取 / 手工生产入仓 / 取消退款不算；各厂事件合并到主厂 quests.automated_received，旧历史无证据不补造。
- p1_warehouse_delivery 奖励手摇传送带 20、分拣料箱 6、初阶自动投料机 6；按已有开放任务流程手动领取。
- p1_free_hands 要求真实制造 I0060，不以持有或奖励代替制造。它是 P1 终局任务，先完成另外 8 项中的至少 4 项才开放，已达成未领奖也计数；制造记录与里程碑先保留，领取机制奖励后才解锁仓库订单和 P2；设备本体不额外消耗。P2～P5 同样由各自终局任务领奖推进，不能只制造里程碑跳阶段。
- 旧版本已经处于 P2 以上且尚无 automated_received 字段的存档，读取后补认该机制奖励，保留既有阶段，避免降级 / 锁住现有设备；不补领第一项物流物品奖励，不重播旧任务通知。阶段仍在 P1 的旧档按新任务规则推进。

## 规划规则

订单数量表示本次新增目标生产量，已有同名成品不会抵扣，也不作为本订单的原料。优先使用计划已产生的中间物料 / 副产物，再用起始仓库现有材料，最后递归补制缺量。每道配方按整批向上取整，例如每批 3 个、下单 5 个实际制造 6 个，多余量完整保留。

只使用当前阶段 / 里程碑及六类工作室首次制造权限已经开放的配方，不自动调用熔炉等地图设备，不提前借用订单未来才解锁的配方，不自动拾取垃圾。多个来源按目录顺序搜索可行组合，有限回溯；不承诺全局最少原料 / 最短时间。欠缺的垃圾包、地图材料或循环所需种子材料在预览中列出，不能确认缺料订单。

单次目标 1～1000 个，最多 256 道分组工序、10000 批，每道分组最多 100 批；递归深度 32、访问预算 3000。过于复杂时提示减少数量或预备中间材料，不无限递归。预览显示顺序、工时、预留仓库材料、最终交付的所有成品 / 副产物和缺量；“最终交付”不重复列出被后续工序消耗掉的中间物品。

## 预留、运行和回收

下单只在起始厂执行，其他厂不免费跨仓。Worker 重新计算计划并对照确认签名；库存变化导致消耗 / 顺序变化时拒绝旧预览，要求重新确认。签名仅用于确认一致性，不替代服务端身份和存档验证。

确认时一次从仓库移走计划需要的现有材料，进入订单 inventory。工序按已有手工耗时（原秒数一半向下取整、至少 1 秒）逐批推进，每批完成才从订单内扣该批原料、加入真实产物，并记录制造 / 手工批次。中间产物保留在订单内供后续使用；最终整批完成时全部转入起始仓库。订单和普通手工队列互斥，不额外建立并行工作室。

取消只退回订单当前 inventory，即未用原料和已经制造但尚未消耗的中间件 / 副产物；已投入成品的原料不再返还，未完成当前批没有产物。工作室仍可在顶部取消；暂停时不可操作。计数 / 最终入仓溢出时等待，取消退款溢出也整笔拒绝，保留订单供腾仓后重试。

订单随完整 IndexedDB / 云备份及行业增量帧保存。客户端和 Go 校验目标 / 配方 / 阶段 / 工作室权限、工序指针与当前批次一致，并从私有库存虚拟重放全部剩余配方检查不缺料、不溢出；读取不结算产物。沿用现有存档版本，无数据库迁移。

## 用户验收重点

在起始厂真实完成两项任务并领取；确认新进度制造 I0060 后仍为 P1，领奖才变 P2。放入 WH 的手动收取不能完成物流任务，堵塞也不能完成；真实带 / 投料或流体 / 机器人卸入任意厂 WH 才能完成。

解锁后仓库显示当前工作室能制作的零库存物品；订单数量 5、每批 3 的配方显示实际 6。准备中间材料和从垃圾包起步分别预览，检查缺少地图生产材料时不能下单。确认后材料离开仓库且普通工作室锁定，顶部显示机械手、当前工序 / 批次；正常暂停 / 后台规则保持。逐步取消、刷新、云恢复，核对只退订单当前实物且不重复产出。大弹窗支持外部 / 关闭 / Esc，键盘焦点留在弹窗，输入数字不触发建造快捷键；固定工作台和 12px 字号保持。
