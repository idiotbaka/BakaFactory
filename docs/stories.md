# 剧情漫画与重放

新增章节“P2 前期：舱门过于拥挤”（`p2_crowded_hatch`）：实际提交基础铁板 / 铜条各 50 并领取同名任务奖励后自动播放，提交但未领奖不播放。五页分别为“工厂很大，门口很小”“生物炭走贵宾通道”“再开一间，问题再来一遍”“给仓库申请几张嘴”“嘴可以多长几个”，批准台词原样保存于 `stories/p2CrowdedHatch.ts`。五张正式漫画位于 `apps/web/src/assets/stories/p2-hatch-v1/`，使用原 P1 / 开场 BAKA-01 造型参考通过内置 imagegen 逐张生成，提示词见 `output/imagegen/p2-hatch-v1/prompts.json`。复用既有领奖差分、观看记录、刷新续播、重放菜单、焦点和打字框架；首次读档 / 云恢复不伪造新事件。

## 当前流程

登录与本机 / 云工厂读取完成后，若账号当前没有工厂且本机未记录开场已观看，在首次工厂命名界面自动打开“开场：下班计划开启”。按确认后的交互，看完末页点击“完成”，先保存观看记录再返回命名表单；玩家继续修改名称、手动点击创建工厂。播放本身不建厂、不提交默认名称，也不发放物品。已有工厂的玩家不强制观看，加载 / 登录未确认、读取失败或云冲突时不抢先弹出。

五页依次为：一笔成功的生意、员工已经安排好了、一次积极的招聘尝试、同事可以自己制造、一份认真的下班计划。使用已确认的五张手绘漫画原图和定稿段落，描述地球垃圾合同、BAKA-01 的晋升 / 招聘、制造同事与下班目标。

真实领取 `p1_free_hands`（“是时候解放双手了”）后自动播放五页“P1：工厂开饭了”：零件里面，怎么还有零件；给双手补上一点工作经验；毕业作品，被归进了原料区；大机器没有小胃口；工厂开饭了。每页使用用户定稿的五行正文，前两页展现机械手发明，后三页从零件成果转向 P2 量产与厂房规划。小视口允许自然换行，不缩小字号。

触发来自运行时对确认快照中 claimed 的新增判定，不使用当前阶段、任务完成但未领奖或开发者开关作为替代。首次读取 / 旧 P2 自动兼容 / 云恢复只建立基线，不冒充新领奖。领奖和待播放编号写入同一完整本机记录；播放中刷新后从第一页恢复，完成记录提交成功后才关闭，观看失败保留弹窗供重试。存档冲突处理完成前不抢先播放。

底部“操作指南”左侧为“重放剧情”，沿用向上展开的 HUD 弹出层：开场始终可重放，P1 章节在该奖励已领取后显示，包括已完成 P1 的历史存档。点击条目收起列表，从第一页重新播放，关闭后焦点返回入口。重放可随时用关闭、Esc 或点击遮罩退出；首次自动播放通过末页“完成”结束，不把 Esc / 刷新 / 中途翻页算作观看完成。剧情不额外暂停已运行工厂，生产仍由原在线许可 / 可见性规则控制；画面里的打盹不代表新增离线收益。

## 播放器与可访问性

- 上方完整配图、下方段落，弹窗最大宽度 960px、图片最高 42dvh，等比 contain、不裁剪；内容独立滚动，标题 / 翻页按钮保留。门户弹层不参与底层工作台尺寸，固定 16:9、18:58:24 和地图尺寸保持。文字最小 12px，正文 14px / 18px 行高，段落仅单次换行，不插空白行。
- 上一页 / 下一页支持回看；最后一页下一页变为完成。方向键或 PageUp / PageDown 翻页，键盘末页不自动完成，仍需确认按钮。保存中禁止重复完成与翻页；失败留在末页提示重试。
- 每页正文按 Unicode 字符在 3 秒内打字显示，用真实 performance 时间采样和有限定时器，普通 / 节能最多 30 / 15 次每秒更新；不新建 RAF，不借用工厂 tick。文字完成或关闭 / 换页时清理定时器；回看重新计时，后台恢复仅让文字完成；文字计时不驱动工厂，工厂后台由 Worker 正常推进。
- 透明预留完整文字高度避免打字时布局跳动，不再提供显示全文按钮。屏幕阅读器读取静态全文，不逐字播报。弹层约束焦点与背景 inert，隔离底层 1～6 / F / R / Delete / Esc 等编辑快捷键；浏览器组合键保留，关闭恢复焦点和页面滚动。
- 图片在实际展示时加载，只预取下一页；其余原图不在登录时批量下载。图片加载失败保留替代说明和文本 / 翻页，不阻止观看。

## 观看记录与边界

`LocalRecord.viewedStories` 与 `pendingStories` 是可选、按 owner 隔离的 IndexedDB 展示元数据，与工厂完整存档使用同一记录和串行写队列。建厂前 save 可以为 null，仍能保存开场完成；P1 的待播放事件随领奖状态原子写入。只有事务成功后才发布已观看状态并移除待播项，失败不会关闭首次播放器，重试可以恢复；普通运行快照不会提前关闭尚在保存的剧情。

两数组去重、各最多 1000 个长度不超过 128 的标识符；旧记录缺省空列表，保留符合格式的未来 / 退役 ID。完成观看不改 Worker 世界、revision、库存、任务或云版本。字段不是 GameSave 游戏数据，不随云备份传输；本机云恢复保留观看历史，并清理已观看或被恢复进度撤回解锁条件的待播项。换浏览器 / 清缓存后恢复已有工厂不强制播放历史章节，已领奖章节仍可从重放菜单查看。
