# 剧情漫画与重放

## 开场五图与 09 号角色

“开场：下班计划开启”五页使用 `apps/web/src/assets/stories/opening-ai09-v1/` 的独立 PNG，统一 384×360。第 1、2 页沿用用户确认的 method B / protected skin palette，已核对像素一致；第 3～5 页通过内置 imagegen 以第 2 页约束角色与画风，基于旧版招聘 / 制造同事 / 下班的核心内容重新构图绘制；第 3 页为侧面看终端，第 5 页从背后望向落日，避免连续正脸。图内不放正文，以图标表达信息，仅保留制服 `09` 和招聘数字 `0`。

角色设定为 09 号具身 AI：蓝色短发、粉色发卡、半睁蓝紫眼、灰色宽松制服与编号胸牌，仿生身体和人形双手，耳侧 / 手腕保留接口。性格慵懒可爱，会认真安排工作，好让自己安心下班。与地图中按任务工作的工具机器人区分；最终目标仍是制造能独立判断并接班的 AI 同事，不改变智能机器人解锁或自动作业权限。

后处理为中值去孤点、BOX 缩图、饱和度乘 0.60、亮度乘 0.90、阈值锐化及无抖动 64 色限色。角色脸 / 颈 / 手局部单独保护六色肤色，后三页共用第 2 页的肤色，人物页最多 70 色，不使用 9bit RGB。游戏按像素方式缩放开场图片，原手绘章节保持平滑显示。可复用处理脚本、原始绘图、实际提示词、色数 / SHA-256 及相邻采样预览见 `output/imagegen/opening-ai09-v1/`。

开场及其他四章的角色台词、手工动力自评、P1 / P6 阶段目标和冲压机任务提示同步适配 09 号。按用户确认，其他四章的 20 张旧插画暂保留；其替代说明明确为旧版电视头造型，不把旧画误述为蓝发角色。下面涉及旧造型和画风的资源描述仅记录这些保留插图。全部旧版资源保留，不改章节 ID、任务 ID、播放条件、观看记录、存档或玩法。游戏内可直接“重放剧情 → 开场：下班计划开启”，无需清档。

## 当前流程

登录与本机 / 云工厂读取完成后，若账号当前没有工厂且本机未记录开场已观看，在首次工厂命名界面自动打开“开场：下班计划开启”。按确认后的交互，看完末页点击“完成”，先保存观看记录再返回命名表单；玩家继续修改名称、手动点击创建工厂。播放本身不建厂、不提交默认名称，也不发放物品。已有工厂的玩家不强制观看，加载 / 登录未确认、读取失败或云冲突时不抢先弹出。

五页依次为：一笔成功的生意、员工已经安排好了、一次积极的招聘尝试、同事可以自己制造、一份认真的下班计划。五页均为像素插画，正文描述地球垃圾合同、09 号的晋升 / 招聘、制造同事与下班目标。

真实领取 `p1_free_hands`（“是时候解放双手了”）后自动播放五页“P1：工厂开饭了”：零件里面，怎么还有零件；给双手补上一点工作经验；毕业作品，被归进了原料区；大机器没有小胃口；工厂开饭了。每页使用适配 09 号后的五段正文，前两页展现机械手发明，后三页从零件成果转向 P2 量产与厂房规划。小视口允许自然换行，不缩小字号。

触发来自运行时对确认快照中 claimed 的新增判定，不使用当前阶段、任务完成但未领奖或开发者开关作为替代。首次读取 / 旧 P2 自动兼容 / 云恢复只建立基线，不冒充新领奖。领奖和待播放编号写入同一完整本机记录；播放中刷新后从第一页恢复，完成记录提交成功后才关闭，观看失败保留弹窗供重试。存档冲突处理完成前不抢先播放。

底部“操作指南”左侧为“重放剧情”，沿用向上展开的 HUD 弹出层：开场始终可重放，P1“工厂开饭了”、P2“舱门过于拥挤”“机械动力，应力过载”与“第一位会走路的帕鲁同事”在各自奖励已领取后显示，包括历史存档。点击条目收起列表，从第一页重新播放，关闭后焦点返回入口。重放可随时用关闭、Esc 或点击遮罩退出；首次自动播放通过末页“完成”结束，不把 Esc / 刷新 / 中途翻页算作观看完成。剧情不额外暂停已运行工厂，生产仍由原在线许可 / 可见性规则控制；画面里的打盹不代表新增离线收益。

## 播放器与可访问性

- 上方完整配图、下方段落，弹窗最大宽度 960px、图片最高 42dvh，等比 contain、不裁剪；内容独立滚动，标题 / 翻页按钮保留。门户弹层不参与底层工作台尺寸，固定 16:9、18:58:24 和地图尺寸保持。文字最小 12px，正文 14px / 18px 行高，段落仅单次换行，不插空白行。
- 上一页 / 下一页支持回看；最后一页下一页变为完成。方向键或 PageUp / PageDown 翻页，键盘末页不自动完成，仍需确认按钮。保存中禁止重复完成与翻页；失败留在末页提示重试。
- 每页正文按 Unicode 字符在 3 秒内打字显示，用真实 performance 时间采样和有限定时器，普通 / 节能最多 30 / 15 次每秒更新；不新建 RAF，不借用工厂 tick。文字完成或关闭 / 换页时清理定时器；回看重新计时，后台恢复仅让文字完成；文字计时不驱动工厂，工厂后台由 Worker 正常推进。
- 透明预留完整文字高度避免打字时布局跳动，不再提供显示全文按钮。屏幕阅读器读取静态全文，不逐字播报。弹层约束焦点与背景 inert，隔离底层 1～6 / F / R / Delete / Esc 等编辑快捷键；浏览器组合键保留，关闭恢复焦点和页面滚动。
- 图片在实际展示时加载，只预取下一页；其余原图不在登录时批量下载。图片加载失败保留替代说明和文本 / 翻页，不阻止观看。

## 观看记录与边界

`LocalRecord.viewedStories` 与 `pendingStories` 是可选、按 owner 隔离的 IndexedDB 展示元数据，与工厂完整存档使用同一记录和串行写队列。建厂前 save 可以为 null，仍能保存开场完成；P1 的待播放事件随领奖状态原子写入。只有事务成功后才发布已观看状态并移除待播项，失败不会关闭首次播放器，重试可以恢复；普通运行快照不会提前关闭尚在保存的剧情。

两数组去重、各最多 1000 个长度不超过 128 的标识符；旧记录缺省空列表，保留符合格式的未来 / 退役 ID。完成观看不改 Worker 世界、revision、库存、任务或云版本。字段不是 GameSave 游戏数据，不随云备份传输；本机云恢复保留观看历史，并清理已观看或被恢复进度撤回解锁条件的待播项。换浏览器 / 清缓存后恢复已有工厂不强制播放历史章节，已领奖章节仍可从重放菜单查看。
