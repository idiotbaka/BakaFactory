## 通行、占格与点击

按建筑定义的 role 允许通过 belt、pipe、shaft、hydraulic_line、cable：全部地面带、地下两端、普通 / 回流 / 管道型调压阀、传动轴、液压动力线、能量线缆。地下带只是地上端口可经过，不提供机器人地下跳跃。机器、WH、终端、投料机、分流器、罐、泵、分液阀、站点和活动施工蓝图仍阻挡；机器人之间仍互斥、不交换占格。

同一通行规则用于实际 BFS、返程安全、部署、跨厂落点、编辑预览 / 原子编辑与两端存档校验。允许机器人与低矮物流重叠，也允许在机器人所在格铺设 / 移入可通行物流；普通机器和蓝图不允许占机器人格，过境及返程保护保持。蓝图即使将来完成为带 / 管 / 线，施工中也仍阻挡。

重叠时地图点击、长按和建造操作优先处理物流；机器人方向图位于独立无交互层，不盖住建筑点击。空地格仍可点击选机器人，重叠机器人可从机器人列表选择 / 定位。

## 路径与移动显示

当前厂所有有有效路段的机器人常显静态虚线，选中路径提高亮度；路径无交互。显示当前确认路段，跨厂只到当前 WH / 已确认落点，不画跨地图直线，无路、站旁待命或过境没有虚构路径。

`previewRobotRoutes` 为当前厂共用一次占格索引，运行时按完整世界快照 / 厂区缓存，选中检视复用已算路径。静态障碍格按不可变布局数组缓存。鼠标移动和 RAF 不做 BFS，不克隆世界、不广播远厂所有路径；多机器人吞吐与百厂表现仍需用户测量。

独立机器人图层按稳定实体 ID 保存轨迹，连续两个确认 tick 的相邻格在一个调度间隔内补间，不预测取货 / 卸货，也不修改真实位置、占格、库存或作业记录。复用 `animationClock` 的 60 / 15 FPS 上限，只绘制有变化的节点；没有活跃位移后停止机器人绘制。普通 / 节能按实际时间采样，开发 TPS 使用对应间隔。

重复读取或同 tick 非位置编辑不重启轨迹；初载、切厂、过境、跳多刻、长延迟、暂停和后台恢复直接校正确认位置，不补播旧移动。暂停的机器人停止位移显示，方向由确认移动增量选择，左右共用一图镜像；尚无方向时朝下。

## 美术与资源

使用内置 ImageGen 参考现有九种机器人物品图标，生成三张 3×3 图集；每行同一机型，依次为侧面、向上背面、向下正面。各图集含三个机型，共 27 个方向图。不是建筑方块图，不替换仓库物品图标。

完整实际提示词：[发条 / 液压 / 巡检](../output/imagegen/robot-travel-v1/p2-p3-prompt.txt)、[电动物流 / 两种分拣](../output/imagegen/robot-travel-v1/p4-p5-carriers-prompt.txt)、[两种维修 / 智能](../output/imagegen/robot-travel-v1/p5-p6-service-prompt.txt)。裁切后的 [九机型三方向核对图](../output/imagegen/robot-travel-v1/preview.png) 按列区分机型，三行依次为侧面、向上、向下。

- 原图及完整实际提示词：`output/imagegen/robot-travel-v1/*-source.png`、`*-prompt.txt`。
- 裁切 / 校准脚本及核对图：同目录 `process.py`、`preview.png`。
- 正式资源：`apps/web/src/assets/robots/v1/{item}-{side|up|down}.png` 与 manifest；侧面统一朝右。
- 每图 128×128 RGBA、32 格像素结构、二值 alpha、最多 16 个不透明颜色；地图按 30px 格绘制，PNG 不含文字。方向切换和左右翻转不旋转整张机体。
- `robotSprites.ts` 一次解析 URL，PNG 独立哈希发布并进入现有资源预热队列；不逐帧解码、不新增 RAF 或装饰动画。`scripts/check-robot-sprites.mjs` 接入 lint，检查目录覆盖与尺寸。

需要重建裁切时，用安装了 Pillow 的 Python 在仓库根执行：

```bash
python output/imagegen/robot-travel-v1/process.py
node scripts/check-robot-sprites.mjs
```
