# 地图拾取建造与物流原地改向

## 交互与范围

在工厂地图内将鼠标指向已安装建筑，按鼠标中键或 E（含大写）进入该类型的连续建造模式。按实际占地命中实例，2×2 的任一覆盖格均可拾取；新建预览沿用目标的朝向及占地，不复制配方、过滤、缓存或其他配置。重复拾取同一类型仍保持建造模式，不执行卡片的再次点击退出。

拾取复用建造阵列的可建造判断：仅当前阶段已解锁、非固定、非 WH / 仓库终端的目录定义可选。空格、机器人和施工蓝图不提供建筑拾取；未解锁或受保护设施显示原因并保留原工具。道具库存为零不妨碍选择，实际空地安装仍由 Worker 检查并扣收库存。

成功后清空图鉴搜索，切到建筑 / 物流对应分类及阶段，选中卡片并只滚动 `catalog-scroll`，不移动页面和地图相机。沉浸模式仍保持，退出沉浸后定位该卡片。成功拾取退出连续删除、清除框选及未完成的地下入口预览；拖动、平移、框选或编辑提交期间不拾取。输入控件、输入法组合、Ctrl / Meta / Alt、按键连发及隐藏地图不触发 E。

E 原有的多尺寸切换迁至 Q，卡片切换按钮继续保留；普通点击 / 数字键选择新工具仍默认 1×1。R / 右键旋转、1～6、F、Esc、50ms 长按移动及原有连续放置保持。

## 物流原地改向

手持地面传送带或物料管道（定义 `role=belt / pipe`，排除地下带），点击已有且 `building_type` 完全相同的方块，将该实例改为当前预览方向。例如手持初阶带朝 →，点击朝 ← 的初阶带，结果为 →。管道包括流体管道、回流管和管道型压力调节阀；动力线、投料机、分液阀、泵、储罐、机器及地下端口不参与。

目标预览沿用有效建造颜色，状态栏提示“修正方向 · 不消耗道具”。朝向已一致则不提交编辑；不同型号 / 变种仍提示占用，不替换、不升级。空格安装沿用原流程。

方向修改调用现有 `updateBuilding → move`，由 Worker 在克隆世界中串行校验并提交，不删除重建。实例 ID、位置、配置、载荷标识 / 数量 / 进度、管内介质 / 数量及总仓库保持；零库存同样可改向。成功编辑递增 revision、撤销关联旧视觉路线并按原规则保存，不产生入库或制造事件。无 API、存档格式、目录规则或数据库迁移。
