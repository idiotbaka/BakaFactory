# 自定义下拉选择

## 范围与交互设计

所有游戏选择框使用 `apps/web/src/game/GameSelect.tsx` / `GameSelect.css`。生产 / 物流 / 流体检视、WH 四面与终端、能源、机器人、蓝图、诊断和地图快捷切厂共 33 处接入，不再挂载原生 select 下拉。

收起时使用深色直角按钮、青色箭头和当前选项；物品 / 设备可显示小图标，长名称省略但保留完整悬停文本。普通字段维持约 36px 高度，地图快捷切厂保持 142×28px。展开层脱离工作台布局，在视口内按剩余空间上下展开，物品 / 配方宽度通常为 380 / 560px、整体最高 480px；窄窗口自动收缩。阶段栏、搜索和页脚固定，仅中间候选列表滚动。保持工作台 16:9、三栏比例、独立滚动和全局最小 12px。

### 物品

- 顶部“全部 / P1～P6”按物品目录 tier 精确筛选，旧无阶段物品按 P1；默认全部。
- 搜索复用 `catalogSearch.ts`，支持名称、编号、拼音全拼 / 首字母及部分内容。库存等原有附加文本仍保留。
- 每项展示实际像素图标、名称、编号和阶段。默认“任意 / 不限 / 暂不选择”等空值项保留，可在任意阶段清除过滤。
- 只过滤调用处原有候选：固体 / 流体兼容、已开放阶段、库存、机器人运载能力和终端去重规则不变。“全部”不额外开放新物品；没有结果时提示换阶段 / 关键词。

### 配方

生产机器和机器人施工配方均为一个列表，不提供阶段分页。每项展示名称、编号、配方额定秒数，以及带图标的完整 `数量× 原料 → 数量× 产物 / 数量× 副产物`；无输入显示“无原料”，不隐藏副产物。

搜索可匹配配方名称 / 编号，以及任一原料、产物的名称 / 编号 / 拼音。候选与禁用条件沿用原调用处：生产机器尚未到阶段的配方灰显不可选，蓝图沿用原阶段 / 里程碑候选范围。额定秒数直接读取 duration_ms，不混用工作室手工加成。

### 普通设置与键盘

方向、优先级、缓存目标、储能模式、间隔、厂区和设备位置使用同一紧凑列表，超过六项时提供搜索。当前值显示勾选，禁用项明确灰显，键盘导航跳过禁用项。

点击或 Enter / Space / 方向键展开；展开后 ↑↓ 导航，Enter 确认，纯列表可用 Home / End。搜索框保留文本编辑及输入法操作，阶段按钮可通过 Tab 访问。Esc 只关闭下拉并返回触发按钮，外部点击 / 焦点转移、外部滚动、窗口缩放 / 失焦关闭；列表内部滚动保持。Tab 从弹层边缘返回主页面正常焦点顺序。控件禁用时立即关闭，重新启用不会自动弹出。

展开时搜索和阶段选择不写游戏配置；只有确认不同的候选才调用原配置回调。Worker 刷新可更新候选 / 库存文本，但保留当前搜索和阶段。下拉与关闭后的触发按钮均隔离 D / Delete、1～6、R / E / F 等游戏快捷键；不引入新的快捷键绑定。

## 开发边界

`GameSelect` 接受 `catalog`、受控 `value` 和 `onValueChange(string)`，使用 `kind="item"` / `kind="recipe"` 明确丰富列表的用途；普通设置自动识别。保留现有 `<option>` / Fragment 作为声明数据，由组件读取 value / label / disabled 后转为自定义 listbox，不把这些 option 挂载到 DOM。新增下拉沿用同一组件，不创建原生 select 或通过伪造 DOM change 事件调用业务逻辑。

弹层使用 Portal，通常挂载至 body；若触发器位于原生 modal dialog 内则挂入该 dialog，避免越出模态层。定位和焦点处理使用实际 DOM 几何，不创建常驻 RAF 或定时轮询；像素贴图与拼音索引复用原资源，无新依赖。数据、产量、配方、Worker 消息、OpenAPI、本机 / 云存档及数据库不变。

现有快捷切厂和机器人运输界面测试改为真实打开列表再点击选项；`GameSelect.test.tsx` 补充物品阶段 / 编号、图片、配方整批数量 / 副产物、禁用、键盘隔离、焦点和关闭状态回归。jsdom 通过 `src/test/gameSelect.ts` 提供布局 / 滚动接口，本轮这些自动测试代码未执行。

实际静态检查与编译状态见 [progress.md](progress.md)，由用户按 [自定义下拉验收](acceptance.md#自定义下拉物品阶段与配方图示待用户执行) 在游戏中确认交互和视觉效果。
