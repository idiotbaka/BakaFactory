# 六阶段统一游玩路线

阶段推进规则更新：P1～P5 均须完成并领取本阶段终局任务奖励；终局需先完成本阶段普通任务至少一半（向上取整）才显示，P1 为 4/8，P2 为 10/19。P2 已加入百件材料制造与自动入库、轴功加工、蒸汽入储压罐、发条车运输、十区扩建和五项首造补给任务，列表与奖励见 quests.md；仍采用半数门槛，无需全部完成。首次制造终局物品仅留成果记录，达成未领奖仍留原阶段；P3～P5 暂只有原制造终局。下表持续产线和长局检查仍须实际游玩验证，P6 仍由首次制造智能机器人完成主目标。

本路线用于 A～F 开发完成后的全量游玩，未代表已经跑过一局。先运行 `npm run lint`、`npm test`、`npm run build`，按需要运行临时服务冒烟；浏览器入口为 `npm run dev`。保留原账号 / 本机 / 云存档，不清库修复。配方细节以图鉴 / 诊断与当前导入目录为准。

P1 便捷调整：在工作室选择设备子分类；首次制造简易拆解台 / 手摇破碎机 / 手工装配台后，即可直接在对应子分类批量加工其配方，不必安装并逐次投料 / 收取。仍共用一条队列，手工耗时为原配方秒数一半、向下取整且至少 1 秒（R1001 为 5 秒、R1002 为 3 秒）；地图设备保留原工时。批数超限自动回填库存上限，仅子分类滚动时吸顶，垃圾堆正常滚动；熔炼、炭化及其余高阶设备继续走地图生产，原阶段目标不变。

每阶段打开“诊断”：核对设备输入缺口与总仓库、所有产物容量、供能和训练条件；通过“物品”查看来源 / 去向与每批时间。名义产能是持续满速的配方计算值，实际制造统计是最近最多 60 个运行 tick 的世界账本差量。逐格固体 / 管线流量不能当作净产量，诊断提示不授予作业凭据。

所有厂区 WH 共用总仓库，玩家可直接在空分厂安装现有设备与补料，不再以跨区机器人作为启动前置。机器人运输 / 现场作业仍走实际路径、WH 8 tick 行程、授权、装卸及返站；检查占格、补能、满载 / 混液拒收与取消守恒，不能在携货时提前退款。具体步骤见 acceptance.md。

在未完工、携货、过境、已卸货仍返站与正在训练等状态，依次核对本机保存后刷新、唯一云备份、换端恢复及旧会话被挤出。后台 / 断网 / 休眠不追赶。恢复后行业成果、队列、库存和任务不复制；观察窗口可以重置。普通 / 节能不改变产量，切视图 / 报错不改变工作台尺寸，文字至少 12px。

发现问题时记录：阶段 / 配方 ID、所在厂和坐标、输入 / 产物 / 能量、机器人任务阶段、最近操作与可重复步骤；区分产线瓶颈、预期背压和实际守恒 / 保存缺陷。性能另按 performance.md 测量，静态闭包和编译不替代本次完整游玩。
