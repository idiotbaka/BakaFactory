# 机器占地与接口空间静态审查

> 本文保留扩容前的审查快照。后续实现已为 35 台生产候选和 M21 提供可选 1×1 / 2×2，现行行为见 [machine-footprints.md](machine-footprints.md)。

审查日期：2026-10-24。依据当前 definitions.json 的 90 个建筑、334 条配方（含 3 条旧档配方）与客户端运行代码。本报告是待确认的候选分析，**尚未实现多格建筑，也未修改配方、占地、玩法或存档**。没有启动服务或执行应用 / 浏览器测试；数字来自目录静态统计，不能当作产线布局或满速运输实测。

## 结论

- 当前所有建筑仍按 1×1 占格。BuildingDefinition / BuildingInstance 没有 footprint / 建筑宽高；实例仅有 x / y / rotation。放置校验、物料 / 能源邻接、编辑器和机器人寻路都按单格工作。现有“多格蓝图”相关规划不等于多格机器已存在。
- 新回收厂生产机器的输入 / 产物各 12 格是内部缓存，不是地图接口数量；旧档测试机器仍为 4 格。容量能装下四五种原料，不代表四个邻格能容纳所有独立线路。
- 31 条现行配方直接需要超过 3 种原料，集中在 8 台机器，最多 5 种。若还计算出料、燃料 / 能源和流体副产物，候选范围显著扩大。
- 已有机器人、手动补料 / 收取、工作室队列与混线可绕过部分接口数量限制，所以这些配方不是据此就无法运行；但现有系统没有通用的多来源投料口、叠层线路或远程无条件自动补料。

## 计入出料、流体和能源后的扩展候选

为贴近“更方便分线”的目标，采用以下统一口径，不把它当作游戏引擎的不可运行判定：

1. 每种配方原料单独一条输入线路，固体与流体都按物品 kind 判断；配方内的流体本来就包含在原料总数中。
2. 非零功率配方预留 1 个供能位置：热炉为燃料输入，轴 / 液压 / 电力为对应导线；M20 可在液压与蒸汽燃料之间选择，只计一种来源，不强制双路备用。
3. 固体产物允许共用 1 路出料（包括多个固体副产物），不同流体产物各用 1 根专管，便于分流存储。若还要求每种固体产物独立输出，需求可能更高。
4. 不额外计算机器人通道、操作余量、备用燃料或一次性启动介质接口；也不通过手动改过滤 / 改目标、轮流换液或机器人来减少预算。

因此公式为：**原料种类 + 供能位置 + 固体出料存在项 + 流体产物种类**。

特别值得优先查看的情形：

- M14 R2025：浑浊水 + 生物炭两种原料，另有专用燃料缓存，产出净化水与固体滤渣，合计 2 + 1 + 2 = 5。原料中的生物炭不会自动充当 fuel；即使两处使用同一种物品，输入缓存和燃料缓存也是两个目标。
- M20 R3007：仅一种粗裂解油输入，但运行目录将轻质烃、液体燃料、重油、油泥四种产物全部归为 fluid_or_gas，分管输出需要 4 路；加输入和供能为 6。不能按名称把油泥当成固体来漏算。
- M22 R3018：工业钢板、粗密封圈、高压工作液三原料 + 液压功率线 + 液压缸固体输出 + 污工作液管道 = 6。
- M25 R3031：两原料 + 液压功率线 + 两种流体产物 + 固体尾砂 = 6。
- M29 R4004：中性盐水一原料 + 电力 + 电解盐液 / 氢气 / 废酸液三管输出 = 5。
- M32 等三原料电力机器，即使只有一种固体产物，也需要 3 + 1 电力 + 1 出料 = 5，不能只筛“四原料”机器。

### M21 液压动力站的特殊情况

M21 属 generator，不计入上面的 35 台 production 机器，需另列。R3012 冷混配为 2 种原料、2 种流体产物、0 功率；只加工且不对外供能时四个接口可满足。R3013 为 20 kW，可在真实启动液和燃料下自供液压；若原料、燃料和两种产物流体独立接入，为 2 + 1 + 2 = 5。若还通过液压线对外供能，再加 1 个位置，即 6；独立保留启动介质注入口还会更多。

启动 medium 至少需真实 1 u 液压工作液，但不是每秒消耗的原料，可用既有手动注入或临时切换管道目标完成，不能把它一律算成永久占口。机器人普通运输任务目前没有 medium 通道；不能据可送 fuel 就宣称可自动补启动介质。

## 已有方案能解决多少

### 机器人可以共享一个可达工作面，但有前提

- P2 发条搬运车就支持显式固定取送、重复运输固体；P4 电动物流机器人等也能将原料直接写入机器 input、将燃料写入 fuel，或从 output 取成品 / 副产物。一台机器人同一时间配置一个单物品运输任务；可给多台机器人分别配置不同原料，或手动改任务，依次共享邻格，不必给每种原料永久放一个投料机。
- P3 液压搬运机器人、P6 智能机器人支持散装流体；普通电动物流机器人不因为阶段更高就能搬流体。巡检机型不等于运输机型，不能只看名字判断用途。
- 机器人在空地走格，传送带、管道、导线和建筑格都挡路；目标周围至少要有一个可达空邻格。四面全部封死后机器人也无法装卸，多个机器人仍受占格、能量、载重、装卸工时和充能站约束。
- 不保证满速：从 WH 装货仍受已配置输出面、每面 1 u/tick 与真实库存限制；没有四面封闭后隔空配送或无限吞吐。
- P6 智能机器人有“自动补料”，只补当前配方一批所缺 input，燃料和产物搬运仍走显式物流；来源只能是授权厂区中配置了该物品输出面的 WH，不会自动切换 WH 过滤。一座 WH 只有四面，五原料的自动补料可能需要不同授权厂区 WH 分担输出，或改用现有显式机器 / 箱子取送路线。
- 智能自动补料是 P6 能力，不宜作为 P1 / P2 的布线前提，也不能依赖尚未制造出来的智能机器人解决其自身首次制造链；早期运输机器人和手动批量补料可用于过渡。

### 其他现成手段

- 手动“从仓库补足原料”和收取产物不占物理输入面，支持按完整批次数补齐；它是现成的应急 / 引导手段，不是独立产线的持续自动进出料。
- M08 及其他已开放的工作室设备可走全世界唯一手工 / 机械手队列，绕过地图接线；中后期机器没有因此获得同类工作室并行队列，不能把全体复杂配方都视为已被覆盖。
- 混合固体带经投料机可输入多种所选配方原料，配合物流过滤 / 分流设施使用；散装流体不能进固体带 / 料箱。管道每节点同刻只存一种介质，轮流换液不等于独立多流体接口。
- 高阶投料臂、柔性投料节点仍是后邻格取、前邻格送，主要提高批次 / 速度；没有多来源、跨两格或绕过占格的抓取实现。

## 尺寸讨论的边界

如果以后实现每个边缘格均可接入，2×2 方形机器有 8 个四向外邻位置，3×3 有 12 个；这不是现有代码已经支持的能力。按上面的单能源 / 固体共用输出口径，生产机器最大预算为 M53 的 7，因此 **2×2 已有充分的接口数量理由，3×3 暂无配方接口数量上的硬要求**。3×3 可作为少数终局机器的视觉 / 布线余量选择，需另行权衡土地、旧布局和后续扩展。

建议确认口径后再确定改造范围：只处理 8 台四五原料机器是最小范围，但会保留三原料供电 / 多流体副产物机器的同类问题；若目标是少依赖混线 / 机器人，则应以扩展表及 M21 特例一起评估，不直接自动修改全部候选。

实际实现还会涉及占格与旋转锚点、边缘邻接、物料 / 能源连接、机器人通路 / 施工预留、地图交互 / 标签 / 动画和旧存档重叠处理，不能只加图片尺寸。本轮未做这些改动，也未决定旧布局如何升级。
