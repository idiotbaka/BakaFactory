# 可选多格机器

## 实施设计与范围

占地审查的 35 台生产机器加 M21 液压动力站，共 36 台支持 1×1 / 2×2，目录 supported_sizes 为 [1, 2]。原始设计 JSON 保持不变，扩展由 scripts/import-gameplay.mjs 导入。其余设备仍只支持 1×1。

实例、放置和机器人蓝图使用可选 size（1 或 2），缺省为 1。x/y 永远是左上角：2×2 占 (x,y)、(x+1,y)、(x,y-1)、(x+1,y-1)；旋转仅改变方向。尺寸不改变安装道具数量、配方、产能、缓存容量或真实物料。已有实例不自动扩容，移动保留原尺寸。

统一几何层负责占格、碰撞、边界、外围八邻格、组网连通与转移接触点。固体 / 流体保持原预留与原子扣收；2×2 的全部八个四向外邻格均参与相邻建筑组网供能。机器人以全部占格为障碍，从外周可达空格装卸 / 施工；蓝图预留全部占格，编辑及过境落点共同避让。

## 实施顺序

1. 协议、导入与前后端存档校验：兼容缺省尺寸，拒绝非法尺寸、四格越界 / 重叠。
2. 放置 / 移动及物流 / 能源统一几何，保留原守恒和调度规则。
3. 机器人路径 / 停靠 / 施工与预留；保持实体 ID、库存和进度。
4. 卡片按钮和标签、E 快捷键、检视、地图整体贴图 / 命中 / 标签 / 动画。
5. 回归测试代码、静态检查、编译及用户验收步骤；实际状态见 progress.md。

## 玩家操作

建造阵列中受支持机器未选中时右上角显示“多尺寸”，选中时原位置变为“⇄ 切换为2x2”或“⇄ 切换为1x1”按钮，显示下一次切换的目标；按钮沿用编辑器深色底、方角与青色悬停样式。每次点击 / 数字快捷键选择机器时，建造尺寸默认 1×1；连续放置期间按 E 或点当前卡片右上角切换按钮在 1×1 / 2×2 间切换。输入框、下拉框、文本编辑与 Ctrl / Alt / Meta 组合不触发 E，长按不连切。检视显示支持尺寸，选中实例还显示当前占地。连续建造底部操作说明仅对多尺寸机器提示“E 键切换尺寸”；鼠标跟随窗显示名称、角度和当前尺寸，多尺寸建造时另显 E 提示，移动已有实例时不显示尺寸切换提示。

2×2 以点击格为左上角，预览四格整体是否合法。任何占格越界、已有建筑、有效蓝图、机器人或过境落点重叠都会拒绝。移动可从任一覆盖格抓取，保留抓取位置及尺寸；不提供已安装机器的原地改尺寸。若要更换已放机器尺寸，先正常拆除回收，再选择另一尺寸安装。

机器人蓝图表单也可选择受支持尺寸，以左上角坐标安装；仍只消耗一个设备，施工一次 10 tick，完成前不生产。取消按原规则携货返仓，不提前返还；全部占格的预留一并释放。

## 空间与连接规则

- apps/web/src/game/footprint.ts 提供占格、外围、边界、重叠、坐标索引和动画接触点；运行层与编辑器共用。apps/server/internal/domain/footprint.go 提供云存档对应结构校验。
- 2×2 有八个四向外邻位置（不含对角）；输入 / 输出投料机依原方向从后取、向前送，接触任意边缘格都指向同一实例和同一组输入 / 产物 / 燃料缓存。所有接口共用原库存预留，不按格复制状态或额外产能。
- 流体管道后邻格可从整个机器边缘抽取产物，前邻格可向 input / fuel / medium 输入；介质、过滤、限流、容量和不混液规则保持。多出口共享已预留的真实产物量。
- 2×2 的全部四个占格与八个四向外邻格共同参与建筑组网划分（`powerRegions`），任何一侧与相邻建筑接触即并入同一组网并共享轴功 / 液压 / 电力网络，不再区分 `power_side`。M21 原真实燃料 / 启动介质及自供能规则保持。
- 机器人所有空地 / 部署 / 过境 / 编辑保护使用完整占格；BFS 不穿越机器的另外三格。装卸、维护与施工寻找八个外邻可达空地，角邻不算工作面；拥堵、授权、供能、载重、真实工时和返程保护继续生效。
- 地图一台实例只绘制一张正视机壳、一组状态 / 进度；覆盖格共用命中实例。阶段描边包围整个机器；简称仍为屏幕 12px，放在整体下半部。转移收据位置记录实际接触格，动画验证其仍在相同实例占格内，并在移动 / 旋转 / 配置变化后撤销。

## 存档与验证边界

format_version=1、rules_version=3 和所有已发布迁移保持。建筑 / 蓝图可选 size，旧档无字段仍为单格，不移动 / 扩大旧设备，不重建实例。新版客户端和 Go 对非法尺寸、null、非整数、不支持的设备、四格越界、重叠以及被覆盖的机器人 / 蓝图共同拒绝；原存档按原失败保护保留。无需数据迁移或清理浏览器 / 数据库。

新增回归代码：local/footprints.test.ts 覆盖八个方向接点、同库存多个接口守恒、单网络选择、完整占格与外周寻路 / 装卸、蓝图预留 / 完工、尺寸兼容与拆移；FactoryEditor / FactoryWorkspace 测试覆盖尺寸操作、预览、左上锚点和抓取偏移；Go footprint / 云存档验证用例覆盖可选尺寸、JSON、越界、双向重叠和蓝图。自动测试未由开发代理执行；执行结果以 progress.md 为准。
