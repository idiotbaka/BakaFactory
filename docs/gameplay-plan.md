## 新增物品编号约定

原始设计案物品继续保留 `i0001` 形式的 ID。未来在原案之外新增的物品统一使用小写 `d` 加四位数字，按 `d0001`、`d0002`、`d0003` 顺序分配；D 代表 DLC 式额外新增道具。编号与阶段无关，不复用已分配编号；图鉴 code 使用对应大写形式，例如 `D0001`。此约定仅针对物品，建筑和配方仍保留各自 ID。

| 物品 ID | 显示编号 | 物品             |
| ------- | -------- | ---------------- |
| d0001   | D0001    | 地下传送带出入口 |
