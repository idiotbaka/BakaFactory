# 工厂编辑器与 HUD 交互

地图缩放达到 120% 后，建筑 Tab 中 category=machine 的方块在下半部显示三字以内简称，如拆解台、蒸汽炉、液压机；物流 Tab 和传动轴 / 线缆 / 电池 / 仓库等非机器始终不显示。m17 机械分流器按现有图鉴归物流，也不显示。白字配工厂地面色描边，独立屏幕坐标层固定 12px Regular，不用缩小字体塞进 30px 格子；低于 120% 不渲染。平移 / 缩放、放置 / 移动预览同步，标签不拦截指针；方向 / 状态 / 进度、完整名称提示与实际编辑保持。适应地图 / 居中放大沿用原缩放（后者 125%），恢复 125% 时即显示；完整设计见 [机器地图简称](machine-map-names.md)。

地图面板内的操作错误浮条显示 3 秒后自动移除；每次新错误（含相同文字再次触发）重新计时，新操作主动清错或组件卸载时取消旧计时器。仅管理本次操作提示，不清除在线 / 登录 / 本地保存等持续故障状态，也不改变生产、保存或错误处理结果。

中央导航移除独立诊断入口，开发者工具入口默认隐藏；登录并加载完成后可在 F12 执行 `bakaFactory.devTools(true)` 开启、`bakaFactory.devTools(false)` 关闭、`bakaFactory.devTools()` 查询。显示偏好随账号在本机 IndexedDB 保存，关闭时回工厂，不重置内部测试设置。入口开放后默认子页为“功能测试”，另一子页为“闭环诊断”。切子页只切展示，不触发世界操作；下单测试开关保持原权限 / 暂停 / 依赖订单限制，诊断继续接收同一观察窗口并可定位当前厂设备回地图。开发者页不显示通用阶段任务说明。

机器人页采用“上手准备 → 部署到当前厂区 → 已部署机队 → 所选机器人任务控制”的纵向卡片。P2 默认只提供发条搬运车，说明初级搬运站、传动轴、补能和本厂固体搬运；部署列表只列已开放机型，未满足本体 / 补能站条件有具体提示。列表保留搜索、厂区 / 待处理筛选和定位；选中机器人以状态 / 能量 / 厂区信息块展示。运输机型直接配置路线，不跨区机型省去多余厂区选择；切到其他厂查看本厂限定机型时提示返回归属厂配置。巡检 / 维修机型显示相应现场作业；训练记录、跨区授权 / 优先级、智能调度、施工和召回参数放在分组折叠区，按阶段 / 角色提供，全部操作与暂停限制沿用原有 WorldAction。已统一总仓库说明，不把机器人描述成库存同步工具。

能源页常显 P1 手工 / P2 机械 / P3 液压 / P4 电力，未解锁类型灰显禁用，即使已有该类型网络也不提前开放；默认显示当前阶段最高已开放类型。手工页显示 BAKA-01 的夹爪 / 能量 / 散热趣味自评，无真实供能作用，后续阶段仍可回看；P5 / P6 沿用电力。P2 提供固燃传动机 → 传动轴 → 机器 / 初级搬运站流程；P3 说明启动工作液与动力管 / 物料管区别，P4 说明发电与线缆。统计只汇总当前选中的能源类型，不把不同动力相加；每个独立网络单独显示供需与等待状态，完整损耗 / 充放参数可展开。炉体燃料单列实际缓存可用热量和设备状态，缺料 / 满产物不会误称为缺少网络。电池效率、功率限制和备用电量只在电力类型的进阶折叠区显示，主页面不向 P2 展开电池规则。面板只读确认状态，不改变能源、机器人、物流或存档。

图鉴搜索框放在带内边距的收缩容器内，下方 P1～P6 六按钮按阶段筛选当前分类。建筑 / 物流的未来阶段禁用，物品未来阶段可预览；三分类分别记住本次查看阶段，默认当前已解锁阶段，读档退回低阶段时建筑筛选跟随收敛。搜索仅作用于当前分类和阶段，不重排；1～6 仍绑定原已解锁建筑顺序，快捷键与选中地图实例会切到对应分类 / 阶段，不因筛选改绑。空结果显示提示。

工厂地图标题在 X / Y 方向右侧提供快捷厂区下拉框，使用厂区管理同一 select_district 操作；切厂后清除地图实体 / 机器人选择和建造预览，工厂地图以原方式重新初始化。暂停、编辑保存、长按移动或平移期间禁用下拉框；保持标题 42px 与固定工作台尺寸。

工作室与右上角手工 / 机械手面板为全局唯一，不随厂区绑定。任意厂区均可拾荒、批量加工、下单、查看进度和取消，工作室设备首次制造权限、材料预留和队列互斥保持；地图垃圾提取口仍只允许起始回收场。仓库所有物品卡统一预留 36px 顶部下单区，不可下单项也保持同样图标 / 名称位置。建筑 / 物流检视的来源按钮下方提供“机械手下单”：按实际安装道具和当前已开放工作室配方判断，沿用 P1 领奖 / 开发开关权限；队列占用或暂停时禁用，固定设施或无合适配方时不显示。弹窗复用仓库下单的计划、确认、报错及焦点管理，不先切仓库或另建加工队列。

传送带地图与放置 / 移动预览按邻格箭头补接弯头及多入口交汇口，延续现有带面 / 轨道 / 横纹和输出箭头。四向转角以直角为主，仅角点微圆滑；同向直线段和未连接端的外观保持。只处理传送带之间的方向关系，不改变实际合流公平性、能量、容量、带速、物品轨迹或存档。

流体管道的地图外观根据邻格箭头自动接出弯头 / 汇流口，保持自身出口箭头；普通管道、回流管和管道型调压阀稍加粗并移除常态矩形底框，选中与建造提示保持。仅视觉连接，邻接却未指向本格的管道不补接侧口；不改变真实流体连接、过滤、容量或输送规则，预览与已放置管道复用同一画法。

所有厂区的仓库页均为“工厂总仓库”，五列卡片、搜索和道具浮卡保持，切厂显示同一库存。任意厂可建造、补料、收取 / 拆除、下单及通过顶部取消唯一队列；下单弹窗说明使用共用总仓库存量，不再禁用分厂入口。拾荒 / 工作室页面可在任意厂区操作，始终使用主厂唯一手工 / 机械手队列；厂区说明明确机器缓存、产线和能源独立，诊断显示总仓库存而不自动给机器填料。纯文案 / 权限调整保持固定 16:9、三栏和最小 12px。

P1～P5 的阶段终局任务须先达成本阶段普通任务至少一半（向上取整，达成未领奖也计数）才出现；隐藏项不计待完成数量 / 红点，页面显示门槛进度。终局带静态粉色描边、“阶段终局任务”标签及下一阶段提示，完成并领取奖励才推进；只制造里程碑不推进。旧已领奖终局保留可见。阶段说明与诊断区分已制造 / 终局已领奖，P6 不显示不存在的下一阶段。普通任务仍可任意顺序完成。

领取“是时候解放双手了”后自动打开“P1：工厂开饭了”，沿用五页开场播放器、3 秒打字 / 紧凑正文和键盘隔离；每页五行定稿，首次必须到末页完成。中断刷新从第一页恢复；本机观看提交失败时留在末页重试，未提交不算看完。底部“重放剧情”在领奖后增加此章节，旧已领奖存档可重放但不强制弹出，开发者开关不开放剧情。剧情自身不暂停工厂，原在线 / 后台规则保持。

中央“开发者工具”使用独立滚动页，包含“功能测试 / 闭环诊断”；原“仓库下单始终可用”开关和当前状态说明位于功能测试。默认关闭，可键盘切换，暂停时禁用；开启后无需任务领奖即可在总仓库下单，仍受已开放配方 / 设备、材料与队列占用限制。开关全厂共享并随游戏存档保存，不改任务 / 阶段；若未正式领奖且存在订单，暂时禁用关闭并提示完成或取消订单。切页不改变工作台、地图和建造工具。

领取“是时候解放双手了”奖励后，仓库按原序增加当前工作室可制作的零库存道具；可制品卡右上角“下单”打开图标工序预览大弹窗。上方顺序显示每步原料 / 产物、设备、批次与手工耗时，下方输入 1～1000 的新增需求量；整批多产、消耗 / 缺料与最终交付实时更新。忙碌、暂停、缺料、规划超限时不能确认；所有厂区使用同一总仓库与唯一队列。弹窗可关闭 / 遮罩 / Esc 退出，焦点限制在弹窗并隔离建造快捷键；下单失败留在预览显示错误，成功后关闭。顶部复用唯一进度显示“机械手自动加工中”、工序 / 剩余批数及取消回收，工作室此时不可另开队列；详见 warehouse-orders.md。

任务标题 / 描述 / 奖励、工作室每批原料 / 产物及仓库名称使用共用的道具来源浮卡。下划线名称可点击 / 键盘激活，浮卡从触发名称下方展开，空间不足时翻到上方并约束在视口内；介绍 / 模组代号 / 物品类型、安装建筑名称、来源配方的设备 / 工时 / 整批物料及阶段 / 里程碑前置均来自现有目录。任务中的设施别名按安装道具映射，最长完整名称优先；垃圾包解释无尽垃圾堆及提取口来源，不把消费垃圾包的分拣配方误作来源。卡内原料 / 产物可继续点查，始终只保留一张卡。

右上角 × 或 Esc 关闭后焦点返回最初名称；点击外部关闭并继续执行所点击操作，不锁定页面或暂停生产。卡片内部滚动可查看全部配方；外部滚动 / 窗口缩放、切换中央主视图 / 厂区时收起，避免悬空定位。卡片获焦点时隔离建造快捷键，关闭后恢复；通过 Portal 展示，不撑开三栏、仓库五列或地图，也不读写库存、制造记录及存档。

首次无工厂的命名页自动弹出五页开场漫画，完成后返回命名表单；工厂由玩家另行确认创建。底部操作指南左侧新增“重放剧情”向上列表，当前仅开场，重放可关闭 / Esc / 遮罩退出。播放器支持上一页 / 下一页与键盘翻页，最后按钮变完成；每页正文 3 秒内显示，紧凑行距 / 单行段落换行，不显示全文按钮。模态焦点 / 编辑快捷键隔离、固定工作台与图片 / 长正文滚动见 stories.md。

中央工厂视图页签在“工厂”右侧增加“任务”，页内分待完成 / 已完成，按配置推荐顺序排列，普通任务不需接受或按序解锁；终局遵循半数门槛。已达成待领奖仍在待完成，领取后移到已完成；未领奖时页签右上角红点并有可访问文字。卡片显示要求、进度、物品图标 / 奖励数量和领取按钮，暂停时不可领奖，任意厂区领取均发到总仓库且保留原建造工具。确认达成后底部气泡每条显示 3 秒，连发时顺序播放，不影响地图尺寸或输入；读档 / 云恢复不重播旧任务通知。

建造阵列分为“建筑 / 物流 / 物品”。物流包含带、投料 / 分流、箱罐、物料管道 / 阀泵；能源导线、动力设备和补能站保留在建筑。分类仅筛选原有顺序，数字 1～6 仍对应全体可建模组的原前六项，选中地图物流实体会切到物流分类。物品沿用原序，未获得时灰显，仍能查看资料；曾获得一次后保持彩色，即使库存耗尽或切厂也不变。

建筑 / 物流右侧原内联“关联配方”改为“获取来源和关联配方”按钮，地图选取同样可用。弹窗上半部按定义的安装道具查找产出该道具的所有配方，明确安装消耗 1 件与拆除返还；建筑与道具异名时额外标注（例如垃圾提取口使用初阶自动投料机）。下半部只列该设施实际可执行的配方，不将道具制作来源混作设施功能。卡片显示每批原料 / 产物图标及数量、加工设备、耗时、工作室入口或首次制造解锁提示、阶段 / 里程碑 / 动力和作业凭据前置；固定设施与无来源有明确说明。

弹窗经 portal 覆盖工作台而不参与三栏布局，内容独立滚动；关闭按钮、点击遮罩、Esc 均可关闭并返回触发按钮。Tab / Shift+Tab 保持焦点在弹窗，打开期间屏蔽底层编辑与建造快捷键，关闭不取消原建造工具；查询不写模拟或存档。物品分类仍使用原内联关联配方。

顶部仓库摘要已移除，工厂名 / 在线状态 / 生产数 / tick 保留。中央“仓库”按每行五张物品卡显示本区库存，可继续搜索；长名称和数量换行，不缩小字号或撑开固定三栏。

机器检视的手动补料改为左侧批数输入（默认 1）、右侧“从仓库补足原料”。这里填写目标完整批数，包含机器已有原料，不是额外追加相同批数；例如每批需 12 包，最多补至 8 批 / 96 包，已放 5 包时只从当前厂区仓库扣 91。下方实时提示综合输入格数、每种最多 100 件及仓库数量的上限，切机器 / 配方恢复默认 1，正常 tick 不重置填写值。超过上限的正整数允许提交，自动按当前上限执行并回显实际批数；空值、非正数、小数、无配方、暂停或无法补齐一批时禁用。原料在 Worker 重新核对后统一补入，不改变生产进度，不从其他厂区免费调拨。

顶部横栏右侧显示全世界唯一手工队列的当前配方、批次和工时条，切 Tab / 厂区仍可见，队列空闲 / 暂停 / 产物上限等待有对应文字。剩余批数（含当前批）和“取消队列并返还未完成原料”按钮也集中在该区域，工作室移除重复队列卡片；切任意中央 Tab 可管理。取消仍走既有 Worker 原子操作，仅退剩余批次原料、保留已完成产物，暂停时禁用，产物上限等待时仍可取消；任意厂区均可取消同一全局队列。工作室配方提供数量输入及“批量加工”，按当前原料显示可加工上限（最多 100），超过上限的正整数立即回填为上限，库存下降时显示值也受最新上限约束；空值、小数、非正数或原料不足禁止提交，Worker 再次原子复核。配方卡仅显示“手工 Xs”实际耗时，实际手工时长为秒数一半、向下取整且至少 1 秒，顶部和来源说明同步。一次只排同配方的一组批次，分厂可下单 / 取消同一队列，普通工作室也可在任意厂区操作同一队列。

“无尽垃圾堆”下方按手动分拣台 / 铁砧锻台 / 手工工作台 / 简易拆解台 / 手摇破碎机 / 手工装配台排列设备子分类，每次仅显示当前设备配方，搜索在本分类内进行。后三项未首次制造设备时灰显、悬停提示“至少需要生产 1 次该设备后才能解锁”；制造后永久开放，无需安装且不消耗该道具。切分类不取消队列，批量数量按配方保留；恢复更早进度导致当前分类未解锁时回到分拣分类。每批原料 / 产物以图标、名称和“存 N / 需 M”或“存 N / 产 M”卡片显示，原料不足有文字与边框提示。

只有设备子分类位于中央滚动区内的吸顶容器，向下滚配方时可随时切设备；无尽垃圾堆 / 拾取按钮与标题、阶段说明正常卷走，子分类自身仍可横向滚动。吸顶块使用不透明底色，不遮住外部工厂视图导航，也不改变工作台 / 地图尺寸。

“开发者工具 → 闭环诊断”独立滚动，包含阶段 / 终局、实际库存瓶颈、能源网络、机器人等待、确认观察窗口及物品来源去向。点问题设备的坐标按钮回地图并选中 / 居中同一实例，复用现有地图焦点，不触发安装、搬料或任务。查询 / 搜索 / 选择物品不写 Worker 或存档；长列表和说明保持固定工作台、三栏比例及最小 12px。

E2e 地图机器人可点击 / 键盘选取，右侧切换“机器人检视”，显示确认坐标、过境余秒、真实携货 / 现场工时、等待原因和返程阶段。可启停、取消、实际归属站召回或打开中央机器人管理；列表和地图保持同一实体选择。选图鉴或建筑退出机器人检视，机器人选择不触发建筑长按移动 / 放置。沉浸模式仍可在地图选择，退出 F 后右侧可查看详情。

列表支持机型 / 实体 ID 搜索及全部 / 当前厂区 / 暂停等待筛选，筛选不会取消任务；详情提供“在地图查看”，跨厂走既有切换，过境定位确认落点。机器人使用中的厂区授权显示锁定原因，完整返站后才撤销；暂停仍可选择、筛选与查看同厂地图，实际操作和跨厂切换需在线许可。已暂停机器人取消后会保持暂停，说明提示启用后继续实际回收。

选中机器人时以静态青色虚线展示当前路段，实际 WH 端口 / 蓝图障碍 / 当前占格均参与计算；预览不保证未来可达，不结算库存。跨区只显示通向 WH 的当前段与确认过境落点；目标删除、无路、占格等待均有文字说明，不伪画成成功运输。没有机器人平滑轨迹、全世界常驻路线或新增 RAF。

智能机器人详情新增自主派单配置，默认关闭；配方补料、巡检与真实消耗备件的维护可单独启停，展示最多 20 条派单 / 等待 / 施工记录。关闭派单不取消当前携货任务，“暂停机器人”才立即停工，“取消并返站”按原路径退回。供货 WH 必须配置对应输出面，目标与来源都需在允许厂区。

E2d2 在选中智能机器人的详情中增加“蓝图施工”：指定当前厂区的设备、整数坐标、方向和可选配方。机器人须实际返归属站、补满能源并装载归属 WH 的 1 个真实设备；切换到授权分厂可向该厂施工，仍需实际跨区。每台同时一张，现场工作 10 秒后安装；在建格用静态虚线工具图形显示，建造预览 / Worker 同时禁止占格。详情显示工时、携货与回收状态，“取消任务并携货返站”释放格位并实际返仓，不能直接删除蓝图取回设备或远程召回本体。批量多格模板 / 自动整厂排程不在当前范围。

E2c 在机器人页增加“真实作业与训练凭据”：显示三类账本存量及当前厂持续异常，选择已部署、已授权且实际返站的机器人后，可现场巡检或装载真实备件清理固体积压。全局选中的机器人可服务允许厂区，界面不免费跨仓。附件按钮在归属站实际安装 / 卸下摄像头；现场、返程、携货和保留备件展示于任务详情，忙碌状态不能召回。机器检视说明训练每批所需 40 / 20 / 30 次真实凭据。列表仍在中央独立滚动，不改变外框、地图或 12px 下限。

“机器人”页支持从当前厂仓库部署一本体、选择兼容补能站、全局列表、启停 / 优先级 / 授权、显式取送路线及携货取消返站。可选当前厂机器 / 箱罐 / WH，远厂只列 WH，切到目标厂可配置当地设备；任务端点按实例 ID 保存，移动设备后重新寻路。指定物品 / 每趟数量 / 输入或燃料用途 / 单趟或循环；展示确认位置、过境余秒、工时、携货、阻塞与完成次数。取消后不即时退库，实际返站且清空任务后才可召回本体；涉及厂区须返站后撤销授权。E2d3 / E2e 状态与交互已整合，待统一验收。

地图按确认格位显示静态机器人，无微小文字或独立动画循环；过境隐藏旧位置，落地再显示。补能站检视展示实付储能与共享补给，站满停止取能、电动补能 88%。绑定站点的移动 / 拆除、机器人占格 / 过境落点建造及新堵断返站路径的建造 / 移动会拒绝；全部由 Worker 再验证，不依赖预览放行。

“厂区”视图可切换、更名和扩建。切换保留所有厂区生产，地图按新厂初始化相机 / 选择；迟到的旧厂编辑拒绝。所有 WH 共用总仓库，任意厂区可操作唯一全局手工工作室；扩建从总仓库扣基础铁板 20、简易支架 10。厂区列表在中央独立滚动，不增加外框高度，完整世界统一本机保存 / 云备份。

流体设施检视支持介质过滤、吞吐、下游目标缓存 / 库存上限；分液阀按前 / 右 / 左设置权重和分支过滤，0 关闭。手动填充与排回总仓库使用完整容积，换液先排空。移动保留内容，拆除完整回收；地图用静态箭头与液位显示管线。

D1 增加同尺寸能源视图，显示网络供需、轴损、充放及储量；检视可选择优先级、供能侧、设备启停、电池模式 / 储备，以及液压站真实工作液注入 / 排回。节点不桥接独立电网，修改配置后下一 tick 重新计算连接；画风和编辑几何保持。

沿用 React、DOM/CSS 网格与 SVG 图标。地图通过 translate + scale 变换实现缩放和平移，图形随视图缩放；保留文字至少 12px，小于 100% 时补偿坐标字号并隐藏难以容纳的代号与次要坐标。没有新增依赖、API、表或 migration；原有账号和工厂继续使用。

当前已增加机器生产、库存、OUT / IN 端口、传送带运输与玩家仓库，规则见 [simulation.md](simulation.md)。中心 工厂仓库 保留在共享定义与地图上，仅从左侧可放置建筑列表移除。

当前皮肤与布局为霓虹工厂，见 [visual-style.md](visual-style.md)：工作台外框固定 16:9、宽度 max(90vw,1200px)，左侧图鉴 / 中央棋盘 / 右侧检视固定 18:58:24，侧栏独立滚动，窄窗口横向滚动；数字 1～6 选择 / 取消建筑；F 收起 / 恢复侧栏且保留外框宽高、建造方向与相机世界中心；底部可切换节能模式和打开操作指南。玩家档案收在上方弹出层。全站文字至少 12px，有效预览为青色，无效为红色；几何尺寸与交互保持，本地保存链路见下文。

## 实施规划与交互规则

交互分为持续放置、已有实例操作和地图浏览，优先级如下：

| 操作                | 持续放置模式                                   | 普通模式                           |
| ------------------- | ---------------------------------------------- | ---------------------------------- |
| 点击左侧建筑        | 切换类型；再点当前类型退出                     | 进入连续放置                       |
| 鼠标移入网格        | 显示方块、名称、代号和方向；青色有效、红色占用 | 显示坐标与 Hover                   |
| 左键点击格子        | 空格提交新实例，模式与方向保持；占用则提示错误 | 选中建筑或空格                     |
| 左键长按已有建筑    | 保持建造，避免移动与放置冲突                   | 50ms 后移动，松左键提交            |
| 右键网格            | 预览顺时针旋转 90°，包括鼠标位于已有建筑上     | 已有建筑打开操作菜单；空格关闭菜单 |
| 移动建筑时右键      | —                                              | 移动预览旋转；不弹出菜单           |
| 左键拖动空格 / 背景 | 平移，不提交建造                               | 平移，不修改实例                   |
| 滚轮                | 以鼠标位置为中心缩放                           | 同左；移动建筑期间暂停缩放         |
| Esc                 | 退出放置，关闭菜单                             | 取消移动、关闭菜单                 |

空格按下不会显示聚焦边框，并清除空格选中框；移动至少 4px 才认定为平移，拖动后的 click 被抑制；短点击仍可选中或放置。放置请求保存期间暂停新建，防止重复提交，响应成功后可以继续点击下一格。失败保留最后确认的布局与当前工具。

放置方向在批量操作中保留，可用右键、R 或工具按钮旋转。切换物品分类退出放置。“选择 / 取消”也可返回普通模式。输入框不截获 R / Delete / Backspace / Esc。

右键菜单按实例 ID 定位，提供垃圾桶图标和“删除”按钮，后续可扩展其他操作。点击外部、Esc、滚轮或开始平移关闭菜单。菜单保持在窗口内，打开后聚焦操作按钮，支持键盘触发。工厂仓库 删除禁用。

## 视图与坐标

平移时可以同时滚轮缩放；每次缩放更新拖动基准，继续移动鼠标不会跳回原缩放比例。默认居中显示 125%，滚轮范围 50%～300%，兼容像素、行和页的 wheel delta。禁止地图滚轮带动页面滚动。“适应地图”在当前窗口尺寸下居中显示边界，“居中放大”恢复 125%。

屏幕位置减去视口原点和平移，再除以缩放，映射到整数格子；包含 25px 坐标轴与 1px 边框。X 向右、Y 向上。只操作视图不会向服务器提交任何修改；缩放后的放置、移动仍提交原始格子坐标。

指针捕获用于已有建筑移动、空格平移，同时保留 window 监听作为回退。右键组合使用鼠标事件处理，保证按住右键时松开左键也只提交一次。失焦、pointercancel、lostpointercapture 取消移动和平移，清理长按计时与捕获；放置工具保留，鼠标回到地图可继续预览。

## 数据保存链路

`FactoryEditor → GameRuntime commands → Worker 串行编辑 → 完整本机快照 → IndexedDB transaction → client render`。

新建、移动、旋转、删除均不发送网络请求，坐标、角度、占用、固定 WH、库存与回收由本地运行层校验。移动保留 ID、configuration、库存和进度。编辑与 tick 使用同一个 Worker 队列，失败保留上一次完整状态。

同一时刻只提交一个编辑，IndexedDB 事务完成后解除保存锁，保留连续放置模式。生产每 5 tick 保存，恢复后不补算暂停时间。旧“刷新布局”改为“重绘布局”，读取当前本机快照，不从服务器覆盖运行状态。

底栏“存档”提供手动上传、明确确认的云恢复和本地保存重试；每 30 分钟自动覆盖唯一云备份。云版本冲突暂停并提供保留本机 / 恢复云端选项。登录失效、断网和本地写入失败暂停编辑，详见 [architecture.md](architecture.md)。

## 传送带视觉连接

同朝向的传送带沿传送方向前后相邻时，带面与两侧轨道延伸到格子边缘，连接处不绘制端盖；独立端点保留圆角端盖。0° / 90° / 180° / 270° 分别指向右 / 下 / 左 / 上，每格保留方向箭头，地图和格内放置 / 移动预览不显示 BELT 代号；图鉴与检视仍显示名称 / 代号。

并排的平行传送带、相反朝向、直角相邻、对角相邻、其他建筑及中间空格不会连接。连接外观直接从本机布局快照计算，移动、旋转、删除或刷新后自动更新，无需额外存储。放置 / 移动预览采用相同带面样式；现有邻居在本地编辑成功后同步重绘端盖。

该节记录传送带视觉连接规则；当前已同时运行运输模拟，见 [simulation.md](simulation.md)。

在项目根目录执行 `npm run dev` 即可同时启动 Go 后端和 Vite 前端，打开 <http://127.0.0.1:5173>。首次尚未安装依赖时先执行 `npm run setup`。

视觉连接的验收建议如下；本轮完整生产验收见 [acceptance.md](acceptance.md)：

1. 向右连续铺设 5 格 BELT，确认带面连成一条，中间没有独立方块边框；再分别尝试向下、向左、向上。
2. 旁边铺一排同朝向传送带，确认两排独立；相反朝向、直角相邻和隔一格也不连接。
3. 删除或移动中间一格，两端自动恢复端盖；补回同朝向传送带后重新连接。旋转中间一格也应断开。
4. 放大 / 缩小后检查箭头和连接处，带面不应出现 BELT 文本；点击、拖动、右键删除仍按具体格子操作。
5. 刷新页面，确认保存的传送带布局重新显示相同的连接外观。

## 用户浏览器验收

1. 左侧显示 MIN / FUR / ASM / BELT / OUT / IN，不提供工厂仓库的建造选项；中心工厂仓库 WH 仍存在、可查看。
2. 点 MIN，移动到网格确认跟随预览；右键旋转，连续左键放置至少三台，模式和方向保持。
3. 再点 MIN 退出；分别用 Esc、物品分类和“选择 / 取消”确认也能退出。切换 FUR / ASM / BELT 可直接更换建造类型。
4. 放置时移到占用格或 工厂仓库，预览为红色，点击不能覆盖。位于已有建筑上右键只旋转，不打开菜单。
5. 退出放置后长按已有建筑移动，在过程中右键旋转再松左键，确认实例位置和方向。拖到占用格 / 地图外、Esc 或切换窗口取消，原布局保持。
6. 右键某台机器打开菜单，点垃圾桶“删除”，只删除该实例。点击外部 / Esc 关闭菜单。右键 工厂仓库，删除禁用。
7. 滚轮缩放，鼠标所指位置保持稳定，图标和文本一起放大；测试 50% 和 300% 边界。空格拖动平移，不建造或移动建筑；放置模式中也能拖动空格。
8. 平移 / 缩放后放置、移动、删除，核对右侧坐标；“适应地图”找回全图，“居中放大”回到 125%。
9. 放置几十个实例后刷新、登出 / 登录，布局与方向保持；第二个同账号页面不得同时运行，关闭原页面后重试。

当前新增了生产模拟与拆除物品回收；尚无撤销、建造资源消耗。后续工作按用户反馈确定，不再按旧阶段路线推进。
