# 仓库筛选、分钟净变化与工厂 IO

## 展示与口径

仓库保留名称 / 编号 / 拼音搜索，提供共用 GameSelect：全部 / P1～P6，以及全部 / 机器 / 物流 / 固体 / 液体，初次进入默认全部，条件取交集。两个筛选值由持续挂载的 IndustryViews 管理，切到工厂、工作室等 Tab 后再返回时保留选择；只保存在当前页面，不新增存档字段或浏览器持久化。阶段读取物品 tier，缺省 P1；安装道具按照建造阵列 isLogisticsBuilding 分类进入机器 / 物流，机器人本体归机器，流体 / 气体归液体，其余材料、组件、废料及阶段成果归固体，不改变解锁权限或目录。

物品卡片左图标、右侧名称 / 数量 / 净变化 / 下单，取消原顶部按钮留白；下单权限和原规划保持。完整窗口后显示 `+25u/m`、`-12u/m`、`0u/m`，正数青色、负数红色、零灰色，保留符号区别。物品耗尽但仍有非零变化时保留卡片，以便看到消耗；无匹配项提供空态。

地图下方工具条“显示组网”左侧的“io数据”可点击向上展开 / 收起卡片，分别列出当前工厂最近一分钟“从总仓库取出”和“存入总仓库”的图标、名称、编号与数量。两列固定并排、各自上下滚动，标题与副文案“最近 1 分钟 · 本工厂内的产物io数据”保留在滚动区外，不再显示长篇统计范围说明。同物品入库 25、出库 12，分别显示 25 和 12，总仓净变化为 +13；进出抵消也保留 IO。

卡片为非模态浮层，无遮罩或焦点锁定。通过 Portal 避免地图容器裁切；打开时按按钮实际屏幕坐标定位到上方，宽 / 高受视口和上方空间限制，切厂关闭。再次点击按钮、关闭按钮或 Esc 收起；关闭按钮 / Esc 返回触发按钮焦点，外部点击 / 焦点转移收起并继续外部正常操作。窗口缩放或外部滚动收起，卡内滚动保持展开。只隔离卡片和按钮获得焦点时的建造快捷键，不锁定背景工厂。保持固定工作台 / 地图尺寸与最小 12px，不增加持续动画、定时器或 RAF。

净变化覆盖唯一总仓库所有成功扣收；工厂 IO 覆盖这些操作的实际厂区，包括固体 WH、取货 / 存入终端、流体 WH、机器人装卸 / 返仓、手动补料 / 燃料 / 工作液、收取、建造 / 回收、机器人本体 / 附件 / 维修备件和施工道具。终端升级按安装目标厂，机器人按实际扣收端点或使用道具的厂区归属。手动拾荒、工作室开工 / 下单 / 取消、任务提交 / 奖励、开发者物品获取按发起操作时的当前厂；共享工作室仅起始厂自动推进，完成产物计入起始厂，不随查看中的厂区漂移。机器缓存之间的内部搬运不算仓库进出，动画、阻塞和试探预留不产生统计。

## 时间与持久化

窗口共用 simulationTime 的 `secondsToTicks(60)=120`，计入 `current_tick-120 < bucket.tick <= current_tick`。仅按游戏 tick 推进：暂停、后台、断网、刷新读档不会增加样本、衰减记录或重放事件，开发者倍速仍以 120 个游戏 tick 为一分钟。

主厂新增可选 `FactoryDetail.warehouse_activity`：

- `started_tick`：首次启用采样时的当前 tick，不用游戏累计年龄伪造历史。新世界与旧档均需从这里累计 120 tick 才显示数字；未满时仓库隐藏速率、IO 卡提示正在积累。
- `buckets`：升序、同 tick 合并、最多 120 个稀疏桶；无变化不创建桶，下一次 tick / 编辑提交时淘汰过期桶。
- 每桶 `tick`、`delta`（逐物品有符号总仓净变化）、`factories`（实际厂区 ID → `received` / `withdrawn` 正整数物品映射）。净变化直接取真实库存差，不用双向统计相减。

历史仅在主厂保存一次，分厂禁止副本；projectFactory 投影同一历史。沿用 format_version=1 / rules_version=3，无数据库迁移，完整 IndexedDB / 唯一云备份自然携带窗口。两端校验必需键、null、窗口长度、时间顺序 / 边界、有效厂区 / 物品和安全整数，非法档拒绝并保留原记录。旧档缺字段合法，从下一次成功转换开始采样，不从库存或累计产量反推。

实际库存仍按原安全整数上限严格验证。IO 的极端重复周转累计量独立饱和至 Number.MAX_SAFE_INTEGER，用 `≥` 标记，避免观察统计溢出影响合法游戏操作；净变化仍取真实总账差量。

## 原子性与性能

`local/warehouseActivity.ts` 在 stepWorld / editWorld / actWorld 同步转换边界捕获统计。克隆后的真实仓库通过 WeakMap 绑定厂区；inventory.store 仅采样已绑定仓库，不采集 crafted 或订单私有物料。固体、流体和拆除的直接写仓改走同一入口，原结算次序保持。机器人跨厂操作显式传厂区，自动派单 proposal 使用独立暂存样本，拒绝时随库存一起丢弃；整笔编辑失败也不提交统计。

每次转换只遍历触及物品来计算总仓净变化，同 tick 仅复制当前桶的变动映射，复用不可变历史桶；不保存 120 份全仓快照或逐笔事件。历史位于 factory 顶层，避开 simulation 常规深克隆；编辑 / 世界操作也先移出不可变历史再克隆游戏状态。开销随真实仓库活动增长，百厂极限性能尚未实测。

WorldFrame 每 tick 只传 started_tick 和当前桶（若有），主线程裁剪并追加，不重传整分钟历史。初始化 / 编辑 / 云恢复仍返回完整状态。摘要仅在仓库页或 IO 卡挂载时计算，按历史引用 / tick 缓存；净变化最多扫描 120 桶 delta，单厂 IO 只读取各桶对应厂区，不遍历其他厂区。无新 Worker、定时器、RAF、依赖或数据库访问。
