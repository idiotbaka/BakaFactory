# 《Baka回收厂：从废墟到智能机器人》
# 工厂放置 / 自动化流水线 / 物流机器人 —— 资源与配方设计总案

【阅读说明】
1. 本文件每条配方都有唯一 ID（例如 R1001）、加工机器、基础加工时间、输入清单和完整输出清单。
2. 所有配方都使用“固定整数产出”。没有必须依靠随机掉落才能推进的稀有物料。物流上可以按比例精确计算。
3. 只存在一个世界级无限资源源头：“垃圾包”。所有金属、硅、贵金属、稀土、塑料和可用燃料最终均可沿配方链追溯到垃圾包。1号工厂的顶部横向 21 格，固定为垃圾点。
4. 玩家手动点击垃圾点，可以获取 1 个 “垃圾包”，随后使用手工的各种工作台等进行加工。垃圾包需要度过前期阶段后进入自动化处理。
5. 机器、管道、传送带、机器人、主线里程碑均可制造，不由金币凭空购买；产线道具和科研里程碑均有真正的材料需求。
6. “设备·某机器”为可摆放的建筑道具，安装后可在该机器上运行对应的工序；已安装设备不应因为产配方而自动返还为库存。
7. 旧式机器应在后期保留竞争力：分解、粗加工、燃烧、废料回收仍然需要低级设备，不能让玩家直接跳过一到三阶段的物料线。

第一部分：游戏核心愿景与设计目标
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

一、核心幻想
玩家面对一座“无尽垃圾山”，既没有矿脉，也没有商店送材料。
最初只能把混合垃圾拆成废铁、铜线、塑料、玻璃、脏水和电子废料；逐渐掌握分拣、破碎、熔炼、冲压、车削、煅烧、热裂解、液压、化工、发电、PCB 制造、精密装配、晶圆光刻、神经计算芯片和模型训练。
最终一个具有躯体、传感器、电池、记忆和规划能力的智能机器人走下总装线。

这不是单纯将配方做得越来越长。每过一阶段，都让玩家获得一种新的自动化解题能力：
- 第一阶段解决“能否持续得到稳定原料”；
- 第二阶段解决“能否在产线之间稳定移动原料”；
- 第三阶段解决“如何处理液体、污染和多种副产物”；
- 第四阶段解决“如何分配电力与调度全厂物流”；
- 第五阶段解决“能否构建自我维护的无人化工厂”；
- 第六阶段解决“如何给机器人赋予感知、记忆、决策和行动的完整闭环”。

二、玩家循环
【探索生产瓶颈】→【读配方/规划路线】→【摆机器和物流】→【供燃料/液体/电力】→【生产/分配副产物】→【产出中间件】→【扩产/升级机器人】→【完成新里程碑】。
游戏中不要以大量重复点击代替思考。初期保留极少量手工互动，玩家建立投料装置后，应能进入真正的放置自动运转状态。

四、资源与物理抽象
本游戏使用工艺单位（unit / u），不严格守恒现实质量。例如 1 个晶棒可切出多片晶圆，玻璃破碎也可能产生比输入件数更多的砂粒：这里的“件”不是公斤。
- 固体：1 u 是一个标准堆叠单位；默认机器等堆叠上限 100。
- 液体：1 u 是统一的流体工艺计量，不承诺等于 1 L；内部以整数流体单位存储。
- 气体：1 u 为管网工艺计量，和液体一样记为整数，但在容器上受压力上限约束。
- 装备/机器/机器人：1 u 代表 1 件完整实体，不参与普通堆叠。
- 电、轴功、热功、流压功：不是库存物品，属于实时网络能量账本。
- 训练数据和固件：配方中的物品不是神奇的“凭空软件”；它们是带有存储介质、授权或校验记录的物理模块。

五、最重要的平衡约束
A. 无概率卡死：所有主线稀有产物可以由固定比例可无限获得的材料生产。
B. 无隐性外部矿场：金、稀土、硅、镍钴、电池盐都从垃圾的子类副产物回收或化学处理。
C. 不允许免费资源正循环：回收配方可以收回材料，必须消耗工时、能源，且总高价值材料不得因闭环无中生有。
D. 多条支线有意义：例如玻璃既走建筑，又走晶圆，还走光学；稀土既造电机，也造感知和致动器。
E. 复杂度来自“耦合与选择”，不来自纯随机稀有概率、每日签到或者强制等待。

第二部分：六阶段的详细玩法结构
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

【阶段 1】灰烬与拾荒
物料方向：无限混合垃圾 → 粗料、燃料、手工机具
主要能源：手工/固体燃烧
完成目标：搭成首条可持续回收—熔炼—装配线，产出机械钥匙
里程碑验收物品：机械启动套件:1
进入条件：开新档自动进入。
初始游戏中的工厂上方新增 Tab，可以切换工厂视图、工作室视图、仓库视图。
工作室视图中可以手动使用 M01 手工工作台、M02 手动分拣台、M07 铁砧锻台（最原始的锤子与铁砧），以及可持续提取垃圾包的垃圾堆。其他物品初始为 0。

关键产业链：
  垃圾包 → 铁质碎片 → 可用铁屑 → 粗铁片 → 简易支架 → 拆解/破碎机
  湿有机物 → 干燥生物质 → 生物炭 → 固体燃料块 → 熔炉供热
  玻璃陶瓷碎片 → 玻璃砂/陶瓷粉 → 耐火砖/再生玻璃块
  废铜线 → 粗铜丝 → 粗铜锭 → 铜条
  粗铁锭 → 基础铁板/铆钉/齿轮 → 传送带/自动投料机/固燃传动机

主线目标：完成“机械启动套件”。它是一份可重复生产的实体成品，同时第一次生产会永久写入 P2 解锁标记；后续不要求反复消耗套件建造每台机械设备。
这一阶段必须给玩家的小惊喜：第一次看见“废物有用了”，通过组装初阶自动投料机让手动喂料退出日常操作。
给玩家 1 条特别明显的废铜/铁分拣线和 1 条可燃物供能线，强化“机械需要吞掉自己刚刚分出来的垃圾才能继续工作”的自给自足感。
工厂中心的 “总线” 可以设置切换每个面的输入/输出，以及配置输出时的白名单，来让玩家从手动处理产线改为半自动。

需要重点管控的产物：干燥生物质、生物炭、固体燃料块、粗铁锭、陶瓷粉、粗铜丝。废电池只可储存或低温拆解；不可丢进普通燃烧设备。

───────────────────────────────────────────────────────
【阶段 2】齿轮与蒸汽
物料方向：机械筛分 → 标准金属件 → 首批搬运装置
主要能源：固体燃料/蒸汽/传动轴
完成目标：不依赖玩家反复搬运，批量生产工业基础件
里程碑验收物品：液压工业许可包:1
进入条件：首次成功制造“机械启动套件”。

产业升级：
  废铁分级 → 机械筛分 → 高温铸造 → 合金钢坯/工业钢板
  铁铜铝 → 冲压、车削 → 精制传动轴、轴承、精制齿轮
  固燃传动机 → 机械轴网 → 机械车床与机械装配线
  净水 + 固燃热能 → 蒸汽锅炉 → 高压蒸汽（为 P3 的初始分馏塔提供启动动力）
  石英砂 → 高纯石英粉；废电路板 → 铜粉/电子粉尘
  陶瓷粉、灰粉 → 回转煅烧窑 → 煅烧矿粉/陶瓷基片

主线目标：做出机械搬运车、压力容器和蒸汽储压包，最终产出“液压工业许可包”，解锁 P3。
机械机器人：发条搬运车在两处固定站点之间搬运小件，默认每次 4 u；只会执行非常简单的“从 A 到 B”的任务。玩家由此第一次不需要用传送带拉满一整条地图。
布局冲突：工业机器集中用轴功率，长轴链有传输损失，锅炉产能和传动轴负载需要被分开管理。玩家可以选择用固燃机给轴网供能，也可以用蒸汽作为储压缓冲；二者都不能免费替代后续流体液压。
可选研究支线：煅烧矿粉 → 陶瓷基片 → 第四阶段的耐热 PCB。它不挡主线，却可以降低后期高温控制模块的原材料成本。

───────────────────────────────────────────────────────
【阶段 3】油液与化工
物料方向：热裂解 → 液体燃料/化学溶液 → 液压装置
主要能源：流体燃料/液压（兼容蒸汽）
完成目标：建立稳定流体回路、耐蚀材料与液压机器人
里程碑验收物品：电气化建设包:1
进入条件：首次制造“液压工业许可包”，并完成第一条压力容器生产线。

产业升级：
  废塑料/废橡胶/焦油渣 → 热裂解 → 粗裂解油 → 分馏 → 液体燃料/溶剂/重油
  液体燃料 → 液压动力站 → 高压工作液 → 液压冲压/装配
  电子粉尘/电路废件/杂合金片 → 湿法浸出 → 贵金属粉/镍钴溶液/稀土氧化物
  石英砂 + 灰粉 → 合金熔炼炉 → 精密硅酸盐玻璃
  污工作液、污水、废酸液 → 离心、过滤、中和 → 有回收损失的闭环

关键的“无死锁启动”规则：M20 分馏塔可吃 P2 蒸汽管网（前期）或 P3 流压（后期）；先用蒸汽分馏第一批液体燃料，再点火 M21 液压动力站。禁止让分馏塔一开始只接受尚未生产的流压，否则会卡死。
主线目标：稳定运行液压动力站、完成液压搬运机器人和管线巡检机器人，产出“电气化建设包”，解锁 P4。
双物流系统：固体有传送带与机械搬运，液体改由流体管道、分液阀、回流管路和储罐构建。若玩家堵住污液出口，反应釜应停机，而不是吞掉副产物，这会把“副产物处理”变成真正的工厂题目。
机器人第一次提供非运输收益：管线巡检机器人能标记堵塞管段、寻找泄漏点；只提升故障处理速度，不凭空给出免费燃料。

───────────────────────────────────────────────────────
【阶段 4】电网与控制
物料方向：发电 → 电网 → PCB/电机/电池 → 数控自动化
主要能源：电力（内燃机为过渡发电）
完成目标：实现传感控制、机器人充电、自动调度
里程碑验收物品：微电子实验许可证:1
进入条件：首次制造“电气化建设包”。

产业升级：
  液体燃料 → 液体燃料发电机 → 电力网 → 可充电储能
  铜条 → 高纯铜线 → 漆包绕组线/绝缘线缆 → 工业电机与电气设备
  铜箔卷 + 绝缘板 + 蚀刻液 → PCB → 工业控制板
  镍钴溶液 + 退役电池粉 → 电解盐/电芯 → 电池组/换电站
  稀土混合氧化物 → 稀土磁粉 → 工业电机
  CNC → 精密机架/接头/散热器 → 电动机器人

主线目标：电网与机器人换电站运行；至少生产 1 个电动物流机器人、1 个自动分拣机器人以及中央路由控制器；完成“微电子实验许可证”，解锁 P5。
核心抉择：全厂是否共用电网？集中式电网带来很高效率，但单点断电会让整个工厂瘫痪。鼓励玩家用储能箱、不间断电源和优先级负载规划保障原料回收与发电线永远优先供电。
中期重要反馈：电动物流机器人在传送带与不同生产楼层间充当“有任务的物流工”。优先处理传送带无法廉价覆盖的中距离高价值小批量材料；常用大宗料仍建议走传送带或管道。

───────────────────────────────────────────────────────
【阶段 5】晶圆与精密机器人
物料方向：高纯材料 → 晶圆/芯片 → 多种功能机器人
主要能源：稳定电网/储能/洁净生产
完成目标：完成可自主维保的无人化工厂与智能前置模组
里程碑验收物品：认知系统项目包:1
进入条件：首次制造“微电子实验许可证”。

产业升级：
  高纯石英粉/工业碳粉 → 多晶硅料 → 高纯硅棒 → 切割晶圆 → 抛光晶圆
  光敏胶 → 初次曝光 → 多层曝光 → 薄膜沉积 → 晶粒
  逻辑/存储/功率/传感晶粒 → CPU、存储芯片、驱动芯片、视觉芯片
  芯片 + 透镜/稀土磁材/触觉膜 → 摄像头、测距雷达、融合感知
  伺服电机 → 精密关节 → 精密机械臂 → 高速分拣/自动维修机器人
  实体存储与多机协作 → 规划固件、维护固件、真实工作轨迹样本

主线目标：制造并部署至少 1 台高速分拣机器人、1 台自动维修机器人，在协作站生成三类训练样本，产出“认知系统项目包”，解锁 P6。
这一阶段应该出现真正的“工厂自维护”：当库存不足、机器卡料、传送带断开或电网故障时，机器人能根据权限执行具体修复，例如从维修备件箱取标准紧固件更换磨损部件。维修不得神奇修复不存在的零件，也不得忽略可达性与修理工时。
高级机器人生成训练数据的特殊规则：配方中的数据样本是可消耗存储卡；但必须有真实机器人正在运行，并满足一定的累计搬运、巡检或视觉作业次数。防止玩家把空机器接上电就无限刷训练数据。

───────────────────────────────────────────────────────
【阶段 6】认知与觉醒
物料方向：超纯加工 → 神经阵列 → 训练/验证 → 智能机器人
主要能源：高压电网/冗余储能
完成目标：造出会感知、规划、行动、维护自身的智能机器人
里程碑验收物品：智能机器人:1
进入条件：首次制造“认知系统项目包”。

产业升级：
  高纯硅/贵金属/稀土 → 超纯净化 → 电子级与神经级材料
  工业碳粉/光敏材料 → 石墨烯/柔性神经导线/高密度触觉网
  电子级硅料 → 神经计算晶粒 + 高带宽存储 → 神经运算/长期记忆模块
  既有机器人实际工作数据 → 训练数据集 → 基础认知 → 规划 → 安全决策 → 可部署认知核心
  高密度电池 → 能源管理；伺服机构 → 双足底盘/灵巧手/躯干；融合传感器 → 头部
  完整 AI 核心 + 仿生机体 → 待验收机器人 → 功能验收 → 智能机器人

主线目标：首台“智能机器人”从终端验收舱走出来。
最重要的戏剧性：前五阶段制造的机器人，最终不是一次性被高级物品抹掉，而是已经为最后的智能体提供了大量真实生产数据、维修经验和路径样本。废料工厂亲手训练出会照顾工厂的机器人，形成叙事闭环。
终局循环：生产更多智能机器人，将其改造为物流型、维修型、精密装配型或极端工况维修型；建设柔性立体物流、神经调度单元与自修复生产模块；最后挑战有限垃圾吞吐/限定电力/限定格子面积下的高效生产目标。

第四部分：能源与流体的统一数值系统
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. 基本单位：能量统一用 kJ；功率 kW，且 1 kW = 1 kJ/s。机器配方基础耗能为“额定工艺功率 × 基础时间”。手工设备不耗网络能源，但在早期占操作队列。发电和动力站的表格功率指最大输出，而不是自身消费。
2. 燃料热值（草案）：干燥生物质 800 kJ/u；生物炭 3,000 kJ/u；固体燃料块 6,000 kJ/u；液体燃料 16,000 kJ/u。轻质烃、重油在默认版本中是化学材料而非直接高效燃料，以免跳过分馏链。
3. 热效率：P1～P2 固体热能工艺统一按 60% 可用热效率计；生物质简易燃烧按 35%；生物炭约 55%。例如 1 固体燃料块可向炉体提供约 3,600 kJ 有效热。
4. 固体发轴功：M09 额定最大 50 kW，燃料→轴功综合效率 33%，单块固燃约提供 1,980 kJ 轴功。50 kW 满载约可运行 39.6 s。轴网的长度、转接器与过载使这一阶段很容易成为生产瓶颈。
5. 流压动力：M21 额定 85 kW，液体燃料→可用流压综合效率 38%，每份液体燃料提供 6,080 kJ 流压；不满载按真实输出负荷计费。液压工作液是独立的循环介质，其损耗来自配方中的“污工作液”，而不等于燃料消耗。
6. 电力：M28 额定最高输出 160 kW，液体燃料→电能效率 40%，每份液体燃料产出 6,400 kJ 可用电；一个 160 kW 机组满载约 40 s 消耗 1 u 燃料。用于驱动第四阶段以后全电气设备。
7. 蒸汽：M14 利用固体热能把净水转成高压蒸汽。初始阶段的 M20 可从蒸汽网络取热功；P3 后期可改接液压动力。蒸汽管网建议用 1 u 蒸汽 ≈ 100 kJ 的可释放蒸汽做平衡起点；M14 默认产出速率 2u/11s，理论平均 18.2 kW，考虑锅炉热损；两台锅炉可稳定驱动一台满载 20kW 的分馏塔。
8. 电池：储能箱基础容量 15,000 kJ，充放电功率各 100 kW，往返效率 88%；高密度电池组单组容量 30,000 kJ，适合移动机器人，电池寿命按天数/工时而不是每次循环重做一次。
9. 超载处理：能源不足时降低对应机器进度，不能在有 10% 电力时依然 100% 产速；一次进度中断保留已完成进度，不重复扣材料；故障停机则保留进度并等待维修。
10. 负载优先级建议：①垃圾提取/初级燃料 → ②发电供燃料线 → ③废液回收和净水 → ④物流与供料 → ⑤精密产线 → ⑥训练集群。如此能防止精密设备一开机造成能源供应线被饿死。

【算例 A】一台 M12 机械车床以 13kW 运行 10 秒，每批需要 130kJ 轴功；理论上 1 份固燃块折合 1,980kJ 轴功，可以支持约 15 批这种单机操作（尚未计入轴功传输损耗与并行机组）。
【算例 B】一台 M51 训练集群额定 450kW，45秒训练工序耗能 20,250kJ。单机 M28 最大仅 160kW，因此需要至少 3 台并联发电机（480kW），或用储能与发电组合短时支撑。理论耗油量 20,250/6,400=3.164u，应通过连续油料缓冲账本计量，而不是每个配方都再写一次耗油。
【算例 C】初始 1 台 M02 的 R1001 为 12 包/10s；若垃圾堆供应足够，平均处理 72 包/分钟，其中理论固定掉出铁质碎片 18u/分钟。升级用 M10 以 5→4 的筛铁配方加工，若只有上述这一条垃圾来源，上游限制使最终可用铁屑达约 14.4u/分钟。这说明“换了高速机器”也不等于瓶颈消失，必须并联新分拣口。

第五部分：物流、工厂与机器人行为
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

一、地图建议
工厂由可扩展的格子区块组成。推荐每个工厂有一个不可复制的固定中心总线 (0,0)，连接分工厂输入/输出。每个工厂拥有独立的本地生产网络，物料必须通过真实传送带、机器人、管道或总线端口转移，不允许“全图凭空共用一个背包”。中心总线的启用权可以来自首次完成相应阶段的里程碑。
推荐让玩家看到六类工厂：回收场、冶炼场、化工园、电力站、精密电子厂、机器人总装区。视觉上的工业文明逐步升级是核心成就感来源。
玩家初始即解锁 6 个工厂，随着进度推进最多解锁 100 个工厂。每个工厂独立运行。

二、垃圾堆
“无限”指资源总量永远不枯竭。

三、运输选择
- 手摇传送带：最低成本，单格 1u/3s，受阻即停止；初期简单且直观。
- 机械传送带：轴驱动，单格 1u/s；P2 可用机械分流器、定量闸门和提升机。
- 液压输送带：单格 2u/s，但要接流压网；化工设备使用独立管道而不是带子运输溶液。
- 电动传送带：单格 3u/s，可由控制台设优先级、白名单、限速与堵塞报警。
- 高速精密传送带：单格 5u/s，专为芯片和复杂小零件；昂贵、耗电。
- 柔性立体输送带：跨层/多方向复用，单位吞吐 6u/s；用于终局大规模工厂。
上面的数字为“单格额定速率”，实际总吞吐取决于合流、转弯、上料机、机器出口能力和拥堵，不允许简单把每个格子的额定速率相加当总线路吞吐。

四、机器人任务调度
每台机器人存储 `home_station`、`current_task`、`battery_or_pressure`、`carry_capacity`、`allowed_zones`、`route_cache`、`maintenance_state`。
任务类型：PICKUP、DELIVER、REFILL、INSPECT、REPAIR、TRANSFER、CALIBRATE。给任务优先级、时效、货品白名单与权限组，避免低级搬运机器人跑去抢高价值晶圆物流任务。

调度逻辑建议：优先紧急供电燃料 > 防止机台停机的补料 > 中间产品运输 > 仓储整理；路由费用 = 移动距离 × 1 + 拥堵惩罚 × 2 + 电量风险 × 4 + 禁入区无穷大。机器人只提供灵活性、覆盖范围和反馈信息，不享受免费瞬移。

五、机器人增益与反制
- 发条搬运车：代替铺设长传送带，降低地图占用，但容量小、定点运行。
- 液压搬运机器人：跨区域搬运，减少转接点，不过要有液压补能与维护。
- 管线巡检机器人：流压系统故障发现延迟从约 90s 降至 30s；发现了仍需真实修理。
- 电动物流机器人：根据中央路由器选择路线，减少空跑，机器人换电站需要实际电能。
- 自动分拣机器人：可按需求动态改变目的地，但同一区域的单臂取放有节拍上限。
- 高速分拣机器人：使用高级传感后拥有更高拾取频率，但精准生产依赖洁净/校准。
- 维修机器人：带备件、消耗工时、检查可达性才能修；减少故障停机损失而不是免费创造物料。
- 智能机器人：在玩家授予任务权限后能执行“自动扩容这条不足的铁料线”等高级目标；仍需消耗相应设备、物料、电力与实际施工时间。

第六部分：经济平衡、调优方式与防卡死设计
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. 不卖原料：基础资源和所有可生产零部件不能直接点击兑换金币。即使加入金币，也建议只作为赛季物流订单、生产挑战和工厂竞赛奖励，不能打断“万物由工厂造出”的内循环。
2. 固定品位表：R1001 定额产出 12 类来源中约 9 类物料，保证稀有资源“难在多层提纯、机器昂贵”，而不是看脸。要新增稀有元素，请首先在废电子、杂合金或灰渣中提供确定性提取配方。
3. 多级品质但不爆炸：每类物质在基础、工业、精密、电子/高纯等四档之间按工序流转。最好不要生成“铁锭 I、铁锭 II、铁锭 III……”这样无意义的重复物品；每一级应真正打开新工艺或新物流需求。
4. 主线与支线分层：里程碑只检查少量关键商品，基础体验玩家可以只走主线；煅烧基片、高温机器人、溶剂回收、终局净化等支线改善成本/可靠性，不作为所有玩家的硬性门槛。
5. 装配的层次：整机通常有 4～8 条半成品支路 + 1～3 次关键的最终加工，不要一次性塞满 15 种输入口；超大产品应拆分为机体、能源模块、感知模块、控制模块四条产线再汇合。
6. 副产物作为经营题：热炼出炉渣、酸洗出废酸、化工出废溶剂、芯片出废气。若玩家不处理，缓冲仓会占满，连带阻塞高价值主线；但所有垃圾都有处理路线，处理收益未必为正。
7. 技术许可证：第一次完成每阶段的里程碑商品，就永久写入科技树的“已证明”状态。将该商品保存在纪念品仓或继续重造都可以；它不应该被某个普通设备蓝图反复强制消耗，避免重复跑完整个上一阶段成就。
8. 建筑配方：大多数设备都有 1 条主蓝图，产物为“设备·机器名”。复杂设备消耗金属结构、密封、电机或电子控制件，建造后消耗这些资源，不返还为原料。拆迁可返还约 80% 可用结构件，电气芯片等精密模块返回比例更低。
9. 新机器的价值：按照配方的实际输入/输出对比，新机器应至少提供 1 项明确优势：提高回收率、提高吞吐、解锁新材、降低耗能、降低空闲占地、提高控制或减少故障。
10. 不允许重复消耗：工艺功率已在能源网络计费，则配方中除化学原料以外不应再出现“燃料块作为加工费用”。只有明确化学原料的炭粉、燃料添加剂、反应介质才写进物料 BOM。

推荐的目标库存策略（开发默认模板）：
- 原料废料：生产需求 3 分钟的缓存。
- 作为能源枢纽的固燃块、液体燃料：生产需求 10 分钟的缓存。
- 流体工作液/净水：生产需求 5 分钟的缓存。
- 半导体晶圆与贵金属材料：生产需求 10 批的缓存，超额后停止高耗能设备。
- 终局训练数据：采集允许预存，计算训练机器电力不足时不要反复尝试开机。

困难档建议调整：
- 休闲：机台磨损关闭；发电燃料消耗×0.8；自动任务默认帮忙设置。
- 标准：使用本文参数；磨损按工时发生；明确污染存储上限。
- 硬核：发电燃耗×1.25；轴网功率损失显著；更多副产物缓冲问题。
困难不建议简单把掉落量压到 1/10，这会把解谜式工业游戏变成挂机等待模拟器。

建议分别定义：ItemDefinition、MachineDefinition、RecipeDefinition、StageMilestone、PowerNetwork、FluidNetwork、TransportGraph、RobotEntity、TaskDefinition。
- RecipeDefinition：id、stage、machine、seconds、inputs、outputs、conditions、energy_cost、tags。
- ItemDefinition：id、name、kind、stackSize、fluidKind、unlockStage、sources、uses、pollutionClass。
- MachineDefinition：id、name、unlockStage、workMode、ratedPower、inputBuffer、outputBuffer、recipes、durability。
- StageMilestone：id、stage、firstCraftItem、permanentUnlockFlag、reward、hint。
- TaskDefinition：taskId、origin、destination、priority、deadline、itemFilter、quantity、reservedInventory、permissions。
- Input/output 在运行中应按“先预留 → 能量确认 → 加工进度 → 原子性结算”，避免并发机器重复扣库存或产出丢失。
- 同一种产品多个制作方式必须显式记录 recipe id，不应仅靠物品名推断配方。
- 设施摆放使用机器道具 item 与运行实例 instanceId 分离；M55 是新增煅烧支线，不应依靠硬编码机器 ID 连号判断阶段。

建议上线前的自动化测试：
T01 可达性：从垃圾包 + 初始三台设备出发，能生产所有主线里程碑，以及 1 台智能机器人。
T02 机器前置：每台新机器的建造配方，只使用该机自身之前已经可获得的资源与工作机器。
T03 燃料自启：无需初始库存，手工分类出干燥生物质 → 生物炭 → 固体热能；没有燃料之前允许少量手工建造。
T04 流体自启：M14 蒸汽可驱动 M20 出第一批液体燃料，随后 M21 自持；无任何“液体燃料必须先有液压”的循环。
T05 电力自启：M28 从 P3 材料手工/液压组装完成，装上 P3 液体燃料即可发电；M29 电解槽不承担发电机前置。
T06 材料独立性：稀土/贵金属/硅/镍钴均有源自垃圾包的路径；没有访问现实世界地图矿点的依赖。
T07 卡带停机：输出仓满、废液仓满、能量不足、机器人运不到时都可以恢复，且不重复生产/消耗。
T08 容错：机器制作中暂停重启、服务器回滚、仓库库存不足、机器人换任务并行时状态一致。
T09 配方循环：将所有回收环的材料价值加权后，检查是否存在无成本纯材料增殖；可逆化学链须依赖额外能源和处理损失。
T10 工厂性能：模拟 1000 台机器、1 万格传送带、500 台机器人进行 24 小时离线计算，目标为亚秒级结算；这是性能测试目标，不是已达到的实测指标。
T11 机器人防作弊：机器人的复制、升级、拆解不能透过重复操作复制电池、CPU 和任务物品。
T12 观测性：玩家可以直接点开物品看全部来源和去向，点机器可看到耗能、瓶颈、未来 60s 预计产量与堵塞原因。

第十部分：机器人规格与成长树
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

RB01 发条搬运车（P2）
  能源：机械动力/定时上弦
  载荷：4 u
  动作节拍：8 s/往返（推荐起值）
  约束：仅固定 A→B；不参与智能避障
  工厂反馈：低成本替代长距离带，站点式物流

RB02 液压搬运机器人（P3）
  能源：液压储压
  载荷：12 u
  动作节拍：10 s/往返
  约束：可跨厂房区块、需维修与补液
  工厂反馈：连接远距离离散材料岛

RB03 管线巡检机器人（P3）
  能源：液压储压
  载荷：0 u
  动作节拍：每 30 s 一次巡检
  约束：检查污液堵塞、漏液；需巡检路径
  工厂反馈：降低流体停机时间

RB04 电动物流机器人（P4）
  能源：充电电池
  载荷：24 u
  动作节拍：8 s/往返
  约束：地址调度/回充/载重限制
  工厂反馈：高价值稀疏物流

RB05 自动分拣机器人（P4）
  能源：充电电池
  载荷：8 u
  动作节拍：每 5 s 执行一次取放
  约束：优先级白名单、缓存口容量
  工厂反馈：提升交汇处分拣灵活性

RB06 高速分拣机器人（P5）
  能源：可换电电池
  载荷：12 u
  动作节拍：每 2 s 一次取放
  约束：精密定位、视觉识别、路径互斥
  工厂反馈：用于微电子小件流

RB07 自动维修机器人（P5）
  能源：可换电电池
  载荷：6 u
  动作节拍：修理工时 20～60 s
  约束：取备件、诊断、维修；无库存不能修
  工厂反馈：降低故障恢复损失

RB08 高温维修机器人（P5）
  能源：隔热外壳+可换电
  载荷：4 u
  动作节拍：每 35 s 单设备
  约束：热区不怕过热惩罚，其他同维修
  工厂反馈：煅烧/裂解高温区维护

RB09 智能机器人（P6）
  能源：高密度电池+能源管理
  载荷：32 u
  动作节拍：每 1～3 s 智能作业
  约束：全局任务规划、学习权限、行为审计
  工厂反馈：最终目标、可配置多用途生产单元

推荐的机器人发展链：发条搬运车 → 液压搬运机器人 → 电动物流机器人 → 高速分拣/自动维修机器人 → 智能机器人；分支机器人不是等级直升、不会变成完全相同的面板，低级机器人应继续在成本敏感工位有用。
机器人持有者可以把机器人从“商品库存”部署为“运行实体”，部署行为本身不毁掉机器人；升级配方中作为输入的机器人将被真实消耗，换取一个绑定的新机体或升级包。部署实体与库存机器人不能同时存在。
