# 机器人检视、任务草稿与地图选点

## 界面分区

机器人中央页拆为「概览 / 部署 / 管理」三个子 Tab。概览展示已部署、已派任务和需要处理的机队统计，以及当前阶段的上手说明；部署只显示机型、兼容站点和参数；管理保留机队搜索、显示范围、任务、厂区授权、现场作业、智能权限、施工与召回。切换子 Tab 不发送游戏操作，子 Tab 支持左右方向键和 Home / End。

地图机器人检视复用物品图标、模组标题、说明、属性行与卡片样式，分为运行状态 / 能量、当前位置、当前任务 / 携货、运输配置和操作区。空闲 carrier / smart 机型可在检视直接安排运输；其他机型通过管理页安排现场作业。进行中的任务保留原有暂停、携货返站和安全召回条件。

九机型地图简称分别为发条车、液压车、巡检机、电运车、分拣机、高速机、维修机、高温机、智能机。简称不超过三字，下一行状态不超过五字，例如去取货、搬运中、取货中、交货中、等库存、等容量、目标拒收。状态颜色为 `var(--muted)`。与机器简称相同，缩放至少 120% 才显示，字号保持屏幕 12px，随原机器人确认位移补间移动；不镜像文字，不增加 RAF、寻路或交互图层。

## 任意物品

运输物品默认可选「任意物品」，也可继续指定某个物品。协议使用既有 `RobotTask.item` 空字符串表示不过滤；非空仍为精确物品编号。机器人 cargo 始终保存实际物品编号和真实数量，一趟只装一种物品，完全送完后下一趟重新选择，保持现有载量与单流体容器边界。

候选来自真实来源缓存：机器只读产物、不提取输入 / 燃料；料箱读其库存；储罐读当前单种流体；WH 只考虑实际开启、指定物品且有库存的输出面。先按已完成趟数轮换候选，过滤机型不能携带的物品，并跳过当前目标拒收 / 满容量或没有对应 WH 接口路线的候选。没有候选时等库存；全部不能接收时显示拒收，存在可接收但装不下的候选时等容量。已经装货的机器人保持实际物品绑定，途中目标被塞满时保留货物等候，不能换货、复制或提前退款。

候选检测只读，不预扣或发放物品；真实来源扣除、cargo 增减、目标接收、工时 / 能耗、WH 输出件数与同面竞争仍走原子 exchange。普通设备的候选共用路线，WH 候选最多来自四面配置；单机器人单 tick 的候选选择复用于能量、行进和装卸规划。地图 RAF 不运行候选或库存逻辑。智能派单仅对已知具体物品承诺需求，未装货且未过滤的手动任务不虚构特定物品预留。

## 支持的端点

新任务与地图 / 下拉入口共用 `local/robotEndpoints.ts`：支持 WH、料箱、生产机器（不含补能站）、流体储罐与蒸汽储压罐。移除普通 / 回流 / 调压管道，以及分液阀、投料泵等中转设施；它们仍按既有规则运行现场物流、供能和通行。液压 / 智能机型可从储罐或机器运输兼容流体，固体机型不会因为任意物品而获得运流体能力。

端点类型在新任务操作内再次校验，不能通过绕过 UI 指定管道。已有旧任务和真实携货不在读档时删除或改写；旧任务继续按原端点规则执行，取消后只能用新白名单重新配置。已拆除端点仍沿用原有安全携货返站规则。

## 地图选点与跨厂

检视和管理页复用 `RobotTaskForm`；工作台按机器人 ID 保存仅限当前页面的草稿，包含来源 / 目标、过滤、每趟数量、投入目标和循环设置。草稿不进入 Worker、IndexedDB 或云存档，切中央页和厂区可继续使用，刷新网页后重置。已提交任务按原存档保存，不依赖草稿。

点击「选取取货和交货位置」会回到工厂地图并保留机器人检视，结束建造 / 删除、未完成地下端口、框选及拖动手势。先点来源，再点目标；2×2 机器任一占地都选同一实体。鼠标旁浮窗显示步骤、来源摘要和当前目标可选性，原地来源描边，悬停有效 / 无效目标显示不同边框。管道、空地、蓝图、机器人本身和相同来源 / 目标都不能选。

支持跨厂且已授权的厂区可从地图右上角切换；不支持跨厂的机型只能选择归属厂。切厂保留第一端点、当前机器人及完整草稿，远厂设备保存厂区 / 实体 ID 和显示摘要；回填后可以继续用下拉修改。撤销授权、拆除 / 移动设备、变更配方与实际通路最终由 Worker 再次校验，不靠显示摘要授权或扣料。

第二次有效点击仅完成回填并退出选点；玩家仍须点「安排运输任务」提交。Esc 或「取消选取位置」退出并保留之前已填草稿，不提交本次未完成路线。切其他页面、选择其他实体、开始其他建造工具、世界暂停 / 离线或机器人被派发任务时结束选点。选点期间仍可平移、缩放、F 沉浸，不能拖动、旋转、删除建筑或中键 / E 拾取建造。

## 协议与兼容

不新增 HTTP 接口、存档字段、格式版本或数据库 migration。OpenAPI 补充任务 `item` 为空的含义并重新生成类型；客户端和 Go 云备份校验同步允许空过滤，但实际 cargo 仍需为已知、可携带、未超载的物品，`cargo.count + delivered` 不能超过本趟数量。原有指定物品任务、实体、存能、货物和计数保持。
