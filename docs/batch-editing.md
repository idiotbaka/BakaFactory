# 工厂地图批量编辑

## 操作与范围

退出建造模式后，按住右键拖出选框；移动超过 4 个屏幕像素才开始框选，普通右键点击仍打开菜单。松开右键确定本次选择，新框选替换旧选择。选框碰到任一覆盖格就选中完整建筑，2×2 机器不会拆成四个对象。

地下传送带选中任一端即补选另一端，即使另一端在选框或视口之外；多个配对可以一起选中。左键在选中建筑任一覆盖格长按 50ms 后拖动整组，松开确认；保留相对位置、朝向、尺寸、配置、缓存和生产进度。地下带整对允许横向 / 纵向平移，保持原间距；未框选时的单端移动仍按原轴线调整。批量模式不提供旋转。

按 Delete / Backspace、工具栏“删除选中 N 个建筑”或右键菜单中的同名操作批量回收。地下带两端计为两个建筑实例，只返还一套道具；输入、产物、燃料、流体、工作液及载荷沿用既有回收规则，未完成进度不生成产物，储能按原规则散失。

Esc 清除选择并取消未确认拖动；点击未选建筑或空格、切建造工具 / 厂区也退出当前选择。窗口失焦、指针取消 / 捕获丢失及视口尺寸变化取消未完成手势。输入控件中的删除键不触发地图删除。建造模式保留右键旋转和连续放置，空格平移、滚轮缩放保持。

本轮框选排除 WH、取货 / 存入终端、固定设施、机器人实体及仍绑定机器人的补能站；它们原有单体操作保持。垃圾提取口可以框选，但整组落点仍须让提取口位于地图顶部。

## 原子性和开发入口

- `apps/web/src/game/batchSelection.ts`：完整占地与矩形相交、关联实例闭包、可框选范围及落点初步检查。未来成对建筑在 `linkedBuildings` 扩展关联规则，界面和 Worker 共用同一闭包，不根据坐标邻近猜测配对。
- `FactoryEditor.tsx` / `editor.css`：屏幕坐标选框、静态选中标记、整组落点预览、菜单及手势取消；无独立 RAF，不改工作台尺寸和字号。
- `local/runtime.ts`：通过一个内部 Worker 消息发送 `batch_move` / `batch_delete`，不新增 HTTP 接口。
- `local/state.ts`：在未发布克隆中完成整笔转换。移动先排除整组旧占格，再检查所有完整目标占地，允许移入组内其他建筑原先的位置，禁止与组外建筑重叠或越界。删除复用既有回收逻辑，跳过已回收的配对另一端，溢出时整笔拒绝。成功只递增一次本厂 revision。
- `local/world.ts`：再次检查当前厂区、蓝图、机器人及跨厂落点、绑定补能站和最终布局的安全返程。分厂回收写入主厂唯一总仓库，分厂账本保持空；主厂 revision 同样只增加一次。

拖动期间模拟继续，预览不修改实际布局或库存。Worker 按执行时状态重新校验；机器人移动或绑定变化可能使预览有效的操作最终被拒绝。失败不部分移动 / 回收，保留选择供重试；成功撤销所有涉及实例的旧 transfers 路线，动画不回写库存。

选择仅存在界面中，不进入本机 / 云存档。沿用现有完整快照，无存档字段、OpenAPI、物品编号或数据库迁移。

## 检查和验收

首次搭建运行 `npm run setup`，常规检查运行 `npm run lint`、`npm test`、`npm run build`。

`FactoryEditor.test.tsx` 覆盖框选、普通右键、多格 / 配对选择、整组预览 / 命令、碰撞拒绝、菜单 / 删除键、输入框 / Esc / 指针取消；`local/batchEditing.test.ts` 覆盖组内腾挪、配对 / 状态保留、读档、碰撞 / 越界、保护设施、回收守恒 / 溢出回滚、分厂唯一库存和机器人 / 蓝图 / 安全返程保护。实际执行结果见 [progress.md](progress.md)。

用户启动 `npm run dev` 后验收：

1. 退出建造模式，摆好普通机器、带和箱子。右键拖选，检查相交建筑出现青色标记，松手不弹菜单；新框选替换旧选择。
2. 左键长按选中建筑拖动，所有选中实例都有落点预览；松手后相对位置不变。允许移入组内旧占格；任一角碰到组外建筑、WH 或地图外时，整组拒绝且保持原位。
3. 仅框住 2×2 机器右下格，四格一起选中；从覆盖格拖动，保持抓取偏移、尺寸、配方、缓存和进度。
4. 仅框住地下入口，出口自动选中，即使在视口外。上下 / 左右移动后配对、间距、朝向和真实载荷保持；多对地下带及普通机器可一起操作。
5. 在机器、箱子、带上留可清点物料，分别用 Delete 和右键菜单回收两组；道具、地下每对一套及实际缓存只返还一次，无未完成产物。刷新后布局和库存保持。
6. 选框穿过 WH、终端、机器人和绑定补能站，确认排除；提取口不能随整组离开顶部。落点机器人 / 蓝图占格或堵住安全返程时整笔拒绝。
7. 分厂回收后切回主厂，总仓库只增加一次；刷新和正常云备份恢复保持结果。
8. Esc、失焦和指针取消结束未确认操作；输入框删除文字不拆建筑。复查单体长按 / 右键、连续建造、缩放 / 平移、F 沉浸和节能模式，工作台尺寸保持。

自动回归不代替浏览器右键捕获、不同缩放 / 高 DPI 和预览视觉验收；实机效果待用户确认。
