# 工厂仓库移动

## 规则与交互

每个厂区仍只有一座内置工厂仓库 WH（内部类型 `bus`）。新厂初始在 `(0,0)`，现可像普通建筑一样长按 50ms 后拖到任意合法空格，松开确认；Esc 取消。朝向始终为 0，R、拖动时右键及旋转按钮不能改变方向；菜单、Delete / Backspace 和删除按钮不能删除仓库，也不能额外建造仓库。

移动保留实例 ID、四面输入 / 输出 / 过滤配置、冷却及完整机器状态，不消耗道具、不退款、不创建新的仓库库存。所有厂仍访问主厂唯一 `simulation.warehouse`，分厂持久化库存为空。原点腾空后可建其他设备，地图坐标与居中 / 缩放仍以地图原点为准，状态栏显示实际仓库位置。

两类仓库终端原有规则保持。升级新增终端时，从本厂仓库的当前位置附近确定性寻找安全空格，不再固定围绕原点安装。

## 物流与机器人

固体、流体和机器人取送继续按仓库实例及真实邻格工作，四面配置指地图的东 / 南 / 西 / 北方向。移动会取消旧位置的物流动画收据，库存只由 Worker 确认，原线路不自动搬迁或接线；玩家需在新位置重新连接实际物流。

机器人目标继续引用同一仓库 ID；本厂路径、携货返仓、跨厂出发和目标落点均使用实际仓库位置。跨厂行程仍为 8 秒，落点为目标仓库的空闲四邻格，受地图边界、建筑 / 蓝图及机器人占格限制。到达后正常运输 / 返站，不赠送能量或复制货物。

移动与原有世界编辑共用占格、蓝图、机器人和安全返程检查。若有机器人正在从本厂跨区离开，或正向本厂过境，暂时拒绝移动该厂仓库，提示等待抵达；暂停中的过境机器人也保留已确认位置，需恢复并抵达后再移。这样无需改写过境机器人坐标、瞬移落点或增加存档字段。普通走格 / 搬运中可以尝试移动，实际结果仍须满足安全返程能量和通路限制。

## 实现与兼容

- 编辑器允许内置 WH 拖动，保留旋转 / 删除保护和 50ms 手势，不新增窗口、定时器或绘制层。
- `local/state.ts` 与 Go `domain/save.go` 保留每厂恰好一座 WH、合法空格、单格与朝向 0 校验，移除必须在原点的限制。移动前后完整快照原子提交，失败保留原状态。
- `robotRoutes.ts` 使用目标厂 WH 当前邻格规划跨厂落点；客户端和 Go 按来源 / 目标仓库实际位置验证过境，原点附近的孤立旧落点不会因位置合法而通过。
- 目录 `fixed=true` 保留为内置 / 不可额外建造的标记，移动权限在 WH 编辑规则中明确放开。导入脚本同步描述，不修改原始设计案，不增加可刷安装道具。
- 存档 / 协议 / 规则版本保持，无数据库迁移。旧仓库自然留在原位置，新位置可保存到 IndexedDB / 云备份；不重新创建实例、不修改账号和实际存档。

## 用户验收

本轮按用户要求不执行自动测试、浏览器测试或 HTTP 冒烟。实际静态检查 / 编译状态见 [进度](progress.md)。用户可执行：

```bash
npm test
npm run dev
```

1. 主厂选 WH，确认旋转 / 删除禁用；长按 50ms 拖到空格，R 和按住左键时右键都不能旋转，松开后位置改变、ID 和四面设置保持。右键菜单、Delete / Backspace 不删除；Esc 取消拖动不改位置。原点可正常建造其他设备。
2. 在分厂重复移动，确认各厂各一座 WH、所有库存仍共用唯一总账。尝试占格、越界、机器人 / 蓝图格与破坏安全返程的落点，应整笔拒绝、保留原位置和库存。
3. 在新位置接入带 / 投料机和管道，验证输入、指定面输出、过滤、原速率及自动入库统计；旧位置不再出入料，移动本身不结算物品或重播旧路线。
4. 将主厂和目标分厂 WH 移到不同位置，安排机器人 WH 取货和跨区运输，确认从实际仓库邻格离开、8 秒后在目标仓库邻格抵达。过境期间尝试移动来源 / 目标厂 WH 应提示等待；抵达后可正常移动，货物和能源保持守恒。
5. 开放仓库 IO 后升级一个终端，确认优先安装在移动后的 WH 附近。已有终端不随 WH 移动，也不改变其配置或库存接口。
6. 刷新本机存档、上传 / 恢复云备份后，检查主厂 / 分厂仓库位置、ID、四面配置、总库存和机器人过境保留，旧原点仓库仍可正常读取。正常 / 节能和不同缩放下手势、地图尺寸及至少 12px 字号保持。

新增 / 更新的回归入口包括 `local/warehouseMove.test.ts`、`warehouseIO.test.ts`、`robotNavigation.test.ts`、`FactoryEditor.test.tsx`、Go `domain/robots_test.go` 与 `httpapi/saves_test.go`；这些测试由用户执行，不将静态编译写成测试通过。
