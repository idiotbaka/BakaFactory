# 开场：09 号与下班计划

开场五页正式资源在 `apps/web/src/assets/stories/opening-ai09-v1/`。第 1、2 页保持用户批准的 method B / protected skin palette 图像像素；本轮通过内置 imagegen 单独重绘第 3～5 页。其他章节仅调整角色文案，20 张旧插画保留待后续重绘。原始开场和前一轮高分辨率试图均保留。

## 角色与画面

09 号是蓝色短发、粉色发卡、半睁蓝紫眼的女性人形具身 AI；灰色宽松制服、白衬衣、深蓝蝴蝶结和 `09` 胸牌，仿生手与耳侧接口。性格慵懒、可爱、认真安排工作，目标是造出能独立接班的伙伴。没有旧电视头、夹爪或天线；搬运小车等工具机器人仍保持各自机型。

五页均为 384×360 RGB PNG，低饱和与暗一些的 SFC 像素插画。第 3 页侧面看终端、招聘零人，第 4 页画机器人同事图纸，第 5 页背影面向空躺椅与落日，招牌倚在门边。画内只有 `09` 和招聘数字 `0`，其余信息使用图标；图纸里的机械机器人是待制造同事。

## 重建与核对

依赖 Python 和 Pillow（仅离线美术工具，游戏不增加运行依赖）。从仓库根目录运行：

```sh
python output/imagegen/opening-ai09-v1/process.py
```

`sources/` 保存五页绘图原始输出。`opening-01-prompt.txt` 与 `opening-02-ai09-prompt.txt` 是前两页原始绘图提示，提示中最初的 256×240 已在后续用户试版中调整为本次 384×360。`prompts.json` 保存本轮第 3～5 页的完整提示及逐图输入角色。

处理顺序：3×3 中值去孤点 → BOX 面积缩小至 384×360 → 饱和度乘 0.60 → 亮度乘 0.90 → 阈值锐化（radius 0.6、percent 100、threshold 4）→ 无抖动 64 色中位切分。第 3 页原始画幅 1312×1199，先裁去左右边缘 16 / 17px 以匹配比例，保留角色与完整数字，不直接拉伸；其他页不裁切。以人工测量的脸 / 颈 / 手范围与暖肤色条件取交集，仅局部使用轻微回暖后的六色肤色；六色从已批准第 2 页训练，后续三页共用。保护区域外与各自 64 色底图逐像素相同。不是 9bit RGB。

`approved-01.png` / `approved-02.png` 保留已批准样本，可用 Pillow `ImageChops.difference` 比较重建结果。`asset-validation.json` 记录尺寸、实际色数、保护像素数、文件大小和 SHA-256。第 1 页 64 色，含人物页不超过 70 色。`*-preview-2x.png` 为相邻采样放大两倍预览，`03-05-preview.png` 为后三页并排预览；游戏引用原始 384×360 文件，播放器仅为开场使用 `image-rendering: pixelated`。

已核对生成图、处理图及前两页样本一致性。游戏浏览器显示及自动回归由用户运行，步骤见 `docs/acceptance.md`。
