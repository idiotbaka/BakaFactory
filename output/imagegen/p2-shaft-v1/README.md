# P2 机械动力剧情配图

内置 imagegen 逐页新绘“P2 前期：机械动力，应力过载”的五张横幅漫画。
提示词和项目内风格参考见 `prompts.json`。正式资源位于
`apps/web/src/assets/stories/p2-shaft-v1/`，页面文案位于
`apps/web/src/game/stories/p2ShaftOverload.ts`。

采用既有 BAKA-01 奶白方头 / 青色眼睛、粉球天线、黄色机身、青绿围巾、金属夹爪与红靴造型，
延续暖锈手绘工业绘本漫画风。每页独立生成，PNG 为 1672×941，等比显示，不拼接、不拉伸。
第 1 / 2 / 3 / 5 页原图直接复制为项目资源。第 4 页局部修订液压设备，确保为封闭工作液回路，
避免画成水坝发电；其导出原图为 1671×941，仅复制最右边缘像素列补足 1px 至 1672×941，
不拉伸或裁切画面，无额外图片处理依赖。剧情正文和页码由游戏绘制。
资源尺寸、体积和 SHA-256 记录于 `asset-validation.json`，不依赖个人生成目录。

可从仓库根目录执行 `node output/imagegen/p2-shaft-v1/validate-assets.mjs`
重新核对正式资源的 PNG 文件头、统一尺寸和五图独立性，并更新静态资源报告。

生成其他剧情时，先阅读 `docs/stories.md`，查看 `prompts.json` 指定的既有参考图片，
使用同样的角色约束、横幅比例与无对话框要求逐页绘制；生成后逐张检查构图与角色一致性，
复制到项目独立版本目录，再核对全部图片的 PNG 头、尺寸及章节引用。
