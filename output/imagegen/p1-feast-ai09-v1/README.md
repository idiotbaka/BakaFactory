## 重建

需要 Python 3 和 Pillow，仅用于离线美术处理。未安装时可先在虚拟环境中执行 `python -m pip install Pillow`。从仓库根目录运行：

```sh
python output/imagegen/p1-feast-ai09-v1/process.py
```

脚本直接复用 `output/imagegen/opening-ai09-v1/process.py` 的预处理与肤色映射函数，不改开场成图：3×3 中值去孤点 → BOX 缩图至 384×360 → 饱和度 ×0.60 → 亮度 ×0.90 → 阈值锐化（radius 0.6、percent 100、threshold 4）→ 无抖动 64 色底图 → 局部六色肤色保护。肤色色板直接读取开场 `asset-validation.json` 的已确认六色；人工测量的脸、颈与手范围再与暖肤色条件相交，保护范围外与 64 色底图逐像素一致。每张最多 70 色，不使用 9bit RGB。

五张源图均为 1295×1214，与目标比例差异小于 0.002，沿用开场规则直接 BOX 缩图，没有裁切。`sources/` 保存绘图原始输出；`asset-validation.json` 保存尺寸、色数、肤色范围、文件大小与 SHA-256。`01`～`05-preview-2x.png` 是相邻采样两倍预览，`contact-sheet-2x.png` 按上三下二的顺序汇总五页；游戏引用 384×360 正式图。

已经目视核对原图及处理后图。静态资源校验在运行脚本时执行；游戏内显示与自动回归由用户执行，见 `docs/acceptance.md` 的“P1 五图与 09 号重绘”。
