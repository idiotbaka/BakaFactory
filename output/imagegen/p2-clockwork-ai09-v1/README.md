## 重建

需要 Python 3 和 Pillow，仅用于离线美术处理，不新增游戏运行依赖。可在虚拟环境执行 `python -m pip install Pillow`，再从仓库根目录运行：

```sh
python output/imagegen/p2-clockwork-ai09-v1/process.py
```

直接复用未改动的 `output/imagegen/opening-ai09-v1/process.py` 函数和已确认的六色肤色色板：3×3 中值去孤点 → BOX 缩至 384×360 → 饱和度 ×0.60 → 亮度 ×0.90 → 阈值锐化（radius 0.6、percent 100、threshold 4）→ 无抖动 64 色底图 → 局部六色肤色保护，不使用 9bit RGB。

按新图测量脸、颈、手范围，与原暖肤色条件相交；员工牌、考评板和交班册附近另以皮肤轮廓限制，避免暖纸、黄色车漆或夕照误着色。区域外与原 64 色底图逐像素相同。源图 1295×1214 或 1295×1215，沿用原比例容差直接缩图，无裁切。

`sources/` 保存最终源图；`asset-validation.json` 记录尺寸、色数、肤色区域、大小与 SHA-256。脚本核对保存像素、保护范围外像素与五图独立性。`01`～`05-preview-2x.png` 为相邻采样两倍预览，`contact-sheet-2x.png` 按上三下二汇总；游戏只引用正式小图并启用既有 `pixelArt` 显示。`integration-validation.json` 记录正文、引用、原有资源与构建产物静态核对，不表示运行了自动测试。

旧 `p2-clockwork-v1/` 资源保留归档。五页标题、25 段正文、任务 / 章节 ID、领奖触发及观看记录保持。已领奖玩家可从“重放剧情 → P2 中期：第一位会走路的帕鲁同事”验收，无需清档。实际验证状态见 `docs/progress.md`，游戏内显示与自动测试由用户按 `docs/acceptance.md` 执行。
