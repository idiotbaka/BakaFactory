## 重建与静态核对

需要 Python 3 和 Pillow，仅用于离线美术处理，不新增游戏运行依赖。可在虚拟环境执行 `python -m pip install Pillow` 后，从仓库根目录运行：

```sh
python output/imagegen/p2-shaft-ai09-v1/process.py
```

直接调用未改动的 `output/imagegen/opening-ai09-v1/process.py` 函数和已确认六色肤色：3×3 中值去孤点 → BOX 缩至 384×360 → 饱和度 ×0.60 → 亮度 ×0.90 → 阈值锐化（radius 0.6、percent 100、threshold 4）→ 无抖动 64 色底图 → 局部六色肤色保护。不使用 9bit RGB。

脸、颈、手选区按新图测量，并与原暖肤色条件相交。图鉴页额外用轮廓多边形限制保护范围，避免暖纸误着色；保护范围外与原 64 色底图逐像素相同。五张原图均为 1295×1215，沿用原比例容差直接缩图，无裁切。正式图为 69～70 色。

`sources/` 保留原始绘图；`asset-validation.json` 保存尺寸、色数、肤色选区、文件大小和 SHA-256；脚本核对保存像素、保护范围外底图和五图独立性。`01`～`05-preview-2x.png` 是相邻采样两倍预览，`contact-sheet-2x.png` 依上三下二汇总；游戏只引用正式小图，并启用现有 `pixelArt` 显示。`integration-validation.json` 记录正文、引用及既有资源的静态核对，不表示运行了自动测试。
