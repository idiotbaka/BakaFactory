## 重建

需要 Python 3 和 Pillow，仅用于离线美术处理，不新增游戏运行依赖。可在虚拟环境执行 `python -m pip install Pillow`，再从仓库根目录运行：

```sh
python output/imagegen/p2-hatch-ai09-v1/process.py
```

脚本沿用上一提交的流程，直接调用未改动的 `output/imagegen/opening-ai09-v1/process.py` 函数：3×3 中值去孤点 → BOX 缩至 384×360 → 饱和度 ×0.60 → 亮度 ×0.90 → 阈值锐化（radius 0.6、percent 100、threshold 4）→ 无抖动 64 色底图 → 局部六色肤色保护。肤色读取开场已确认的 `asset-validation.json`，每张最多 70 色，不使用 9bit RGB。

脸 / 颈 / 手选区按新图测量并与原暖肤色条件相交。第四页纸面、第五页夕照墙面与肤色接近，另以局部轮廓多边形收紧保护范围，避免出现粉色矩形；预处理参数、色板和区域外底图保持原流程。区域外与 64 色底图逐像素一致性、保存像素一致性、尺寸、色数与独立 SHA-256 在处理脚本中校验。

五张源图为 1295×1214 或 1295×1215，沿用原比例容差直接 BOX 缩图，无裁切。`sources/` 保留原始绘图；`asset-validation.json` 记录实际规格、选区、色数及散列；`01`～`05-preview-2x.png` 为相邻采样两倍预览，`contact-sheet-2x.png` 按上三下二汇总。游戏仅引用正式小图，并启用现有 `pixelArt` 显示。
